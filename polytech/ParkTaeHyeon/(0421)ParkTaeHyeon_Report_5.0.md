# 차세대 원격 지원: VNC (Virtual Network Computing)

검은색 콘솔 터미널에 갇혀 명령어를 치는 SSH의 텍스트 기반 원격 연결에서 벗어나, 윈도우의 '원격 데스크톱'처럼 완벽한 **GUI 데스크톱 그래픽 화면**을 통째로 띄워 마우스를 움직이게 해주는 프로토콜이 바로 **VNC(가상 네트워크 컴퓨팅)**입니다.

* **원리:** 서버 측 그래픽 프레임 버퍼를 캡처하여 클라이언트 (뷰어)에게 RFB 프로토콜을 이용해 픽셀 데이터를 전송하고, 반대로 클라이언트 쪽에서 클릭된 마우스/키보드 X, Y 좌표 입력값을 서버에 쏴주는 방식입니다.
* **장점:** 물리적으로 지구 반대편에 있는 서버 환경도, 오피스 문서 작업이나 웹 브라우징이 가능한 바탕화면 통째로 컨트롤할 수 있습니다. 운영체제 제약이 거의 없습니다.

## VNC 주요 소프트웨어 제품군 비교

### 1. RealVNC
가장 인지도가 높고 근본 있는 VNC 구현체입니다. 유·무료 버전으로 나뉘며 윈도우, 리눅스, 안드로이드 모바일 등 완벽한 크로스 플랫폼을 지원합니다.
* **보안:** 유료 구독 시 강력한 AES-256 (128비트 블록 암호문을 사용한 대칭키 알고리즘) 등 군사급 암호화 기술이 탑재되어 기업망에서도 널리 쓰입니다.

### 2. TightVNC
가볍고 단순함이 무기입니다. 저대역폭(느린 인터넷)의 통신 환경에서 화면 압축 기술(Tight Encoding)을 극한으로 끌어올려 버벅임을 줄이는 데 특화되어 있습니다.
* **제한 사항:** 암호화 레벨이 약해 오픈된 외부 인터넷망에서 쓰기에는 탈취 위험이 있습니다.

### 3. UltraVNC
TightVNC와 비슷한 무료 프로젝트이지만 주로 Windows 환경의 편의 기능에 몰빵한 유틸리티입니다. 채팅 기능, 양방향 드래그 앤 드롭 파일 전송 기술이 강점입니다.

### 4. TigerVNC
리눅스 진영에서 최근 가장 많은 표준 채택(Rocky Linux, Fedora 기본 VNC 데몬 등)을 받고 있는 무료 고성능 프로그램입니다. TightVNC의 느린 3D 렌더링을 획기적으로 개선해 화질이 뛰어나며 응답 속도가 발군입니다.

### 5. TurboVNC
TigerVNC 계열이지만 **OpenGL(3D 가상 그래픽 렌더링)**에 완벽하게 집착한 버전입니다. VNC 화면을 띄워 놓고 CAD 렌더링 도면을 돌리거나 무거운 3D 게임 코딩을 시연할 때 끊김 없는 프레임을 보장하기 위해 주로 공학계에서 세팅합니다.
