# 운영체제 통제권 전환 및 런레벨(Runlevel) 이해

## 1. 가상머신(VM)에서 마우스/키보드 커서 탈출하기

VMware나 VirtualBox를 통해 리눅스를 구동 중일 때, 마우스로 리눅스 시스템 창 내부를 클릭하면 마우스와 키보드의 온전한 디바이스 제어권이 리눅스(게스트 OS)에 가두어져 버립니다. Windows(로컬 호스트 OS)로 다시 마우스를 빼내려면 아래의 기본 단축키를 눌러야 합니다.

* **VMware의 기본 탈출 키 (Host Key):** 키보드의 로 왼쪽과 오른쪽 `Ctrl` + `Alt` 버튼을 동시에 한 번 누르기.
* **VirtualBox의 기본 탈출 키:** 키보드 우측 하단에 있는 우측 `Ctrl` (Right Ctrl) 버튼 한 번 누르기.

*(※ 이 단축키는 가상머신 소프트웨어의 환경설정(Preferences / HotKeys) 메뉴에서 사용자 취향에 맞게 자유롭게 변경할 수 있습니다.)*

## 2. 리눅스의 7가지 심장 박동 모드: Runlevel

**런레벨(Runlevel)**이란 리눅스가 켜질 때 처음부터 끝까지 어떤 데몬 그룹들을 활성화할지 결정하는 "목적별 부팅 모드 스위치"입니다.
`0`부터 `6`까지 총 7단계로 정의되어 있으며, 터미널 명령창에 `init [숫자]`를 입력하는 즉시 리눅스는 해당 레벨 상태로 강제 전환을 시작합니다. 

* **런레벨 0 (`Poweroff`):** 
  시스템을 즉시 종료하고 전원을 꺼버립니다. (`init 0`)
* **런레벨 1 (`Single User Mode`):** 
  시스템 관리자 혼자 덩그러니 접속되는 복구 및 안전 모드입니다. 관리자가 root 비밀번호를 분실했을 때 이 모드로 강제 부팅해 암호를 초기화하는 등 시스템의 치명적 오류를 임시 복구할 때 씁니다.
* **런레벨 2 (`Multi-User without NFS`):** 
  네트워크가 단절된(오프라인) 상태의 텍스트 콘솔 다중 사용자 모드입니다.
* **런레벨 3 (`Full Multi-User CLI Mode`):** 
  ★ **현대 실무 리눅스 서버의 영원한 표준 부팅 상태**입니다. 그래픽 낭비 없이 오로지 검은 텍스트 화면 상태로 부팅되며, 모든 네트워크 서비스가 구동되는 다중 접속 가능 상태입니다.
* **런레벨 4 (`Unused`):** 
  시스템에서 쓰지 않도록 비워둔 예비 번호입니다.
* **런레벨 5 (`Graphical GUI Mode`):** 
  런레벨 3의 통신 베이스 위에 무거운 X-window (그놈, KDE 등 그래픽 마우스 환경) 데스크톱 환경을 덮어씌워 부팅합니다. 서버 자원을 헛되이 낭비하므로 실무 서버 체제에선 절대 쓰지 않고 리눅스를 테스트하는 개인 PC 개발용입니다.
* **런레벨 6 (`Reboot`):** 
  시스템을 즉시 재시작합니다. (`init 6`)

> 🚨 **치명적 주의 사항!** 
> 절대로 시스템의 '기본값(default)' 부팅 룰(`/etc/inittab` 또는 `systemctl set-default`)을 `0`이나 `6`으로 고정 세팅하지 마세요! 해당 설정이 저장되면, 부팅되자마자 다시 꺼지고, 부팅되자마자 꺼져버리는 무한 루프 지옥에 빠져 리눅스를 포맷해야 할 수도 있습니다.
