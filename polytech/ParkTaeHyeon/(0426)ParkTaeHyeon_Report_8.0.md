# Windows 터미널의 종류: CMD vs PowerShell vs Terminal

리눅스에 막강한 터미널 쉘인 Bash, Zsh이 있듯이 마이크로소프트의 윈도우(Windows) 진영에도 세대를 거쳐 발전해 온 3가지 강력한 명령 지휘소가 있습니다.

## 1. 전설의 시작: 명렁 프롬프트 (CMD)
* **역사:** Windows 95 시절 `Command.com`과 MS-DOS 환경의 잔재로부터 이어져온 가장 오래된 원시적인 형태의 쉘입니다.
* **특징:** 
  가장 가볍고 근본적이지만, 기능이 한정되어 있어 핑테스트(`ping`)나 단순 디렉터리 훑어보기, 낡은 로컬 에러 잡기 정도에 사용됩니다.

## 2. 엄청난 파괴력: 파워쉘 (PowerShell)
* **역사:** 2006년 출시되어 XP 시절부터 지원된 파란색 창의 괴물 같은 쉘입니다. 현재 윈도우 서버 환경의 절대적인 표준입니다.
* **특징:** 
  CMD로 할 수 있는 모든 것을 하위 호환하며, 윈도우 아키텍처의 핵심인 `.NET Framework` 와 **C# 객체(Object)** 지향 논리를 쉘 상에 직접 투척해 프로그래밍할 수 있습니다. 
* **구문 시안성:** 에러가 나거나 특정 구문이 실행될 때 단색(형광등색)만 지원하던 CMD와 달리, 구문 파서가 에러는 붉은색, 경고는 노란색으로 **컬러라이징(Syntax Highlighting)** 해주어 직관적인 스크립트 디버깅이 가능합니다.

## 3. 리눅스를 품은 차세대: Windows Terminal
* **역사:** 2019년 Windows 10/11 전용으로 출시된 오픈소스 기반의 궁극의 터미널 모음집입니다. (현재 Windows 11의 완전한 기본 터미널 프로그램으로 교체되었습니다.)
* **특징:** 
  CMD와 PowerShell을 탭(Tab)으로 각각 띄울 수 있는 창호지 역할을 넘어, 가장 충격적인 혁신은 윈도우 내부의 리눅스 코어 엔진인 **WSL(Windows Subsystem for Linux)**을 네이티브로 완벽히 지원한다는 점입니다. 
  즉, 이 터미널 화면에서 클릭 한 번이면 진품 Ubuntu 리눅스의 `Bash` 쉘이 구동되어 리눅스 서버에 접속할 필요 없이 내 윈도우 안에서 리눅스 인프라를 지휘할 수 있습니다. 
* **커스텀:** JSON 프로필 설정을 통해 탭 분할, 글꼴 매핑, SSH 서버 직접 다이렉트 환경 등 엔지니어의 상상력을 모두 구현할 수 있는 미려한 GUI를 제공합니다.
