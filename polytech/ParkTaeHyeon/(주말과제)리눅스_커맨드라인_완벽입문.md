# 터미널 프롬프트 커스텀: ANSI 이스케이프 코드와 색상 제어

리눅스의 쉘 터미널은 단지 글자만 찍어내는 것이 아닙니다. 
우리가 항상 마주치는 명령어 대기줄인 **프롬프트(`[me@linuxbox ~]$ `)**도 내 마음대로 시간을 박아 넣고 색상을 화려하게 치장할 수 있습니다. 이것은 `$PS1` 이라는 통제 변수와 `ANSI 제어 코드`의 마법입니다.

---

## 1. 프롬프트 모양의 통제 (PS1)
현재 내 프롬프트를 그려주고 있는 변수는 `PS1`입니다. 이 변수 안에 특정한 예약어(백슬래시 `\`)를 넣으면 동적인 데이터로 렌더링 됩니다.

```bash
# 기본값 확인
$ echo $PS1
[\u@\h \W]\$
```
* `\u` : 현재 내 유저 아이디 (username)
* `\h` : 호스트 서버 이름 (hostname)
* `\W` : 현재 내가 위치한 맨 끝단 디렉터리 이름
* `\$` : 일반 유저면 `$`, 루트 유저면 `#` 마크 점등

### 프롬프트 다이어트 및 시계 장착 (활용 예시) 
```bash
# 1. 뼈대만 남기기 (오직 $ 기호 하나만 띄움)
$ PS1="\$ "

# 2. 작업 시간 표시기 장착 (\A는 24시간제 시계 표시기)
$ PS1="\A \h \$ "
17:33 linuxbox $
```

## 2. ANSI 이스케이프 제어 코드로 색상 입히기
터미널 모니터 하드웨어에게 "화면에 글자 대신 컬러 잉크를 뿌려라!"라고 지시하는 명령어 체계가 있습니다. 이를 **ANSI Escape Code** (표준 탈출 코드)라고 하며, 시작 코드는 무조건 `\033[` 입니다.

### 색상 코드표 맛보기
* 글자색 코팅: `30`(검정), `31`(빨강), `32`(초록), `33`(노랑)
* 바탕색 코팅: `41`(빨간배경), `42`(초록배경), `44`(파란배경)
* 포맷: `\033[색상번호m` (해당 색상으로 스위치 ON!)
* 리셋: `\033[0m` (색상 칠하기 종료 및 복구)

```bash
# 테스트: 빨간색으로 글자를 치장해보자. 프롬프트 전체에 31번(빨간 잉크)을 뿌렸을 때의 참사
$ PS1="\[\033[0;31m\]<\u@\h \W>\$ "
# 결과: 프롬프트뿐만 아니라 내가 쳐서 출력되는 결과 물들까지 죄다 빨간색으로 화면이 피바다가 됩니다!
```

### 정교한 복구 코드 (`\033[0m`)
터미널의 잉크 통은 한 번 열면 닫아주기(`0m`) 전까지 평생 색을 뿌리기 때문에, 프롬프트 장식이 끝나는 맨 마지막 점에 반드시 잉크 통을 리셋해줘야 내가 입력할 글자가 정상적인 흰색으로 출력됩니다.

```bash
# 가장 스탠다드한 에러 없는 붉은색(31m) 프롬프트 셋팅!
$ PS1="\[\033[0;31m\]<\u@\h \W>\$\[\033[0m\] "
```

## 3. 영구 적용시키기 (`.bashrc`)
위처럼 터미널 창 화면에 `PS1`을 주입하는 방법은 재부팅하거나 마우스를 꺼버리면 날아가 버립니다.
그래서 나만의 멋진 색상 프롬프트 코드를 만들었다면, 리눅스에 로그인할 때마다 제일 처음 읽어오는 내 집 안의 장부파일인 **`~/.bashrc`** 파일에 고정시켜 두어야 매일매일 자동으로 장착됩니다.

```bash
# ~/.bashrc 파일의 최하단에 아래를 적고 저장합니다.
PS1="\[\033[0;31m\]<\u@\h \W>\$\[\033[0m\] "
export PS1
```
