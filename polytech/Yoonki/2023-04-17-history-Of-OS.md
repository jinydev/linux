# 운영체제의 역사 (1부)

컴퓨터 하드웨어를 제어하고 인간이 편하게 쓸 수 있도록 돕는 시스템인 '운영체제(OS)'가 어떠한 철학과 필요성에 의해 지금의 형태로 진화했는지 알아보는 역사입니다.

## 1. 1950년대: 최초의 OS와 일괄 처리(Batch)
창고만 한 크기의 초창기 컴퓨터들은 오직 복잡한 계산을 위해 키보드도 모니터도 없이 펀치 카드(구멍 뚫린 종이)를 집어넣는 형태였습니다.

* **GM-NAA I/O (최초의 OS):** 1950년대 미국 General Motors에서 IBM 컴퓨터를 돌리기 위해 만든, 최초로 입출력 장치와 상호작용하는 원시 운영체제입니다.
* **일괄 처리 시스템 (Batch Processing):** 당시엔 컴퓨터가 너무 비싸서 한 사람씩 쓸 수가 없었습니다. 여러 사람의 작업(펀치 카드)을 한 번에 다 모아서(Batch) 통째로 컴퓨터에 던져주고 며칠 뒤 결과를 한 번에 받아오는, 자원 절약형 처리 방식이었습니다. 

---

## 2. 1960년대: 메인프레임과 시분할 시스템의 혁신
대형 캐비닛 형태의 **메인프레임(Mainframe)** 컴퓨터가 은행과 정부에 도입되던 시기입니다. 

* **IBM OS/360:** 일괄 처리의 한계를 벗어나, "각기 다른 하드웨어라도 똑같은 OS/360 환경이면 프로그램이 호환된다"라는 이식성의 개념을 최초로 심은 현대적 범용 운영체제입니다.
* **시분할 시스템 (Time-Sharing):** 엄청난 혁명입니다. 거대한 컴퓨터 하나에 모니터 여러 대를 꽂고, 중앙 CPU가 0.1초씩 사람들에게 빙글빙글 돌아가며 연산을 할당해줍니다. 사용자들은 마치 "나 혼자 이 거대한 컴퓨터를 통째로 쓰는 것" 같은 대화형(Interactive) 컴퓨터 착각을 느끼게 되며 오늘날 클라우드의 모태가 되었습니다.

---

## 3. 1970년대: UNIX의 탄생과 프로그래밍의 혁명
* **UNIX (유닉스):** 1969년 벨 연구소의 켄 톰슨과 데니스 리치가 개발한 서버용 운영체제입니다. 이들은 UNIX를 다른 컴퓨터에 쉽게 이식하기 위해 아예 **C언어**라는 위대한 프로그래밍 언어를 직접 발명해 운영체제를 다시 짰습니다. 오늘날 전 세계 인터넷을 지탱하는 모든 OS의 아버지입니다.

## 4. 1980년대: 개인 컴퓨터(PC)와 GUI 화면의 등장
엄청나게 비싸던 메인프레임 시대가 저물고, 책상 위에 놓을 수 있는 개인용(PC) 컴퓨터가 보급됩니다.
* **MS-DOS:** 빌 게이츠의 마이크로소프트가 만든, 검은 화면에 키보드로 명령어를 치는 CLI(Command Line Interface) 기반의 16비트 운영체제입니다. 폭발적으로 보급되며 PC 시대를 열었습니다.
* **Macintosh (애플 매킨토시):** 1984년 마우스로 아이콘과 창을 클릭하는 **GUI (Graphical User Interface)** 환경을 상용화시켜, 컴퓨터를 전문가의 전유물에서 일반 대중의 도구로 끌어내렸습니다.
