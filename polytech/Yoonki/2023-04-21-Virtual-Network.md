# 가상머신(VM)의 3대 네트워크 라우팅 모드

가상머신을 띄우고 리눅스 서버를 구축할 때 가장 헷갈리는 것이 네트워크 세팅입니다. VMWare나 VirtualBox에서 제공하는 **NAT, Bridged, Host-Only** 3가지 핵심 네트워크 어댑터의 특성을 정리합니다.

---

## 1. NAT (Network Address Translation)
가상머신 구동 시 가장 기본값으로 잡히며, **서버 구축용으로는 치명적이지만 인터넷 서핑용으로는 가장 안전한 모드**입니다.

* **원리:** 여러분의 윈도우(호스트 PC)가 내부적으로 '작은 가짜 공유기(DHCP)' 역할을 자처합니다. 가상머신은 윈도우로부터 사설 IP(`10.0.x.x` 등)를 은밀하게 하나 부여받아, 윈도우의 등 뒤에 꼭꼭 숨어서 몰래 바깥(인터넷)과 통신합니다.
* **장단점:** 윈도우가 인터넷만 된다면 가상머신도 무조건 외부 웹서핑이 가능해 편합니다. 하지만 **외부망에서 이 안쪽에 있는 가상머신으로 찾아들어올 수가 없기 때문에**, 여기서 웹 서버를 돌리려면 포트포워딩 설정이라는 번거로운 작업을 해줘야 합니다.

## 2. Bridged (브릿지 네트워크)
**진짜 실무 서버처럼 내 방 공유기에 가상머신을 직접 꽂는 모드**입니다. 

* **원리:** 호스트 PC(윈도우)의 랜카드를 투명한 다리(Bridge)처럼 빌리기만 하고, 실제 IP는 윈도우가 받고 있는 집 안 공유기(KT, iptime 등)로부터 똑같이 동등한 식구로서 사설 IP(`192.168.0.x`)를 하나 독립적으로 발급받습니다.
* **장단점:** 호스트 PC와 완전히 독립된 별개의 컴퓨터로 취급되므로, 같은 공유기 와이파이를 잡고 있는 스마트폰이나 다른 가족의 노트북에서도 가상머신의 아이피를 치고 즉시 웹 서버로 다이렉트 접속이 가능합니다. 테스트 서버 오픈 등 실무 실습에 가장 완벽합니다.

## 3. Host-Only (호스트 전용 / 내부 네트워크)
**완벽한 무인도, 인터넷이 절단된 폐쇄망 서버 생태계**입니다.

* **원리:** 외부의 공유기나 인터넷 세상과의 선을 물리적으로 끊어버립니다. 오직 내 윈도우(호스트)와 이 가상머신들끼리만 끼리끼리 연결된 전용 폐쇄망을 구축합니다.
* **장단점:** 외부 통신이 원천 차단되므로 `apt install` 같은 다운로드가 불가능합니다. 그러나, 외부 해커가 절대 뚫을 수 없다는 뜻이기도 하므로, 보통 웹 서버 뒤에 숨겨놔야 하는 1급 보안 데이터베이스(DB) 전용 사설 통신 서버망을 구축할 때 NAT와 섞어서 현업에서 구성합니다.
