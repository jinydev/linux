# 리눅스 압축 1편: '묶기'와 '압축'의 분리 철학

흔히 윈도우에서 `알집`이나 `반디집`으로 폴더를 하나 우클릭해 `.zip` 파일로 쭈욱 빨아들이듯 압축하는 것과 달리, **리눅스(UNIX) 세계에서는 "파일을 거꾸로 하나로 뭉치는 것"과 "실제 용량을 비트 단위로 줄이는 것" 의 2가지 행위가 완벽히 독립된 개념**을 가집니다.

---

## 1. 아카이빙(Archiving)과 압축(Compression)의 차이

### 1단계: 묶어주기 (아카이빙 - Archiving)
리눅스의 수만 개 폴더와 권한 정보를 그냥 무식하게 압축하면 손상되거나 퍼미션이 날아갑니다. 그래서 먼저 오로지 **"용량은 단 1바이트도 줄이지 않고 그저 거대한 하나의 단일 파일 덩어리로 묶는 작업"**을 수행합니다. 
이 묶는 표준 도구가 바로 끈적한 테이프라는 뜻의 전통 명령어 **`tar` (Tape ARchive)** 입니다. 만들어진 파일은 `.tar` 가 됩니다.

### 2단계: 짓눌러서 압축하기 (압축 - Compression)
예쁘게 한 덩어리로 묶인 안전한 `.tar` 원본 덩어리를, 수학적 알고리즘(`gzip`, `bzip2`)을 적용시켜 실질적인 HDD 용량을 극단적으로 절반 이하로 줄여버립니다. 
압축 엔진이 적용된 결과물 파일은 최종적으로 **`.tar.gz`** 형식의 기나긴 족보를 갖게 됩니다.

---

## 2. 절대 명사: `tar` 명령어 기본 활용 가이드

현대의 `tar` 명령어는 옵션 한 글자만 더하면, "1단계(묶기)"를 수행하자마자 찰나의 순간에 알아서 백그라운드 엔진에게 던져 "2단계(압축)" 까지 한 큐에 투 트랙으로 끝내줍니다.

### [기본 문법 구조]
```bash
$ tar [옵션] [생성될최종파일명.tar.gz] [압축할대상폴더명]
```

### [가장 많이 쓰는 실무 3종 세트 정리]

#### ① 묶으면서 동시에 압축하기 (cvfz)
가장 보편적인 `gzip` 알고리즘(`z` 옵션) 적용 생성 방식입니다.
```bash
# myfolder 폴더 전체를 backup.tar.gz 이라는 고도 압축 파일로 생성
$ tar cvfz backup.tar.gz /home/user/myfolder/
```

#### ② 압축 풀지 않고 묶여있는 파일 내용만 구경하기 (tvf)
파일이 몇 백 기가바이트 단위라 풀 엄두가 안 날 때 목록만 사전 점검합니다.
```bash
$ tar tvf backup.tar.gz
```

#### ③ 압축 냅다 풀기 (xvfz)
현재 내가 위치한 디렉토리 바닥에 고스란히 묶인 폴더들을 토해냅니다.
```bash
$ tar xvfz backup.tar.gz

# (심화) 내 바닥이 아니라 -C 옵션을 줘서 우분투 /tmp/ 임시 방으로 쏴서 흩뿌리기
$ tar xvfz backup.tar.gz -C /tmp/
```

> **[옵션 알파벳 원리 암기장]**
> * **`c`** (Create) : 새로운 아카이브 덩어리를 만든다. (묶기)
> * **`x`** (eXtract) : 아카이브 덩어리를 찢고 헤쳐 모인다. (풀기)
> * **`t`** (list) : 내부 파일들의 리스트만 출력해서 본다.
> * **`v`** (Verbose) : 지금 압축되고 있는 파일 이름을 화면에 투명하게 다 보여줘라.
> * **`f`** (File) : 지정된 파일명으로 만들겠다. (무조건 옵션 맨 끝에 f를 써야 파일명과 붙음)
> * **`z`** (gZip) : 묶으면서 동시에 gzip 엔진으로 압축까지 해서 용량을 줄여달라.
