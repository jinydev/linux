# 리눅스 시스템 관리 기본 명령어

윈도우와는 달리 모든 것을 마우스 없이 키보드와 텍스트(CLI)로 조작해야 하는 리눅스 서버 세계에서, 개발자와 인프라 엔지니어들이 밥 먹듯이 타이핑하는 최소한의 명령어 세트입니다.

## 1. 시스템 전원 및 프로세스 제어

- **`poweroff`** : 메인보드 전원까지 완전히 즉각 종료 (현대적인 표준)
- **`shutdown -P now`** : (위와 동의어) 안전하게 모든 데몬 캐시를 디스크에 쓰고 즉시 전원 끄기
- **`shutdown -r 22:00`** : 예약 재부팅. 오후 10시에 재부팅 (r은 reboot 구문)
- **`shutdown -c`** : 예약했던 기존의 셧다운 스케줄을 취소(Cancel)
- **`reboot`** : 시스템 즉시 재시작

*(추가 지식: 콘솔 상단에 `[root@localhost ~]#` 처럼 마지막 프롬프트 기호가 **`#`** 이면 시스템 전체를 제어할 수 있는 신적인 권한, 즉 **SuperUser(Root)** 상태를 의미하고, **`$`** 표시가 떠 있다면 권한이 제한된 일반 사원(User) 계정임을 나타냅니다.)*

## 2. VI/VIM (콘솔 화면 전용 에디터)
GUI 메모장 팝업이 뜨지 않는 리눅스 서버에서, 설정 파일을 수정하기 위한 고전 텍스트 인터페이스 에디터입니다.
- **실행 모드 진입:** `vi 파일이름.txt` (명령 모드로 최초 진입)
- **수정 시작:**  키보드 `i` 또는 `a`를 누르면 화면 모서리에 `-- INSERT --` 글자가 뜨며 수정 가능
- **수정 후 나가기:** `Esc` 를 연타하여 입력 모드 탈출 후, 콜론(`:`) 누르기
- **`:wq`** : 수정한 문서 내용 저장(Write) 후 강제 종료(Quit) 
- **`:q!`** : 수정한 내용이 맘에 들지 않아 저장하지 않고 강제 종료 (비상 탈출)
- **`:%s/원래단어/새단어/g`** : 텍스트 파일 내의 '원래단어'를 모두 '새단어' 일괄 치환(가장 많이 쓰이는 정규식)

## 3. 디렉토리 구조 및 파일 조작 (필수)

| 명령어 (Command) | 실무 활용 예시와 문법 | 주요 특징 설명 |
|---|---|---|
| **`ls`** | `ls -al` (제일 자주 타건) | 현재 속해 있는 폴더 내의 파일 갯수, 종류, 숨김목록(`.`)까지 상세히 봅니다. |
| **`pwd`** | `pwd` | 현재 콘솔 창이 컴퓨터 하드디스크 깊숙이 어디에 속해 있는 지 절대 경로 표기 |
| **`cd`** | `cd /var/log/` | 지정한 해당 경로 폴더 지점으로 쏙 이동합니다. (`cd ..`은 바로 윗 부모 폴더로 퇴각) |
| **`mkdir`** | `mkdir -p /root/abc/def` | 임의의 폴더를 생성합니다. (`-p`를 주면 경로상에 부모 디렉토리가 없어도 오류내지 않고 다 만들어 버립니다.) |
| **`cp`** | `cp -r file_A 폴더_B/` | 파일을 복사해서 어딘가로 붙여넣습니다. 대상이 폴더면 무조건 통째로 복사하는 `-r` (재귀적 옵션)을 줍니다. |
| **`mv`** | `mv abc.txt bbc.txt` | 파일을 이동시킵니다. 사실상 리눅스에서 파일 이름(Name)을 변경하는 명령어가 바로 mv 입니다. |
| **`rm`** | `rm -rf log_folder` | 묻지도 따지지도 않고 경로 폴더와 파일을 강제(f) 영구 삭제합니다. |

## 4. Yum/Dnf를 활용한 패키지 프로그램 설치
레드햇(RHEL), Rocky 리눅스 환경에서 우분투의 `apt` 처럼 구동되는 스마트 패키지 설치 매니저입니다. 과거 RPM 인스톨러 방식이 프로그램 설치 시 'A 부품이 모자라서 못깐다'는 의존성 오류를 밷던 비극을, 수백 개 인터넷 서버를 다 뒤져 의존성 파일을 통째로 깔아주도록 진화한 현대적 방식입니다.

- **`yum check-update`** : 시스템에 업데이트가 필요한 패키지 검색
- **`yum -y install nginx`** : 도중에 묻는 설치 진행 Y/N 대화창에 모두 Yes(`-y`)라고 대답하며 Nginx 웹서버를 초고속 설치
- **`yum remove 패키지명`** : 설치된 내상 패키지 클린 환향 제거
