# MAC Address (물리적 하드웨어 주소)

## 1. MAC 주소란 무엇인가?
MAC Address(Media Access Control Address)란, **컴퓨터의 랜카드(네트워크 인터페이스 카드, NIC)가 제조사 공장에서 생산될 때 고유하게 부여받는 48비트 크기의 영구적인 물리적 식별 번호**입니다. 세상에 단 하나뿐인 기기 고유의 지문과도 같습니다.

* **형식 표기:** `00:1A:2B:3C:4D:5E` 처럼 16진수 6자리 쌍으로 표기됩니다. (앞 3자리는 제조사 고유 ID, 뒤 3자리는 제품 일련번호)

## 2. MAC 주소와 IP 주소의 결정적인 차이

인터넷 통신을 위해 왜 IP 주소와 MAC 주소 두 개가 전부 필요할까요?
주민등록번호(MAC)와 현재 살고 있는 아파트 택배 주소(IP)로 비유할 수 있습니다.

* **IP 주소 (논리적 주소):** 내가 카페에 가면 카페 IP, 집에 가면 집 IP를 할당받듯 **환경에 따라 유동적으로 변하는 1회성 택배 도착지 주소**입니다. (네트워크/L3 계층)
* **MAC 주소 (물리적 주소):** 내 랜카드가 태어날 때 부여받은 **절대 변하지 않는 고유의 기기 번호**입니다. (데이터링크/L2 계층)
> 서울에서 부산으로 택배(패킷)를 보낼 때, 최종 목적지(부산)는 IP 주소로 길을 찾지만 중간중간 거쳐가는 대전 우체국, 대구 우체국(라우터) 사이의 짧은 던지기 통신은 무조건 MAC 주소를 통해 장비 간 옆구리 통신이 이뤄집니다.

## 3. 내 리눅스의 MAC 주소 확인하기

리눅스 터미널에서 아래 명령어를 치면 내 서버의 물리적 MAC 주소(`link/ether` 정보 부분)를 즉각 알 수 있습니다.

```bash
# 최신 리눅스 표준 네트워크 확인 명령어
ip link

# (구형 명령어)
ifconfig -a
```
