# 현대 컴퓨터 아키텍처의 탄생: 에니악과 폰 노이만

## 1. 하드웨어 배선의 지옥, 초기 컴퓨터 (에니악)
세계 최초의 전자식 범용 컴퓨팅 기계인 **에니악(ENIAC, 1945년)** 시대에는, 새로운 계산식을 풀기 위해서 수천 개의 진공관 스위치 선을 사람이 직접 손으로 끼워 패치보드에 물리적 배선을 전부 다시 연결해야만 했습니다. 

'하드웨어적'으로 덧셈 계산기를 만들었다가, 곱셈을 원하면 전선을 전부 다 뽑고 배선을 다시 짜맞춰 '하드웨어 구조 자체를 바꾸는' 무식하고 거대한 노가다 과정이 필요했습니다. (스위치를 한 번 갈아 끼우는 데에만 수일이 소요되었습니다.)

## 2. 천재, 존 폰 노이만의 발상 (John Von Neumann)
미국의 전설적인 수학자 폰 노이만은 이 지독한 에니악의 꼴을 보고, 인류의 소프트웨어 역사를 갈라버리는 희대의 천재적인 논문을 발표합니다.

> "매번 전선을 다시 꼽을 필요가 뭐 있어? 연산을 처리하는 두뇌(CPU)와 정보를 기억하는 방(Memory)을 물리적으로 분리해! 그리고 우리가 할 **명령어 코드(프로그램)를 기억의 방에 데이터처럼 집어넣어 둔 뒤, CPU가 순서대로 그걸 읽어서 처리하면 되잖아!**"

이것이 바로 인류 최초로 **"소프트웨어(프로그램)"를 메모리에 올려서 작동**시킨다는 **"내장형 프로그램(Stored-Program)의 개념"**의 탄생입니다.

## 3. 현대 폰 노이만 아키텍처 (현대 컴퓨터의 기본 뼈대)
오늘날 우리가 스마트폰부터 맥북, 클라우드 서버에 이르기까지 사용하는 모든 인프라 장비의 구조는 모두 이 '폰 노이만 아키텍처'를 100% 동일하게 따르고 있습니다.

### 핵심 3대 구성 요소 체계
1. **중앙 처리 장치 (CPU):** 데이터를 연산하고 제어하는 두뇌 (ALU, 제어장치 등 탑재)
2. **주 기억 장치 (Memory / RAM):** CPU가 실행할 '명령어 코드'와 '실제 데이터'가 아주 자유롭게 모두 저장되는 모래사장 공간
3. **입출력 장치 (I/O Device):** 키보드나 모니터, 하드디스크 등 외부 세계와 통신하는 도구

### 💡 폰 노이만 구조의 의의
이 구조의 가장 엄청난 장점은 **프로그램과 데이터가 동일한 메모리(RAM) 공간에 0과 1의 숫자 형태로 똑같이 취급되어 올라간다는 것**입니다. 덕분에 컴퓨터는 더 이상 물리적인 스위치 전선을 개조할 필요 없이, 메모리에 C언어나 파이썬으로 짜인 소프트웨어 텍스트만 집어넣어 주면 무한한 용도(게임기, 계산기, 브라우저)로 변신하는 범용성을 획득하게 되었습니다.

### ⛔ 구조적 병목 한계점 (Von Neumann Bottleneck)
명령어와 데이터를 하나의 메모리 버스 길을 통해서만 불러와야 하므로, 너무 똑똑해진 현대의 CPU(초고속)가 메모리(느림)가 명령어를 던져 줄 때까지 아무것도 못하고 기다려야만 하는 고질적인 트래픽 정체 현상이 발생합니다. 이를 **병목 현상**이라 부르며, 현대 IT 인프라는 이를 해결하기 위해 CPU 내부에 L1, L2 캐시 메모리를 장착하여 극복해 내고 있습니다.
