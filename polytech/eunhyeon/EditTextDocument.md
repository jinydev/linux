# 리눅스 시스템 편집기 다루기
## 0419. VI/VIM 텍스트 에디터
<hr/>

> 윈도우 OS에는 '메모장'이라는 GUI 편집기가 있습니다. 화면 환경이 제공되지 않는 터미널 기반 리눅스 서버(CLI)에서는 모든 시스템 환경 설정 값과 방화벽 파일 수정, 코드 작성 작업들을 콘솔 창 내 코어 텍스트 에디터를 통해 진행해야 합니다. 

이러한 핵심 에디터 중 개발자와 시스템 관리자들에게 압도적인 선택을 받는 도구가 바로 `vi`와, 그 기능을 확장 및 개선시킨 향상 판 `vim` (Vi IMproved) 편집기입니다. 명령 모드 기반의 수려한 텍스트 네비게이션이 특기입니다. 

```bash
# 파일 새로 작성 혹은 기존 문서 파일 오픈 및 진입
vi my_script.sh
```

## 1. VI 에디터의 3가지 핵심 모드 라이프 사이클
VIM 모델은 화면 진입 시 함부로 글이 쳐지지 않기 때문에 철저히 세 가지 모드(Mode) 간의 전환 규칙을 이해하는 것이 사용법의 핵심입니다.

* **명령 모드 (Command Mode):** 에디터 오픈 시에 처음 진입하는 최상단 안전 구역 지대입니다. 자판을 두드려도 글이 써지지 않으며, 자판 키가 마치 기능키 단축키처럼 활용되어 커서를 옮기거나 라인을 복사/잘라내고 삭제하는 네비게이션 편집 작업을 담당합니다.
* **입력 모드 (Insert Mode):** 명령 모드 지대에서 특정 `키(Key i, a, o 등)`를 눌러 텍스트 입력기를 풀어주어 메모장처럼 화면상에 직접 코드를 타이핑하고 타이틀을 쓰는 실제 편집 행위 구역입니다. 편집을 마쳤다면 `Esc` 키를 연타하여 명령 모드로 복귀해야 저장할 수 있습니다.
* **마지막행 모드 (Last Line Mode):** 명령 모드 상태일 때, 키보드로 `:` 콜론 기호를 치면 하단 맨 끝줄에 명령 바가 생기게 됩니다. 여기에서 문서 저장(w), 나가기/종료(q), 행 번호, 검색 규칙 변경 같은 에디터 전반의 총체적 시스템 옵션을 인가할 수 있습니다.

## 2. 자주 사용하는 핵심 VIM 명령어 단축키 핸드북

### 📌 명령 모드 단축키 (커서 조작 및 편집)
*(※ 항상 ESC를 누른 상태라는 것을 가정합니다)*

| 키 바인딩 | 주요 수행 기능 설명 |
|---|---|
| `x` | 현재 커서가 위치한 글자(단일 문자) 한 개를 즉시 제거/삭제 |
| `dw` | 현재 커서가 시작된 곳부터 띄어쓰기 끝부분(한 단어)을 삭제 |
| `dd` | 커서가 위치한 한 줄 내의 전체 행 전체 문장을 잘라내기/삭제 (`3dd`시 아래로 세 줄 삭제) |
| `yy` | 커서가 위치한 한 줄 내의 전체 행을 램 메모리 공간에 복사하기 (Copy) |
| `p` | 메모리에 저장(혹은 잘라내기) 된 내용을 커서 다음 아랫줄로 완전히 붙여넣기 (Paste) |
| `u` | 앗, 실수했다! 방금 실행했던 명령을 되돌리기 (Undo, Ctrl+Z의 역할 수행) |
| `0` / `^` | 현재 행을 기준으로 커서를 문장의 제일 맨 앞 글자 시작점으로 날려 보내기 |
| `$` | 현재 행을 기준으로 커서를 문장의 제일 맨 끝단으로 날려 보내기 |
| `G` | 편집기의 스크롤을 맨 아래 문서의 최하단 끝 공간으로 일괄 이동 점프 (`1G`는 문서 최상단) |
| `h` `j` `k` `l` | 리눅스 터미널 환경의 좌, 하, 상, 우 커서 이동키 표준 |

### 📌 입력 모드 진입 전환키
명령 모드 상태에서 이 키들을 터치하면 구석에 `-- INSERT --` 글씨와 함께 타이핑 환경이 허용됩니다.

| 전환 키 바인딩 | 진입 시나리오 |
|---|---|
| `i` | 현재 선택된 마우스(커서) 바로 **그 자리에서** 텍스트 커서 활성 진입 |
| `a` | 현재 커서에서 한 글자 공간 **바로 다음에** 커서가 생기며 타이핑 활성 전입 |
| `o` | 커서가 있는 줄의 **바로 아랫줄(엔터 친듯)**로 신규 라인을 만들면서 바로 타이핑 활성 진입 |

### 📌 마지막행 모드 단축키 (문서 파일 제어)
명령 모드시 `:`키로 활성화하며 엔터로 명령을 던집니다.

| 옵션어령 | 주요 수행 저장 기능 |
|---|---|
| `:w` | 현재 작성된 파일명을 덮어씌어 저장(디스크 기록). 에디터가 꺼지지는 않음. |
| `:q` | 에디터 화면 자체를 종료. 단, 저장하지 않고 타이핑된 사항이 존재할 경우 경고를 뱉으며 튕김. |
| `:wq` | 저장(Write)을 확실히 진행함과 동시에 에디터를 종료(Quit)하고 쉘로 완전히 복귀함. 최고 빈도수. |
| `:q!` | 수정된 사항들이 있더라도 문서 저장을 쿨하게 포기하고 **강제로(Force) 폭파 종료**함. |
| `:set nu` | 왼쪽 마진을 뚫어 문서 행 라인의 번호 표기 출력 (프로그래밍 오류 추적 시 필수) |
| `:/문자열` | 작성한 텍스트 안에서 입력한 해당 문자열을 파일 앞쪽 흐름 위치부터 빠르게 탐색/서치 기능 |
