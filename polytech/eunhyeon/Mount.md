# 리눅스 파일 시스템 마운트 (Mount)
## 0420. 마운트(Mount)의 이해
<hr/>
   
**마운트(mount)**란 물리적인 하드 디스크 장치나 USB, CD-ROM 같은 블록 디바이스를 리눅스 시스템이 인식할 수 있도록 **특정 디렉터리에 연결**시켜주는 과정입니다.

윈도우 운영체제는 C 드라이브, D 드라이브처럼 공간 단위로 디렉터리 트리가 분리되지만, 리눅스는 오직 최상위 루트(`/`) 디렉터리에서 뻗어나가는 **단일 트리 구조(Single Directory Tree)**를 사용합니다. 따라서 새로운 디스크를 장착하면 반드시 루트 트리의 특정 빈 가지(디렉터리)에 접목시키는 '마운트' 작업이 필수입니다.

*(과거 보고서 정정: 최신 우분투 데스크톱(GUI) 환경에서는 윈도우처럼 PnP(Plug and Play) 데몬이 작동하여 USB를 꽂으면 자동으로 마운트 처리됩니다. 하지만 실무에서 쓰이는 서버용(CLI) 환경에서는 관리자가 수동으로 마운트를 선언해주어야 합니다.)*

## 1. 기본 명령어 사용법

마운트를 하기 전, `lsblk` 혹은 `fdisk -l` 명령어로 장치명(예: `/dev/sdb1`)을 확인해야 합니다.

```bash
# 기본 구문
mount [옵션] [장치명] [대상 디렉터리(Mount Point)]

# /dev/sdb1 USB 장치를 /mnt 에 마운트
mount /dev/sdb1 /mnt 

# 시스템에 현재 마운트된 모든 정보 출력
mount
```   

## 2. 주요 옵션들 ([Option])

마운트 시 `-o` 인자를 주어 파일 시스템이 작동하는 방식을 제어할 수 있습니다. 

* `-a` : `/etc/fstab` 파일에 명시된 파일 시스템들을 일괄적으로 모두 마운트합니다. 부팅 시 자동 적용되는 스크립트에서 활용됩니다.
* `-t <파일시스템>` : 마운트할 장치의 포맷 유형을 명시합니다. (`ext4`, `xfs`, `vfat`, `ntfs`) 최근 리눅스는 자동으로 감지(auto-detect)하므로 생략하는 경우가 많습니다.
* `-o <세부옵션>` : 여러 조건을 부여할 때 쉼표(,)로 구분합니다.
  * `ro` : 읽기 전용(Read-Only) 모드로 마운트 (해킹 방지 및 원본 보존용)
  * `rw` : 읽기/쓰기 가능 모드로 마운트 (기본값)
  * `remount` : 이미 마운트된 장치의 설정을 변경하여 다시 마운트할 때 사용
  * `loop` : ISO 이미지 파일 등 물리 장치가 없는 파일을 가상으로 마운트할 때 활용
  * `noatime` : 파일을 읽을 때마다 기록되는 접근 시간(Access Time) 메타데이터 갱신을 끕니다. 디스크 I/O 트래픽을 크게 줄여 서버 성능과 수명(SSD 등)을 상승시키는 핵심 엔터프라이즈 최적화 옵션입니다.

## 3. 영구 마운트 (fstab)
재부팅 시에도 자동으로 마운트가 유지되게 하려면, 관리자 권한으로 `/etc/fstab` 파일에 마운트 정보를 기록해야 합니다. 임의로 mount 명령어만 치면 1회성 연결이므로 재부팅 시 풀립니다.
