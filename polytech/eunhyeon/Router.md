# 리눅스와 네트워크 통신
## 0425. 라우터와 라우팅(Routing)
<hr/>   

> **라우팅**은 서로 다른 여러 네트워크들 사이에서 데이터 패킷이 목적지까지 빠르고 안전하게 도착하도록 최적의 이정표(경로)를 선택하여 표지판을 제시해 주는 핵심 프로세스입니다.

## 1. 라우터(Router)란 무엇인가?
일상에서도 공유기를 흔히 찾아볼 수 있듯이, **라우터**는 이기종 혹은 서로 다른 IP 대역을 갖는 네트워크 간의 관문 역할을 하는 네트워킹 핵심 장비입니다.
- **경로 결정:** 패킷 내 대상 IP 주소를 분석하고, 내부의 지도(라우팅 테이블)를 기반으로 어디로 가야 가장 최적화된 경로인지 지표를 도출합니다.
- **데이터 포워딩:** 도출된 계산 결과를 바탕으로 다음 연결된 이웃 라우터 장비(Next Hop)로 패킷 데이터를 힘차게 넘겨줍니다.

## 2. 라우팅 테이블(Routing Table)
지도 없이 길을 찾을 수 없듯, 라우터 내부에는 목적지 네트워크와 다음 정거장 주소들이 맵핑된 라우팅 테이블이 존재합니다. 

이 테이블을 어떻게 짤 것인가에 따라 정적/동적 라우팅으로 분리됩니다.
* **정적 라우팅 (Static Routing):** 
   네트워크 관리자가 "A 목적지로 갈 때는 무조건 B 포트로 보내라!"라고 수동으로 경로를 100% 고정 입력하는 방식입니다. 대규모망에서는 힘들지만, 외부로 나가는 출구(Gateway) 설정 등 소규모 단순 아키텍처 환경에서는 CPU 부하 없이 아주 안정적이고 강력합니다.
* **동적 라우팅 (Dynamic Routing):** 
   라우터들끼리 끊임없이 통신하며 현재 통신 단절(장애)이나 교통 체증 상태를 공유해 실시간으로 지도(라우팅 테이블)를 개정합니다. 우회 도로를 즉각 탐색하므로 대규모 복잡한 인터넷 구조에 필수적입니다.

## 3. 대표적인 동적 라우팅 프로토콜 생태계
라우터 장비들끼리 어떻게 상호작용하여 최적의 경로를 도출할 것인지에 대한 통신 규약 체계를 의미합니다.

### 내부 게이트웨이 프로토콜 (IGP - Interior Gateway Protocol)
단일 기업이나 기관 등 하나의 주체(AS - Autonomous System)가 통제하는 폐쇄된 인프라 망 **내부**에서 움직이는 규칙입니다.
- **RIP (Routing Information Protocol):** 
   목적지까지 가기 위해 거쳐야 하는 라우터의 갯수(Hop Count)가 적은 길을 최적의 길로 칩니다. 매우 직관적이고 오래된 레거시 방식이며, 경로 우회 한계치가 짧아 현대 대규모망에서는 도태되었습니다.
- **OSPF (Open Shortest Path First Protocol):** 
   현재 가장 인기 있는 엔진입니다. 단순히 라우터 갯수만 보지 않고, "어떤 도로가 대역폭(속도)이 더 넓은가, 지연율이 낮은가"를 수학적 알고리즘으로 전부 지도화(Link-State)하여 최단 경로를 산출합니다.

### 외부 게이트웨이 프로토콜 (EGP - Exterior Gateway Protocol)
서로 통제원이 완전히 다른 수많은 거대 망 단위(AS) **외부**를 서로 이어주어 오늘날의 구글, 아마존 데이터센터, ISP 등을 연결 및 통합하여 하나된 거대 인터넷(Internet) 망을 유지시키는 규약입니다.
- **BGP (Border Gateway Protocol):** 
   지구상의 유일한 외부 도메인 라우팅 시스템입니다. 인터넷의 척추(Backbone) 역할을 수행합니다. 각 AS 고유 번호를 활용하여 초대형 망끼리의 패킷이 무한 루프에 빠지지 않고 목적국에 도착하도록 제어합니다.
