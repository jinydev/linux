# 리눅스 파일 전송하기
## 0426. SCP (Secure Copy Protocol)
<hr/>   

**SCP(Secure Copy)** 명령어는 SSH 프로토콜 기반으로 로컬 컴퓨터와 원격 리눅스 서버 간에 파일 및 디렉터리를 **안전하게(암호화하여) 전송**하는 리눅스의 핵심 도구입니다. 

기존의 `ftp` 프로토콜은 데이터가 평문으로 전송되어 탈취(Sniffing) 위험이 있지만, `scp` 통신은 비밀번호 입력과 데이터 전송 과정의 모든 흐름이 완전히 암호화됩니다.

## 1. SCP 기본 문법

`scp`의 기본적인 문법은 로컬 파일 복사 시스템인 `cp`와 완벽히 유사하게 **"원본" "목적지"** 순서로 적습니다. 단, 원격지를 표현할 때 `계정명@IP주소:경로` 포맷을 사용합니다.

```bash
# scp [옵션] [복사할 원본] [붙여넣을 목적지]
```

## 2. 주요 사용 시나리오

1. **로컬 -> 원격 서버로 보내기(업로드)**
   ```bash
   scp my_file.txt john@192.168.0.100:/home/john/
   ```
   > 로컬의 `my_file.txt` 를 IP `192.168.0.100` 접속 계정 `john`의 `/home/john/` 디렉터리로 전송합니다.

2. **원격 서버 -> 로컬로 가져오기(다운로드)**
   ```bash
   scp john@192.168.0.100:/var/log/syslog ./
   ```
   > 서버에 있는 `syslog` 파일을 내 컴퓨터의 현재 디렉터리(`./`)로 가져옵니다.

3. **폴더 전체 전송하기 (옵션 주의) **
   ```bash
   scp -r config_folder/ john@192.168.0.100:/tmp/
   ```
   > 디렉터리단위로 내부에 든 모든 파일을 복사하려면 재귀적 옵션인 `-r`이 필수입니다.

4. **특정 포트 지정 시 (-P)**
   원격 서버가 기본 SSH 포트인 22번이 아닌, 2222번을 쓴다면 어떻게 할까요? SCP 전용 옵션인 대문자 `-P`를 명시해야 합니다. (SSH의 소문자 `-p`와 혼동주의)
   ```bash
   scp -P 2222 data.zip john@192.168.0.100:/home/
   ```
