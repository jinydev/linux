# 데비안/우분투 계열 방화벽 시스템
## 0424. UFW (Uncomplicated Firewall)
<hr/>

> **UFW**(Uncomplicated Firewall)는 "복잡하지 않은 방화벽"이라는 그 이름답게 데비안 및 우분투 리눅스 진영에서 기본적으로 제공하고 권장하는 매우 직관적인 방화벽 프론트엔드 제어 툴입니다.

레드햇 계열(CentOS, Rocky)이 `firewalld`를 전면으로 내세웠듯, 우분투 서버는 `netfilter` 커널의 `iptables` 규칙이 가진 극도로 난해하고 복잡한 명령 구조를 포장하여 누구나 CLI(Command Line Interface)에서 손쉬운 포트 개방과 폐쇄 명령어를 칠 수 있게 UFW 인터페이스를 전격 고안했습니다.

## 1. UFW의 핵심 보안 원칙 (Default Deny)

기본적으로 모든 방화벽 시스템의 대전제처럼, UFW를 시스템에 최초 활성화하는 그 순간 **모든 "외부 ➡️ 내부"로의 연결 시도는 일절 묵살되며 전면 차단(Deny)**됩니다. (단, 내부망에서 웹서핑을 하거나 요청을 보내는 아웃바운드 포트는 기본적으로 허용됩니다.)

따라서 방화벽 데몬 활성화 이전에 반드시 현재 로그인된 원격 SSH(포트 22) 세션을 허용 처리해 주지 않으면, 곧바로 세션이 쫓겨나고 영영 서버 접속이 불가능해지는 대형 사고가 자주 발생하므로 극도의 주의가 요구됩니다.

## 2. UFW 제어 및 룰 설정 가이드

### 단계 1: 포트 개방 (초기 설정)
아직 데몬을 시작하지 말고 문지기에게 22번 포트 허가를 명령합니다.

```bash
# 원격 제어 포트(SSH) 허용 명시 (22/tcp 와 동일)
sudo ufw allow ssh

# 특정 포트 및 통신 규약 허용 명시
sudo ufw allow 80/tcp    # HTTP 프로토콜을 위한 포트 열림
sudo ufw allow 443/tcp   # HTTPS 프로토콜 
```

### 단계 2: 방화벽 엔진 활성화 및 상태 체크
필수 포트를 확보했다면 데몬을 켜고 리스트를 확인합니다.

```bash
# 방화벽 엔진 켜기
sudo ufw enable

# 엔진 작동 상태 및 포트 적용 규칙 확인 리스트업
sudo ufw status
# 상세 현황(방향성 등)을 볼 땐 뒤에 verbose를 더합니다.
# sudo ufw status verbose
```

### 단계 3: 특정 포트 통신 차단 및 규칙 재정의 삭제
열려진 규칙을 폐기하거나 차단하는 방식입니다.

```bash
# 특정 포트로의 엑세스를 거부하기
sudo ufw deny 21/tcp     # FTP 원천 차단

# 기존에 허용명령을 내렸던 규칙을 규칙 리스트에서 지워버리기 
sudo ufw delete allow 80/tcp 

# 아이피 구역(Subnet) 기반 통신 차단 시나리오 예시
sudo ufw deny from 192.168.0.210
```

> **📌 시스템 추적 팁:** 
> UFW의 로깅 스위치 기능을 켜두면, 무단 접속 시도로 인해 드랍된 외부 트래픽 해킹 내역들이 `/var/log/ufw.log` 시스템 파일 등에 적재됩니다. 이를 추적하여 공격 아이피들을 색출할 수 있는 유용한 수단이 됩니다. (`sudo ufw logging on` 명령어 사용)
