# 리눅스 필수 생존 기본 명령어 요약

리눅스 CLI(Command Line Interface) 터미널 화면에서 마우스를 대체하는 가장 필수적인 핵심 명령어 10가지입니다.

> 💡 **Tip:** 모든 명령어는 뒤에 `--help` 옵션(예: `ls --help`)을 주거나 `man` 명령어(예: `man ls`)를 입력하면 거대한 설명서 매뉴얼을 볼 수 있습니다.

---

## 1. 파일 시스템 탐색 명령어

* **`pwd` (Print Working Directory):** 내가 지금 우주 미아가 되지 않도록, 현재 서 있는 절대 경로 위치를 찍어줍니다. (예: `/home/ubuntu`)
* **`cd` (Change Directory):** 원하는 폴더 위치로 이동합니다.
  * `cd /var/log` : 절대 경로로 바로 이동
  * `cd ~` 또는 그냥 `cd` : 내 계정의 아늑한 홈 디렉터리로 즉시 복귀
  * `cd ..` : 내가 속해 있는 현재 폴더의 바로 위(부모) 상위 폴더로 이동 (백스페이스 같은 효과)
  * `cd -` : 직전에 머물렀던 과거 경로로 이동 (뒤로 가기)
* **`ls` (List Segments):** 현재 폴더 안의 파일과 폴더 목록을 시각적으로 뿌려 확인합니다.
  * `ls -l` : 파일 크기, 권한(rwx), 생성일 등 상세 정보 출력
  * `ls -a` : `.` 으로 시작하는 숨김 파일까지 모조리 강제 출력
  * `ls -al` : 숨김 파일을 포함해 모든 정보를 리스트업 (가장 많이 씁니다)
  * `ls -rt` : 생성 시간순(Time)으로 정렬하되 거꾸로(Reverse) 정렬하여 방금 제일 최신에 생성된 파일을 맨 밑으로 오게 합니다.

---

## 2. 파일 및 디렉터리 조작 명령어

* **`mkdir` (Make Directory):** 새 폴더를 생성합니다.
  * `mkdir -p /app/data/logs` : 중간에 app이나 data 폴더가 없으면 에러를 뿜는 게 아니라, 없는 뼈대를 싹 다 연달아 만들어버립니다.
* **`touch`:** (빈 깡통) 크기가 0바이트인 텅 빈 파일을 즉시 만들거나, 이미 있는 파일일 경우 수정 시간을 현재 시간으로 갱신해 줍니다.
* **`cp` (Copy):** 파일이나 폴더를 복사합니다.
  * `cp 원본파일 목적지파일` : 단일 파일 복사
  * `cp -r 원본폴더 목적지폴더` : 폴더 안에 수만 개의 파일이 있더라도 재귀적(Recursive)으로 싹 긁어서 통째로 복사합니다. (디렉터리 복사 시 `-r` 옵션 필수)
* **`mv` (Move):** 파일을 이동시키거나, 이름을 바꿀 때(원위치에서 다른 이름으로 보냄) 사용합니다.
* **`rm` (Remove):** 파일을 완전히 사살(삭제)합니다. 윈도우 휴지통 같은 복구가 안 되니 매우 신중해야 합니다.
  * `rm -r 디렉터리` : 폴더 통째 지우기
  * `rm -rf 디렉터리` : 묻지도 따지지도 않고 디렉터리와 내부 수천 개 파일을 강제 폭파합니다. (초보자 주의 명령어)

---

## 3. 출력 및 기타 유틸리티 명령어

* **`cat` (Catenate):** 텍스트 파일 안의 글자 내용을 화면에 바로 던져 뿌려버립니다.
  * 분량이 엄청나게 길면 스크롤이 위로 사라지므로, `cat file1 | more` 또는 `less file1` 같은 조합으로 한 페이지씩 잘라봅니다.
* **리다이렉션 (`>` , `>>` , `<` ):** 모니터 화면으로 튀어나갈 글자 등 출력을 잡아채어 파일로 쏠 수 있습니다.
  * `ls -al > result.txt` : 덮어쓰기. 새로 result 파일에 저장합니다.
  * `echo "hello" >> result.txt` : 이어쓰기. 기존 결과 값 뒤에 데이터를 계속 누적시킵니다.
* **`alias` (별명 부여):** 수십 자가 넘어가는 끔찍하게 긴 명령어나 귀찮은 옵션을, 내가 쓰기 편한 한두 자루의 단어로 정의해 버립니다.
  * (등록) `alias ll='ls -alF'` -> 이제 터미널에 `ll` 만 치면 저 긴 옵션 명령이 실행됩니다.
  * (해제) `unalias ll`
