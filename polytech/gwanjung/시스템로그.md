# 리눅스 시스템 로그 (System Log)와 분석 추적

서버 엔지니어에게 리눅스의 **로그(Log)**는 항공기의 블랙박스와도 같습니다. 해커가 언제 침투했는지, 서버가 왜 갑자기 죽었는지 파악하려면 반드시 `/var/log` 디렉터리의 텍스트 파일들을 뒤져야 합니다.

과거에는 `syslog`라는 데몬이 기록을 쌓았으나, 최근의 배포판들은 기능이 수십 배 강력해진 데이터베이스 연동형 패키지인 **`rsyslog`**를 운영 및 탑재하고 있습니다.

## 1. 8대 핵심 로그 파일 (`/var/log/`)
리눅스 사고 조사 시 반드시 조회해 봐야 할 주요 파일 경로입니다. 이 파일들은 시스템 관리자(`root`) 권한으로만 열람할 수 있습니다.

1. **`messages` (우분투에서는 `syslog`):** 커널 및 시스템 데몬들이 남기는 전체 시스템 표준 로그. 가장 거대한 데이터가 쌓입니다.
2. **`secure` (우분투에서는 `auth.log`):** `su`, `sudo`, `ssh` 등 인증 및 접속 시도와 권한 관리 성공/실패 여부를 낱낱이 기록하는 **핵심 보안 파일**입니다.
3. **`dmesg`:** 서버가 부팅될 때 커널이 뱉어낸 무수히 많은 전장 하드웨어 감지 메시지. 하드 드라이버 인식 실패 등을 추적합니다.
4. **`maillog` (또는 `mail.log`):** `postfix`, `sendmail` 시스템 내부에서 오고 간 메일 작업 기록.
5. **`cron`:** 예약 스케줄러인 `cron`이 지정된 시간에 파일을 백업했는지 등의 자동화 동작 이력이 남습니다.
6. **`wtmp` & `btmp`:** 터미널과 접속의 모든 로그인 상태(성공, 시간 등)와 `btmp` (실패=Bad login)를 기록합니다. 이 두 파일은 바이너리로 암호화돼서 `cat`으로 볼 수 없고 전용 조사 명령어를 써야 합니다.

## 2. 보안 추적 명령어 (접속 기록) 
해커나 악의적 사용자의 동선을 파헤치는 추적 명령어 3형제입니다.

### 1) 최근 모든 로그인 이력 ( `last` )
바이너리로 기록된 `/var/log/wtmp` 파일을 번역해서, 유저들의 접속/재부팅 시간표를 화려하게 출력합니다.
```bash
# ihduser 계정이 로그인한 시간대 추적
last ihduser

# 시스템을 시스템 매니저가 재부팅한 가장 최근 이력 2줄만 확인
last -2 reboot
```

### 2) 사용자별 가장 마지막 방문 도장 ( `lastlog` )
`/var/log/lastlog` 파일을 읽어들여, 시스템 내 등록된 모든 계정 유저들이 각자 "가장 마지막으로いつ 방문(로그인)했는지" 여부만 깔끔히 보여줍니다. 해킹된 휴면 계정 감지에 특효약입니다.
```bash
# bob 계정이 최근에 접속한 적이 있는지 추적
lastlog -u bob
```

### 3) 실패한 암호 도전 이력 - 해커 침투 탐지 ( `lastb` )
`/var/log/btmp` 파일을 번역합니다. 무차별 암호 대입(Brute-force) 공격이 들어왔는지 확인하는 보안 관리자의 필수 명령어입니다. (root 권한 필수)
```bash
# 누군가 로그인을 시도하다가 비밀번호가 틀려 튕겨 나간 가장 최근 3번의 이력 출력 
sudo lastb -3
```
