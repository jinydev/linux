# 시스템 정보 조회 및 관제 명령어

가동 중인 리눅스 서버에 접속했을 때 OS 및 하드웨어 스펙, 부하 상태 등을 한눈에 파악해 볼 수 있는 모니터링 명령어 세트입니다.

## 1. 운영체제 및 핵심 하드웨어 스펙

* **`uname -a` (OS 커널 정보):** 
  현재 설치된 리눅스의 이름, 네트워크 호스트명, 커널의 릴리즈 코어 버전, CPU 아키텍처(x86_64, ARM 등)를 한 번에 주루룩 출력해 주는 나침반입니다.

* **`lscpu` (CPU 족보):**
  소켓 수, 물리 코어 개수, 스레드 수, 캐시 메모리 등 CPU의 물리적 아키텍처 상태를 아주 직관적으로 보여줍니다. "이 서버가 몇 코어짜리인지" 확인할 때 1순위로 칩니다.

* **`dmidecode` (바이오스 및 부품 스펙 덤프):** (루트 권한 필요)
  메인보드(Baseboard), 램(Memory)의 꽂혀있는 슬롯 상태와 클럭 속도, 섀시 모델명 등 사람이 확인하기 힘든 메인보드 DMI 테이블 정보를 파헤쳐줍니다. 메모리 증설 여부를 볼 때 필수입니다. 

---

## 2. 서버 부하 및 리소스 (메모리, 디스크)

* **`uptime` (최초 구동 파악):**
  가장 많이 쓰는 명렁어. 서버가 켜진 이후로 재부팅 없이 **며칠(Days)** 동안 살아서 돌아가고 있는지, 그리고 1/5/15분 치 **평균 부하량 (Load Average)** 수치를 띄워 시스템 과부하를 파악하게 합니다.
  * `uptime -p` : 좀 더 예쁜 문장(Pretty) 형태로 가동시간 노출 (예: `up 1 weeks, 3 days`)

* **`free -h` (RAM 메모리 상태):**
  전체 물리 메모리 여유분, Swap(다락방) 가상 메모리 여유분, 현재 프로세스나 OS 캐시가 집어삼킨 램 사용량을 메가/기가 등 사람이 읽기 편한 단위(`-h`, human-readable)로 출력합니다.

* **`df -h` (하드 디스크 용량):**
  루트 디렉터리(`/`) 및 모든 마운트된 볼륨들이 보유한 총 용량 100% 중 몇 퍼센트의 디스크가 꽉 찼는지 파악합니다. 이것도 `-h` 옵션을 안 쓰면 바이트 숫자가 길어져 읽기가 불가능합니다.

## 3. 네트워크 대역폭(IO) 및 포트

* **`ifconfig` / `ip addr`:**
  시스템의 랜카드(네트워크 인터페이스)들에 할당된 사설 IP, 공인 IP 상태값 및 MAC 주소를 파악합니다. 최신 리눅스에선 `ifconfig`가 죽어가고 `ip a` 가 권장 표준입니다.
  * 옵션 `-a` : 중지된 랜카드까지 전부 출력합니다.

* **`sar -n DEV 1` (네트워크 메트릭):**
  sysstat 패키지의 꽃입니다. 1초 간격으로 내 서버의 랜카드(eth0, ens33 등)에서 송수신되는 패킷의 수와 네트워크 Byte 대역을 CCTV처럼 출력해 주어, 혹시 외부에서 디도스(DDoS) 트래픽이 꽂히고 있지 않은지 의심될 때 사용합니다.
