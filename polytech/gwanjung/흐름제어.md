# 쉘 스크립트 흐름 제어: `case` 분기문

Bash 쉘 스크립트 코딩을 할 때, `if` 와 `else if` 가 너무 많이 중첩되면 지저분한 코드가 됩니다.
입력으로 들어온 특정한 문자열의 값(Value)이 A냐, B냐, C냐에 따라 다이렉트로 여러 갈래의 스위치를 눌러주는 직관적인 다중 조건문이 바로 **`case` 문장** (C/Java 언어의 `switch-case`와 동일)입니다.

## `case` 구문 구조 
아래는 유저가 파라미터 인수로 입력한 값에 맞추어 서버 데몬의 행동 지침 구조를 선별하는 전형적인 포맷입니다. 리눅스 `/etc/init.d/` 밑에 깔린 거의 수백 개의 시스템 컨트롤 부팅 스크립트들이 100% 이 구조를 쓰며 돌아갑니다.

```bash
#!/bin/bash
# 파일명: service_control.sh

# $1 은 스크립트 뒤에 유저가 날린 첫 번째 단어를 의미합니다.
# ex) ./service_control.sh start
case "$1" in
    start)
        echo "서비스 데몬을 구동합니다... (Starting)"
        # systemctl start 명령 등 배치...
        ;;
    stop)
        echo "서비스를 중지 및 파기합니다... (Stopping)"
        # kill 명령 등 배치...
        ;;
    restart)
        echo "서비스를 재부팅합니다... (Restarting)"
        ;;
    *)
        # 별표(*)는 위 start, stop이 아닌 아무 말 대잔치를 입력했을 때
        # 즉, '기본(Default) 예외 값' 처리 구간입니다.
        echo "도움말 사용법: $0 {start|stop|restart} 중 하나를 입력하세요."
        exit 1
        ;;
esac

exit 0
```

### [ 문법 핵심 정리 ]
1. 쉘 스크립트의 `case`는 반드시 역순 글자인 **`esac`**로 문맥의 방어막 블록을 닫아야 에러가 안 납니다.
2. 매칭 시킬 단어 문자열 패턴 옆엔 우측 소괄호 닫기 `)` 기호를 박습니다.
3. 해당 처리 구간이 끝나면 자바의 `break;` 처럼 무조건 더블 세미콜론 **`;;`**을 찍어주어야 다음 패턴으로 흘러가지 않고 분기문을 완전 탈출합니다!
4. 최하단 예외 구속은 별표 와일드카드 `*` 를 이용하며, 매뉴얼 출력 에러코드로 퇴장(`exit 1`) 시키는 것이 모범 쉘 아키텍처입니다.
