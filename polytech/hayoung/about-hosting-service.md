# 웹 호스팅(Hosting) 서비스 생태계

내가 만든 웹사이트 코드를 24시간 내 방 PC를 커져서 전 세계에 서비스하려면 컴퓨터 과열, 엄청난 전기세 부과, 해커의 무차별 IP 공격 등 지옥이 펼쳐집니다.  
따라서 항온·항습 시스템이 갖춰진 거대한 데이터 센터(IDC) 전문가들에게 **24시간 켜져 있는 서버 컴퓨터의 "본체 일부 공간"을 월세를 내고 임대하는 비즈니스**를 가리켜 **호스팅(Hosting)** 서비스라고 부릅니다. 

서버 운영체제로서 보안성이 높고 무료인 'Linux'가 압도적으로 많이 쓰이므로 보통 호스팅은 **리눅스 호스팅**을 의미합니다. 규모에 따라 3가지 세대로 나뉩니다.

---

## 1세대: 웹 호스팅 (공유 호스팅, Shared Hosting)
> "거대한 고시원 방 한 칸 임대"

* **특징:** 서버 컴퓨터 1대 (아파치, MySQL이 세팅됨)에 수백 명의 입주자(게시판, 블로그 주인)가 동시 입주하여 사용합니다. 
* **장점:** 매우 쌉니다. (수천 원 대). DB 연동, 웹 서버 세팅을 몰라도 클릭 한 번으로 게시판(워드프레스 등)이 설치됩니다. 초보용입니다.
* **단점:** 옆방 입주자가 쇼핑몰 대박이 터져서 서버 CPU를 혼자 100% 잡아먹어 버리면, 내 홈페이지도 따라서 툭툭 끊기고 마비되는 최악의 단점이 있습니다. (관리자 권한 Root 도 제공되지 않습니다.)
* **대표 업체:** 카페24(Cafe24), Bluehost 등

## 2세대: 단독 서버 호스팅 (Dedicated Server)
> "마당 있는 전원주택 통째로 임대"

* **특징:** 아예 물리적인 컴퓨터 본체 1대를 나 혼자만 오롯이 씁니다. 최고 관리자 권한(Root)이 제공됩니다.
* **장점:** 엄청난 트래픽 폭주가 발생해도 성능이 요동치지 않습니다.
* **단점:** 초기 장비 구축비, 세팅 유지보수, 백업 등 운영에 관한 모든 책임을 엔지니어가 짊어져야 하며, 1년에 수백만 원 대의 비용이 깨집니다.

## 3세대: 클라우드 호스팅 (Cloud Computing / VPS)
> "레고처럼 언제든 늘리고 줄일 수 있는 마법의 고급 아파트"

* **특징:** 현대 IT 인프라의 알파이자 오메가입니다. 서버는 가상의 환경에 떠 있으며, 평시에는 최소 비용만 내다가 사용자가 폭주하면 마우스 클릭 몇 번으로 컴퓨터 대수와 메모리를 100배 이상 실시간으로 팽창(Scale-out) 시킵니다.
* AWS(Amazon Web Services), GCP 등은 전 세계 인프라를 장악한 대규모 클라우드 플랫폼이며, 개개인 개발자는 비교적 단순하고 개발 친화적인 VPS(Virtual Private Server) 호스팅 업체를 애용합니다.
* **대표 업체:** AWS EC2, DigitalOcean, Vultr, Linode 등
