# IP 주소 체계 (IPv4, 서브넷마스크, 서브네팅)

인터넷에 연결된 모든 기기는 우체국 주소와 같은 고유한 논리적 식별자를 부여받습니다. 이를 **IP (Internet Protocol)** 주소라고 합니다.

## 1. IPv4 주소 이해하기
가장 보편적인 IPv4는 숫자 4묶음(예: `192.168.0.10`)으로 표현됩니다. 내부적으로는 각각 8비트(0~255)로 이루어진 4개의 옥텟(총 32비트)로 구성되어 있습니다.
IP 주소는 크게 "나의 소속 동네"를 뜻하는 **N (네트워크 주소)** 부분과, 그 동네 안의 어느 "번지 수"인지 가리키는 **H (호스트 주소)** 부분으로 나뉩니다.

---

## 2. IP 낭비의 재앙 (Classful 방식)과 극복 (Classless)

과거 IP를 주먹구구식으로 나눠줄 때는 **Class**라는 무식하게 고정된 칸막이 방식을 도입했습니다.
* **A 클래스:** `N.H.H.H` 구조. IP를 무려 1,600만 개나 주는 괴물 클래스. 소수 기업이 독점했습니다.
* **B 클래스:** `N.N.H.H` 구조. 6만 5천 여대 할당.
* **C 클래스:** `N.N.N.H` 구조. 254대밖에 안 주는 쪼잔한 클래스. PC방 등에서 씁니다.

### 클래스 붕괴와 서브넷 마스크(Subnet Mask)의 등장 
회사에 PC 300대가 필요해서 C 클래스(254개 제공)로는 택도 없으니 울며 겨자 먹기로 B 클래스(65,000개 수용)를 구매했습니다. 이로 인해 쓰지 않는 64,700여 개의 황금 IP가 공중에 쓰레기처럼 버려지는 낭비 사태가 벌어졌습니다! 전 세계 43억 개의 IP는 삽시간에 고갈 위기에 처합니다.

그래서 고정된 Class 체계를 완전히 폭파(Classless) 시켜버리고, **필요한 만큼 주소를 자유자재로 슬라이스** 해서 쪼개 쓸 수 있는 그물통 치수 도구가 등장했는데, 이것이 바로 **서브넷 마스크 (Subnet Mask)** 입니다.

> **작동 원리 (마스킹):** IP 주소 위로 `255.255.255.0` (가려지는 검은색 잉크) 체계를 덮어씌워서(And 비트 연산), 마스킹된 부분까지가 '네트워크 동네(N)'이고 뒷부분 남은 공간이 '부여할 수 있는 PC 대수(H)'로 가변적으로 산출되는 원리입니다. (이를 기호로는 서브넷 프리픽스 `/24` 같이 표현합니다)

## 3. 서브네팅(Subnetting)의 수학적 분할

거대한 하나의 IP 도로를 여러 개의 작은 골목길 망으로 칼집을 내어 파티션을 나누는 기법입니다. (부서망 분리, 브로드캐스트 부하 축소 등)

**[예시: 부서별 분할]** 
C클래스 대역 `192.168.10.0` 이 있으며, 회사 기획팀과 개발팀 네트워크를 반으로 쪼개 자르고 싶을 때?

1. 기본 C클래스의 서브넷은 `/24`이며 256대의 PC를 담습니다.
2. 이 대역을 2개로 쪼개기 위해 서브넷 마스크를 1비트 앞으로 옮겨 `/25` (`255.255.255.128`) 로 조작합니다.
3. 그러면 256개의 자리가 반으로 뚝 부러져 두 개의 독립적인 네트워크 구역이 탄생합니다.
   * **[기획팀 서브넷]** 네트워크 대역: `192.168.10.0 ~ 127` (총 128대 사용 공간)
   * **[개발팀 서브넷]** 네트워크 대역: `192.168.10.128 ~ 255` (나머지 128대 사용 공간)
4. 만약 각 대역에 묻지마 전체 발송을 하는 '브로드캐스트(Broadcast)' 전파를 쏴도 절대 서로의 부서 담장을 넘어가 장애를 유발하지 않습니다.
