# 우분투 리눅스 - 원격 접속의 진화 (SSH 서버 구축) 

리눅스 시스템은 서버룸(IDC)에 처박혀 있는 쇳덩이 컴퓨터이기 때문에, 여러분의 쾌적한 윈도우/맥북 개인 PC에서 원격으로 검은 터미널 화면에 접속해 관리해야만 합니다. 이 원격 통신의 기술은 시대를 거쳐 하나로 통일되었습니다.

---

## 1. 텔넷 (Telnet): 현재 엄격히 금지된 구시대의 유물

과거의 전통적인 원격 접속 도구였습니다. 하지만 치명적인 설계 결함으로 현대 IT 인프라 규정상 **사용이 아예 불법 수준으로 금지된 프로토콜**입니다.

* **절대 금지 사유 (패킷 스니핑 보안 이슈):** 통신하는 텍스트가 1%의 암호화도 없이 날것(Plaintext)으로 태평양 바다를 건너옵니다. 해커가 통신망 중간에 돋보기를 갖다 대면 여러분이 키보드로 친 "로그인 아이디: root, 비밀번호: 1234!!!" 가 영어 소설 읽듯이 100% 해독되며 즉시 해킹 붕괴로 이어집니다.

*(기존의 텔넷 구축 가이드, `telnet-server` 설치 내용 등은 학습 가치가 오히려 혼동과 재앙을 초래하므로 본 가이드에서 전면 폐기/삭제 조치했습니다.)*

---

## 2. OpenSSH 서버: 현대 인프라의 마스터 솔루션

결국 텔넷의 평문 보안 사고를 막기 위해 **SSH(Secure Shell)**라는 절대적인 보호 규약이 도래했습니다. 오가는 텍스트를 RSA/ECDSA 등 군사급 암호화로 갈가리 찢고 섞어서 보내므로, 해커가 훔쳐봐도 쓰레기 값만 뜹니다.

### 👉 우분투에 SSH 서버 설치 및 포워딩 가이드

1. **내 가상머신(Ubuntu)에 SSH 자물쇠 및 서비스 데몬 설치**
```bash
sudo apt update
sudo apt install openssh-server

# 부팅될 때 알아서 백그라운드에서 살아서 돌게 시스템 등록
sudo systemctl enable ssh
sudo systemctl start ssh
```

2. **포트 포워딩 (Port Forwarding)** 
외부(윈도우 PC)에서 가상머신(VirtualBox)의 내부 사설 IP망으로 들어갈 수는 없습니다. 방화벽 문제와 NAT의 차단 벽 때문입니다. VirtualBox 네트워크 설정에서 `포트 포워딩`을 들어가, 윈도우 PC의 특정 포트(예: 2222)를 찌르면 가상머신 리눅스의 22번(SSH 전용) 포트로 구멍을 뚫어 전달해 주도록 매핑해야 합니다.

3. **윈도우(Client)에서 리눅스로 진입!**
예전에는 `PuTTY` 같은 프로그램을 별도 설치했지만, 윈도우 10/11은 기본적으로 터미널(cmd)에 `ssh`가 내장되어 있습니다.
```bash
# 윈도우 커맨드라인에서 바로 입력 (포트 2222를 뚫어놓은 예시)
ssh -p 2222 yulim@127.0.0.1
# 비밀번호를 치면 암호화 터널이 구축되며, 내 윈도우가 리눅스 머신으로 완전히 변신합니다.
```

## 3. 보충: 그래픽스 원격제어 (VNC)
터미널의 검은 화면(CLI) 말고, 마우스로 움직이는 그래픽 화면(GUI) 자체를 통째로 원격 송출 받고 싶을 때 쓰는 데몬입니다. (윈도우의 '원격 데스크톱 연결'과 똑같습니다.)
* **특징:** 화면 픽셀 데이터를 무식하게 다 통신으로 쏴주어야 해서 속도가 굉장히 느리고 엄청나게 무거워 렉이 심합니다. 따라서 현지 서버 마스터들은 특수 설치 목적 외에는 VNC 그래픽 포트를 모두 잠가버리고 100% SSH 터미널로만 작업하는 것이 국룰입니다.
