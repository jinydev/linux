# 리눅스 프로세스 (Process) 통제 완전 정복

우리가 리눅스 창에 명령어를 칠 때마다 내부에서는 수많은 프로그램 모듈이 메모리에 올라가서 자리를 잡고 줄서기를 하며 작업을 수행합니다. 이렇게 실행되어 펄떡임이 유지되고 있는 형태를 **프로세스(Process)**라 부르며, 이 위태로운 시스템의 작업 흐름을 통제하고 제어하는 방법을 배웁니다.

---

## 1. 운영체제 체계 내 프로세스의 족보
내가 서버를 켜면(구동), OS의 심장인 커널(Kernel)은 가장 먼저 **PID 1번** 지휘자인 `init` (현대 리눅스엔 `systemd`) 이라는 뿌리 프로세스를 깨웁니다. 
이제 1번 조상님인 `init`이 다른 서비스들을 자식처럼 낳으며(분기) 수백 개의 스크립트 트리를 엽니다. 모든 프로세스는 고유의 민증 번호인 **PID(Process ID)**를 각자 부여받아 관리됩니다.

## 2. 작업 상태 감시와 추적 (`ps`, `top`)

### `ps` (Process Status) 명령어
살아있는 프로세스들의 상태 사진을 '찰칵' 직찍해서 한 장 찍어주는 스냅샷 명령어입니다.
* `ps ux`: 내가 현재 터미널에서 실행시킨 종속 작업 목록 확인
* `ps aux` (가게부 전체 스캔): **가장 많이 쓰는 옵션.** 시스템에서 다른 유저가 돌리는 프로세스까지 싹쓸이하여, PID, 메모리 점유율, 상태값(STAT) 기호를 출력합니다.

> **💡 STAT (프로세스 상태 기호)**
> - `R (Running)`: 미친 듯이 현재 CPU 할당을 받아 실행 중인 상태.
> - `S (Sleep)`: 조건 발생 전까지 코를 골면서 자율 휴면 상태 대기.
> - `Z (Zombie)`: **경계 대상.** 프로그램은 죽었으나 부모 프로세스가 시체를 수습해주지 않아 시스템 메모리 목록만 차지하고 있는 기형적인 **좀비 프로세스**.

### `top` 명령어 
`ps` 명령어가 죽어있는 멈춘 스냅샷 사진이라면, `top`은 **실시간으로 변동하는 시스템 감시 CCTV 액션캠**입니다. (3초마다 갱신되며, `q`를 눌러 탈출합니다. 더 화려하고 직관적인 서드파티 툴인 `htop`이 요즘 더 선호됩니다.)

## 3. 유체 이탈 제어 (`fg`, `bg`, `jobs`)

단일 터미널에서 명령을 돌리다 꼼짝도 못 하고 마냥 쳐다봐야 하는 사태를 막는 통제 명령어입니다.

* **`Ctrl + Z` (기절시키기):** 화면 한가운데 켜져서 나를 가리던 프로그램(예: 압축풀기, vim)을 강제 기절시켜 뒷방(백그라운드)으로 처박아 대기 상태로 만들고, 내게 명령어 프롬프트 창을 다시 쥐여 줍니다.
* **`jobs`:** 지금 화면 뒤로 처박혀서 기절해있는 리스트(Job 번호)를 보여줍니다.
* **`bg %1`:** 뒤에 기절해있는 1번 작업에게 전기 충격을 가해 화면을 띄우지 않고 뒤에서 조용히 계속 일을 돌리라고(Background run) 시킵니다.
* **`fg %1`:** 뒤에 돌아가던 1번 작업을 다시 내 눈앞의 화면(Foreground) 위로 멱살을 잡아 올려놓습니다.

## 4. 제거 명령의 무덤, Kill 시그널

`kill` 명령어는 이름처럼 프로세스를 무조건 사살하는 살인마가 아닙니다. 정확한 비유는 **"운영체제가 프로세스에게 쏘는 신호탄(Signal)"**입니다.

1. **공손한 종료 요청 (`kill -15 [PID]` 또는 그냥 `kill`):** 
   해당 PID 프로세스에게 "마무리 정리하고 천천히 알아서 죽으셈"하고 젠틀하게 시그널(SIGTERM)을 보냅니다.
2. **사형 선고 - 묻지마 폭격 (`kill -9 [PID]`):** 
   프로세스가 렉에 걸려 -15번의 젠틀한 말을 듣지도 않고 먹통일 때, 운영체제 차원에서 묻지도 따지지도 않고 **강제 삭제 파쇄**시켜버리는 철퇴 신호(SIGKILL)입니다. 데이터 유실이 크므로 최후의 수단입니다.
3. **학살 (`killall 프로세스이름`):** 
   PID 번호를 찾기 귀찮을 때, 예를 들어 `killall apache2` 와 같이 이름으로 검색해 동일한 이름의 모든 프로세스를 몰살시켜버립니다.
