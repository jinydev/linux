# Bash 스크립트: for 반복문 완벽 정복

반복적인 서버 관리 작업이나 문자열 리스트를 순차 처리할 때, Bash의 **`for` 루프명령어**를 활용하면 작업 시간을 획기적으로 줄일 수 있습니다. Bash에서는 크게 두 가지의 `for` 문법을 지원합니다.

---

## 1. bash 전통 쉘 형식 (문자열 목록 순회)

단일 변수를 여러 개의 단어(문자열, 파일경로 등) 목록 속에서 순서대로 넘겨가며 순회하는 고전적이고 가장 많이 쓰이는 방식입니다.

### [기본 문법 구조]
```bash
for 변수명 in [단어목록]; do
    # 반복해서 수행할 명령어
done
```

### [실무 응용 예제]
가장 많이 쓰이는 터미널 한 줄짜리 반복 구문입니다.
```bash
# A, B, C, D 문자를 하나씩 i에 담고 돌면서 화면에 찍기
$ for i in A B C D; do echo $i; done
A
B
C
D

# (응용) 특정 폴더 안의 모든 .log 파일의 이름을 백업으로 바꾸기
$ for file in *.log; do mv "$file" "${file}.bak"; done
```

---

## 2. C 언어 스타일 형식 (숫자 조건 순회)

단순 단어 순회가 아니라 숫자(Index)를 1부터 100까지 증가시키거나 짝수 단위로 뛰어야 할 경우, 최신 Bash에서는 일반 C 프로그래밍 언어와 똑같은 형태의 for 문을 제공합니다. 

단, 괄호가 반드시 **이중 소괄호 `(( ))`**임을 명심해야 합니다.

### [기본 문법 구조]
```bash
for (( 초기식; 조건식; 증감식 )); do
    # 반복해서 수행할 명령어
done
```

### [실무 응용 예제]
```bash
# 0부터 4까지 5번 회전하는 카운터 스크립트
$ for (( i=0; i<5; i++ )); do
>   echo "현재 카운트는: $i"
> done
현재 카운트는: 0
현재 카운트는: 1
현재 카운트는: 2
현재 카운트는: 3
현재 카운트는: 4
```

> **🔥 팁 (while문과의 원리 비교)**
> C 형식의 for문은 내부적으로 다음의 `while` 구조와 100% 동일하게 동작합니다. 
> 초깃값을 밖에서 준 뒤 들어와 조건식으로 검사하고, 명령어가 끝나면 증감식을 돌린 후 다시 조건으로 올라가는 메커니즘입니다.
