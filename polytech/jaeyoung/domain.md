# 인터넷의 간판: 도메인(Domain Name)

인터넷으로 서버를 찾아가기 위해서는 반드시 `172.217.166.78` 같은 숫자로 된 IP 주소를 외워야 합니다. 이를 인간이 기억할 수 있게 **의미 있는 영문이나 한글 문자로 매핑(변환)해놓은 가상의 주소**가 바로 도메인(Domain)입니다.

(DNS 서버가 이 도메인을 IP로 해독해주는 역할을 합니다.)

---

## 도메인의 3단계 역트리 구조 체계

도메인은 맨 끝단(루트)부터 앞으로 차근차근 계층을 밟아 내려가는 역트리(Inverted Tree) 구조로 되어 있습니다. `www.google.kr.` 을 예시로 분석해 볼 수 있습니다.

### 1단계: 최상위 도메인 (TLD, Top-Level Domain)
가장 맨 끝자리(`.kr` 또는 `.com`)에 위치하며, 도메인의 '목적'이나 '소속 국가'를 가장 크게 분류하는 대분류입니다.

| TLD 구분 | 대표 종류 및 의미 |
| :-- | :-- |
| **gTLD (일반 목적)** | `.com`(기업), `.net`(네트워크), `.org`(비영리), `.edu`(미국교육) |
| **ccTLD (국가 코드)** | `.kr`(한국), `.jp`(일본), `.de`(독일), `.us`(미국) |

### 2단계: 차상위 도메인 (SLD, Second-Level Domain)
최상위 도메인 바로 좌측에 붙으며, **등록한 조직의 실체 형태**나 목적을 더 세분화하는 중분류입니다. 
* 한국(`.kr`)의 경우 대표적으로 `.co.kr`(기업 영리회사), `.go.kr`(국가 정부기관), `.ac.kr`(대학교) 따위로 나뉩니다.
* 일반 TLD(`.com`)를 쓴다면 이 차상위 자리에 곧바로 자율 명칭(google)이 오기도 합니다. 

### 3단계: 도메인 이름 (Domain Name)
우리가 직접 돈을 내고 가비아 등에서 자유롭게 작명해 사는 **자율적인 고유 이름**입니다.
* `naver`, `google`, `daum` 등 기업의 정체성이 담기는 상표와도 같습니다.

---

### 서브 도메인(Sub-Domain)과 호스트명
우리가 흔히 치는 맨 앞의 `www`는 사실 도메인 소유자가 자유롭게 나누어 쓰는 가상의 구역, 즉 '호스트명(Host Name)'입니다. 관리자는 동일한 구글 도메인 안에 `mail.google.com` 이나 `m.google.com` (모바일) 처럼 서버의 역할을 분리하기 위해 서브 도메인을 무한정 생성하여 라우팅 할 수 있습니다.
