# 파일 소유권 대장 파일 관리: chown 과 chgrp

리눅스에서는 아무리 허접한 텍스트 파일 쪼가리 하나라도, 무조건 이 파일을 낳은 '창조주(소유자)'와 '팀(그룹)' 두 개의 간판 명패가 무조건 박혀있습니다. 이 집주인 명패 자체를 아예 다른 사람에게 영구적으로 넘겨버리는 명령어들을 알아봅니다.

**(주의: 타인의 파일을 뺏거나 내 파일을 넘기는 압류/양도 행위이므로, 이 권한 박탈은 절대신인 `root`(sudo) 관리자 뱃지를 달았을 때만 통용됩니다.)**

---

## 1. chown (CHange OWNer) : 모든 소유권 변환

특정 파일이나 디렉터리의 주인 계정과 담당 그룹을 모두 내 마음대로 포맷팅해 줍니다. 
`ls -al`을 쳤을 때 나타나는 두 개의 이름 덩어리 영역을 콜론(`:`) 으로 구분해 새로 세팅합니다.

### 문법 규칙
```bash
# 기본 사용 포맷
chown [유저명]:[그룹명] [타겟파일혹은폴더]
```

### 실무 응용 예제 
```bash
# 1. 파일의 소유자만 강제로 root 영감님에게 넘겨버림 (콜론 생략)
$ sudo chown root test.txt

# 2. 파일의 소유자는 'myuser'로, 팀 그룹 간판은 'mygroup'으로 완벽히 양도함
$ sudo chown myuser:mygroup myfile.txt

# 3. [가장 많이 쓰는 심화 응용 - 대문자 R 파급 효과]
# 특정 'myfiles' 폴더 껍데기뿐만 아니라 그 속에 천만 개의 폴더와 파일이 들어있더라도, 
# 일일이 작업할 필요 없이 '모든 하위 파일'들까지 전부 다 주인 소유권을 myuser:mygroup 으로 물들여버립니다. (Recursive)
$ sudo chown -R myuser:mygroup /var/www/myfiles
```
*(주의사항: 소문자 `-r` 이 아니라 대문자 **`-R`** 옵션입니다. 리눅스 옵션 대소문자는 엄격히 다릅니다.)*

---

## 2. chgrp (CHange GRouP) : 그룹 멤버십만 단독 변환

소유자는 건드리지 않고 가만히 보존해 둔 채로, 권한 공유의 팀 단위인 '그룹 이름표'만 살짝 갈아 끼울 때 사용하는 특수 명령어입니다.
* 물론 이 명령어 쓸 바에야 보통 `chown :newgroup` 처럼 공백 활용법으로 `chown` 을 한 큐에 쓰는 사람들도 많습니다.

### 문법 및 예제
```bash
# 1. 대상 파일의 그룹을 hansgroup 프로젝트 팀으로 배속 이동시킵니다.
$ chgrp hansgroup test.txt

# 2. 하위의 모든 세부 서브 파일들까지 싹 긁어 그룹을 colors 로 동기화 변경시킵니다. (대문자 R)
$ chgrp -R colors color_files
```
