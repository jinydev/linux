# 터미널 기반 HTTP 클라이언트: curl

**`curl` (Client for URLs)** 은 리눅스 터미널이나 백그라운드 쉘 스크립트 안에서, 웹 브라우저(크롬) 없이 다이렉트로 인터넷 통신을 쏴서 데이터를 받아오거나 파일을 업로드할 때 사용하는 가장 파워풀한 네트워크 전송 도구입니다.

---

## 1. 기본 다운로드 및 데이터 수신 (GET)

서버(URL)가 응답하는 HTML 태그 덩어리나 순수한 JSON 데이터 텍스트를 그대로 화면에 뿌려줍니다. 
`> ` 리다이렉션을 쓰거나 `-o` 옵션을 주면 응답 내역을 파일로 이쁘게 저장할 수도 있습니다.

```bash
# 1. 구글 메인 페이지 HTML을 화면에 죽 뿌려봅니다.
$ curl https://www.google.com

# 2. 결과물 텍스트를 화면이 아니라 data.txt 파일에 저장합니다. (output)
$ curl -o data.txt https://www.google.com
```

## 2. 실전 API 통신 응용

단순히 글자만 가져오는 걸 넘어, 웹 개발 시 `POST` 로 로그인 폼을 던지거나 헤더(Header) 정보를 조작해 해킹 테스트나 백엔드 기능 검증을 할 때 빛을 발합니다.

### POST 폼(Form) 전송
`-X POST` 로 통신 방식을 지정하고, `-d` (Data)로 날릴 파라미터 조각들을 묶어서 쏩니다.
```bash
# 로그인 아이디와 패스워드를 묶어서 서버로 몰래 발송합니다.
$ curl -X POST -d "username=admin&password=123" https://www.example.com/login
```

### JSON 헤더(Header) 지정 통신
RESTful API 백엔드 서버와 통신할 때, "난 JSON으로만 대화할래" 라고 규격을 강제할 때 씁니다. `-H` (Header) 옵션입니다.
```bash
# Accept 요건을 json으로 강제하여 응답을 받습니다.
$ curl -H "Accept: application/json" https://www.example.com/api/users
```

## 3. 그 밖의 프로토콜 (FTP 배포)

HTTP 뿐만 아니라, 서버 배포용으로 FTP 프로토콜을 사용해 인증 절차(`-u`)를 거쳐 파일을 다운받는 짓도 쉘 한 줄로 즉시 구현 가능합니다.
```bash
# 아이디:비밀번호로 인증을 뚫고 타겟 파일을 현재 디렉터리로 받아옵니다.
$ curl -u ftpuser:1234 -o file.txt ftp://ftp.example.com/file.txt
```
