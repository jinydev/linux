# 단일 컴퓨터의 공간 분할: 가상 머신(Virtual Machine) 원리

맥북을 쓰면서 은행 사이트에 가기 위해 윈도우가 필요하거나, 윈도우 PC에서 리눅스 서버 실습을 해야 할 때, 컴퓨터 기계를 한 대 더 사는 대신 **"내 컴퓨터 안에 가상의 소프트웨어 컴퓨터를 하나 더 조립하는 마법"** 인 가상머신(VM)을 구축합니다.

---

## 1. 운영체제 속의 운영체제 (가상화)
컴퓨터의 뇌(CPU)와 RAM, 하드디스크 자원들의 일부 퍼센티지를 떼어내서 "이거 떼줄 테니 너 독립적인 척하고 따로 살아라!"며 방어막을 쳐주는 가상화 계층 기술입니다.

### [가상머신 도입의 실무적 장점]
1. **완벽한 치외법권 독립 격리 (격리성):** 호스트(원래 컴퓨터) 컴퓨터와 게스트(가상 컴퓨터) 컴퓨터는 서로의 영역을 볼 수 없습니다. 게스트 컴퓨터가 랜섬웨어 바이러스에 걸려 완전히 폭파당해도, 바깥쪽 현실 컴퓨터에는 단 1%의 피해도 번지지 않습니다. 의심스러운 파일을 폐쇄 테스트(샌드박스) 할 때 요긴합니다.
2. **미래의 시간 되돌리기 (스냅샷):** 실습하다가 리눅스 부팅이 고장 나버렸을 때, 어제 찍어둔 '백업 사진(Snapshot)' 재생 버튼만 누르면 1초 만에 어제 정상 상태로 타임머신 복구가 끝납니다. 물리 컴퓨터에선 불가능한 기술입니다.
3. **자원 쪼개기 (분할 효율성):** 물리 서버 1대의 CPU가 너무 거대하고 놀고 있다면, 그 속에 작은 가상 컴퓨터 10대를 쪼개서 만들고 임대료를 받는 비즈니스(클라우드 셋방)가 가능합니다.

### [가상머신의 필연적 단점과 오버헤드]
* **퍼포먼스 깎임 현상:** 운영체제 위에 자원을 통제하는 가상화 번역기(Hypervisor)를 또 얹고 그 위에 또 다른 운영체제를 돌리다 보니, 원래 물리 컴퓨터 100% 성능을 내지 못하고 연산 처리 손실(오버헤드 딜레이)이 필연적으로 발생합니다. 고사양 3D 그래픽 게임을 가상머신에서 못 돌리는 이유입니다.

## 2. 업계를 지배하는 가상화 솔루션 3대장

내가 사용 중인 컴퓨터 구석에 게스트 컴퓨터를 지어주는 전문 건설사 소프트웨어 라인업입니다.

* **1. Oracle VirtualBox (버추얼박스)**
  전 세계 대학생과 개발자들의 압도적 1픽. 오라클이 주도하는 완전 무료 오픈소스로, 윈도우와 맥은 물론 온갖 OS 파생판에서 전부 라이선스 제약 없이 가볍게 돌아갑니다. 수업 실습용의 영원한 스탠다드입니다.
* **2. VMware (브이엠웨어)**
  가상화 업계의 절대 권력 공룡기업. 개인용 무료판(`VMware Player`)도 있지만, 기업 데이터베이스 서버 시장과 자원 통제 소프트웨어(`vSphere`) 시장을 완전히 독식하고 있는 안정성의 끝판왕 유료 솔루션입니다.
* **3. Microsoft Hyper-V**
  마이크로소프트가 "남의 프로그램 깔지 말고 우리 윈도우10 Pro 버전에 내장된 가상화 버튼만 누르면 바로 쓸 수 있어!" 라며 OS 차원에서 깊숙이 때려 박아 제공하는 고속 가상화 도구입니다.
