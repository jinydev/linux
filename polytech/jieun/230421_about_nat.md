# 사설망 통신 규약: NAT 와 포트포워딩(Port Forwarding)

전 세계 공인 IP 부족 사태(IPv4 고갈)를 해결하기 위해 등장한 구세주 기술입니다. 회사 내부의 100대 컴퓨터가 단 1개의 진짜 인터넷용 공인 IP만으로 인터넷을 할 수 있게 해주는 마법의 라우팅 기법을 분해합니다.

---

## 1. NAT (Network Address Translation) 의 원리

공유기(라우터) 안쪽에 있는 내 노트북의 사설 IP(`192.168.0.10`)는 바깥세상(네이버)에 나가면 길을 잃어버리는 가짜 IP입니다.

* **동작 시나리오 (패킷 변조):** 내 노트북에서 구글 웹서버로 접속 시도를 할 때, 이 패킷은 문지기인 '공유기'를 거칩니다. 공유기는 내 가짜 출발지 IP를 떼어버리고 공유기 자신이 가지고 있는 진짜 **'고가치 공인 IP' 로 출발지 스티커를 위조(변환)**하여 구글로 날립니다. (SNAT)
* **NAT 라우팅 테이블:** 공유기는 "방금 192.168.0.10이 보냈던 요청"이라는 장부를 내부 메모리 NAT 테이블에 적어둡니다. 구글이 응답을 공유기로 보내주면, 공유기는 이 장부를 보고 "아! 아까 10번 컴퓨터가 시킨 거다"라며 노트북에 쏙 돌려줍니다. 

### [유용성]
1. **IP 주소의 극단적 절약:** 1개의 공인 IP 회선 값만 내면 100명이 와이파이를 쓸 수 있습니다.
2. **보안 (해킹 방어):** 외부 인터넷의 해커는 공유기의 공인 IP만 보일 뿐, 내 공유기 안쪽 노트북의 구조나 사설망 IP 대역을 절대 투시할 수 없습니다.

---

## 2. 포트포워딩 (Port Forwarding): 외부에서 안쪽 침투하기

NAT의 특징 때문에, 반대로 외부의 손님이 내 공유기 안쪽에 있는 사설 리눅스 웹서버(`192.168.0.22`)로 다이렉트로 접속하고 싶어도 투시가 안 되어서 불가능합니다. 
이 억울함을 풀기 위한 기술이 포트포워딩, 즉 '도착지 위조 배달(DNAT)' 기법입니다.

* **동작 시나리오:** 공유기에 설정 규칙을 겁니다. **"무조건 외부에서 공유기의 `80번` 포트로 접근하는 손님이 있으면, 묻지도 따지지도 말고 내 안쪽 서버인 `192.168.0.22 의 80번` 포트로 바로 토스해 버려라(Forward)."**
* 외부 손님은 내 방 공유기의 공인 IP 주소만 입력해도, 공유기가 자동으로 문을 열어주고 안쪽에 꽁꽁 숨겨진 리눅스 웹서버 창고로 즉시 점프(라우팅)시켜 줍니다.

> **💡 요약 비유**
> * **NAT (SNAT):** 기숙사 학생 수백 명이 나갈 때, **기숙사 대표 주소 하나로 퉁쳐서** 편지를 보내는 기술.
> * **포트포워딩 (DNAT):** 외부에선 기숙사 대표 주소만 쓰여 있어도, 층별 우편함 번호(포트) 규칙에 따라 방안의 특정한 학생에게 **다이렉트로 편지가 꽂히도록** 설계하는 기술.
