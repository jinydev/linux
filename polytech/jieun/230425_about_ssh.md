# 원격 시스템 통신 프로토콜: SSH 결합과 비대칭 키 원리

서초동 집 소파에서 강남구 AWS 지하 서버실의 리눅스 컴퓨터를 관리하기 위해, 콘솔을 키보드로 다이렉트 타이핑 치듯이 화면을 끌어오는 해킹 방어 0순위 원격 지배 기술입니다.

**(※ 경고: 과거에는 Telnet 프로토콜을 사용했으나, 패킷이 단순 평문 노출 투명 창이라 해킹이 빗발침에 따라 도태되고 완전 무결한 SSH로 국제 표준이 강제되었습니다.)**

---

## 1. SSH (Secure Shell) 의 주요 특징
* **포트 할당:** 표준 TCP `22번` 포트 구멍을 씁니다.
* **클라이언트 계열:** 리눅스/맥은 기본 탑재이나 윈도우는 옛날엔 빈털터리라 외부 도구인 `PuTTY`, `Xshell` 등을 깔아서 썼습니다. (현재는 윈도우 파워쉘에 OpenSSH가 내장되어 무혈입성 가능).
* **접속 통로 구조:** 양 끝에 거대한 강철 터널링 파이프를 박아 넣고, 그 속에서 모든 텍스트 타이핑 명령어가 해독 불가한 난수 체계로 뭉개져 실시간 암호화로 교환됩니다. 

---

## 2. 보안의 알파와 오메가: 비대칭 키 (Asymmetric Key)

단순히 `admin/1234` 문자를 쳐서 들어가는 원시적 방식은 털리기 매우 쉽습니다. 최고 등급 서버 보안에서는 절대 암호를 공유하지 않고, 쌍방 열쇠(비대칭 키 알고리즘) 검증법을 사용합니다. 

### [두 개의 자물쇠 무기 분리]
* **Public Key (공개키):** 암호 자물쇠를 채우는(Encrypt) 용도의 자물쇠입니다. 전 세계 1억 명이 이 자물쇠를 다 복사해서 가지고 있어도 아무런 해킹 문제가 없습니다. 리눅스 서버에 등록해 둡니다.
* **Private Key (비밀/개인키):** 자물쇠를 풀 수 있는 단 1개의 절대 열쇠, 마스터키입니다. 오직 내 노트북 로컬 하드디스크 깊은 곳 증명서 팩토리(`~/.ssh/id_rsa`)에만 존재해야 하며 카카오톡으로 남한테 전송하거나 유출되는 즉시 서버 보안은 뚫려버립니다.

## 3. SSH 세션 체결 시나리오 (핸드셰이크)

이 안전한 열쇠 구조가 어떻게 원격 접속 접속망에 결합하는가에 대한 논리입니다. 

1. **상견례:** 내 노트북(클라이언트)이 서버 TCP 22번에 "야 문열어" 접속 노크를 합니다.
2. **함정 수사:** 서버는 순순히 열어주지 않고, 서버가 들고 있는 `Public Key (공개키)` 자물쇠로 잠근 거대한 수학 난수퍼즐 상자를 클라이언트에게 던져줍니다.
3. **진위 증명:** 이 퍼즐 상자는 오직 진짜 `Private Key (비밀키)`를 가진 놈만이 박스 열쇠 구멍을 딸 수 있도록 설계되어 있습니다. 내 노트북이 내 뱃속에 있는 비밀키로 상자를 열어 해답을 외칩니다.
4. **동기화 성사:** 서버가 "아 이 해답을 단독으로 열었다고? 너 진짜 주인의 노트북이 맞구나!"라며 문을 열어주고 강력한 강철 터널 암호 터널 파이프가 뚫리며 서버 키보드 지배가 통제됩니다.
