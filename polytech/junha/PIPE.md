# 출력과 입력을 잇는 호스 도관: 파이프 (Pipe `|`)

리눅스 터미널의 모든 커맨드는 자기만의 섬(프로세스) 안에서 놀고 있습니다. 내가 명령을 쳤을 때 모니터 화면에 허무하게 흩뿌려지고 버려지는 텍스트 결괏값 덩어리들을 바닥에 버리지 않고, **호스를 연결해서 다음 명령어의 입(Input)으로 강제로 쑤셔 넣어 연쇄 폭발을 일으키게 만드는 심볼이 바로 파이프(`|`) 입니다.** 무적의 리눅스 생산성의 근원이기도 합니다.

---

## 1. 파이프 심볼의 3대 철학 (방해 없는 데이터 스트림)

* **메모리 직통 배송 (IPC - Inter-Process Communication):** A의 결괏값을 텍스트 메모장 중간 파일로 굳이 저장했다가(`>`), B명령어에서 그 텍스트를 불러와서(`cat`) 읽게 하는 번거롭고 멍청한 짓을 막아줍니다. 램(RAM) 메모리를 타고 결과가 즉시 다음 놈의 입력창으로 흐릅니다. 
* **일방통행 (단방향):** 언제나 왼쪽 명령어의 토사물(출력)이 오른쪽 명령어의 입(입력)으로 역류 없이 꽂혀 들어갑니다.
* **무한의 블록 조립성:** `명령A | 명령B | 명령C | 명령D` 처럼 10번이고 레고 블록처럼 호스를 이어 붙여 고도의 가공 프로세스 공장을 만들 수 있습니다. 

---

## 2. 파이프와 무조건 같이 쓰이는 가공 유틸리티 (필터기)

파이프로 쏟아져 들어오는 무자비한 텍스트 덩어리를 채에 쳐서 내가 원하는 정보만 걸러내는 파수꾼 필터 삼대장이 있습니다.

* **`grep` (글자 색출기):** 천 줄짜리 결과가 넘어와도, 자기가 지정한 키워드가 든 줄만 쏙 빼고 나머진 묻지도 따지지도 않고 다 버리는 궁극의 수색꾼입니다.
  ```bash
  # 현재 돌아가는 수만 개의 프로세스 리스트를 토스받아서 그중에 mysql 단어가 있는 놈만 걸러라
  $ ps -ef | grep mysql
  ```
* **`sort` 와 `head/tail` (정렬 컷팅기):** 용량이나 알파벳 순서대로 데이터 열을 이쁘게 오름차순/내림차순 시킨 뒤 무자비하게 머리나 꼬리채를 잘라냅니다. 
  ```bash
  # 파일을 쭉 읽어 알파벳순 정렬 후, 밑에서 3장만 잘라서 화면에 내놔라
  $ cat app.log | sort | tail -n 3
  ```
* **`awk` 와 `cut` (칼잡이 조각가):** 공백이나 콤마로 띄워진 데이터 표를 토스받아서, 쓸데없는 1열 3열 열람칸은 없애버리고 "오직 2번째 이름 칸만 떼서 보여줘!" 라고 분해하는 포맷팅 도구입니다. 리눅스 스크립트 장인들의 상징입니다. 
  ```bash
  # 띄어쓰기 열 리스트 중에서 2열 덩어리만 떼서 출력하라
  $ cat data.txt | awk '{print $2}'
  ```
