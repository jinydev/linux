# Everything is a File: 리눅스 파일 시스템과 계층 구조

유닉스와 리눅스의 가장 무서운 설계 철학은 **"모든 것은 파일이다(Everything is a File)"** 입니다. 하드디스크에 저장된 이력서(.txt)만 파일인 윈도우(Windows)와 달리, 리눅스는 키보드 본체, 모니터, 네트워크 랜카드 장비마저도 디렉토리에 들어있는 단일 특수 파일(Device File) 껍데기로 간주하여 컨트롤합니다.

---

## 1. 파일의 종족 구분 (File Types) 
리눅스 터미널에서 `ls -l` 을 쳤을 때 좌측 맨 앞에 찍히는 스펠링 1글자는 이 파일의 종족을 분별합니다.

* **`-` (일반 파일 / Regular File):** 우리가 아는 가장 보편적인 존재입니다. 텍스트 문서(`.txt`), 자바 소스 코드(`.java`), 심지어 이미 실행 중인 프로그램 덩어리마저 여기에 속합니다.
* **`d` (디렉토리 / Directory File):** 리눅스는 디렉토리 조차 폴더(가방)라는 논리 형체가 아니라, 그저 '자기 밑에 있는 꼬맹이 파일들의 주소록 리스트를 텍스트로 적어둔 파일' 덩어리에 불과하다고 취급합니다. 
* **`l` (심볼릭 링크 / Link):** 윈도우의 '바탕화면의 바로가기'처럼 다른 진짜 파일의 주소만을 허수아비처럼 가리키는 포인터 파츠입니다.
* **`c` & `b` (장치 디바이스 파일):** 마우스(입력), 하드디스크 드라이브(출력 장치) 등의 쇳덩어리 기계 부품과 드라이버를 `/dev` 폴더 밑에서 캐릭터(c), 블록(b) 파일의 스킨으로 취급해버리는 기이한 유닉스의 산물입니다.

---

## 2. 세계수 뿌리 (루트 `/`) 계층 아키텍처

윈도우는 하드디스크가 3개면 `C:\`, `D:\`, `E:\` 로 몸통을 세 동강 내비립니다.
반면 리눅스는 하드디스크가 100개건 USB가 10개건, 무조건 킹맥 최상단 뿌리인 **슬래시 `/` (Root Directory)** 단 1개의 꼭대기에서 나뭇가지 파생 트리 구조로 모든 것을 묶어버립니다.

### [필수 생존 암기 디렉토리]
1. **`/root` :** 리눅스의 전지전능한 신(root, 슈퍼유저)이 거주하는 침실 폴더입니다. 일반 평민 계정은 접근하면 접근 거부(Permission Denied)를 맞고 쫓겨납니다.
2. **`/home` :** 나를 포함해 시스템 서버에 아이디를 부여받은 일반 평민 유저들(donghak, jieun 등)의 아파트 단지가 제공되는 곳입니다. (`/home/jieun`)
3. **`/etc` :** **(매우 중요)** 서버의 모든 핵심 세팅, 비밀번호 장부, 아파치와 톰캣의 텍스트 설정 파일이 다 쑤셔 박혀있는 서버 관제실 톱니바퀴 저장소입니다. 실수로 하나라도 지우면 시스템이 박살 납니다.
4. **`/bin` & `/sbin` :** 우리가 치는 `ls`, `cp` 와 네트워크 재시작 시스템 툴 같은 모든 명령어 실행 스크립트 실행파일들이 박혀있는 무기 창고입니다. 
5. **`/dev` :** 모니터, 하드디스크 장치들을 몽땅 파일 형태로 변환해 인식시켜 둔 기계들의 무덤.
6. **`/var` :** 시스템이 동작하면서 쌓이는 잡다한 쓰레기 로그(에러 일지 - `/var/log`), 메일 보관소 등 용량이 계속 널뛰기하는 임시 가변성 창고입니다.

## 3. 파일 생태계 통제 기본 명령어 (조작술)

터미널에서 이 파일 생명체들을 살해하거나 복제하는 가장 기본적인 명령들입니다. 

* **`touch` (심폐소생술/창조):** 빈 내용의 0바이트 껍데기 파일을 허공에서 생성해 냅니다. 또는 기존 파일이 있다면 '가장 최근에 열어본 시간' 타임스탬프를 현재 시간으로 갱신해 줍니다. 
* **`cat` (부어버리기):** 파일에 있는 모든 글자 텍스트 내용을 한방에 터미널 창 바닥에 좌르륵 쏟아붓습니다. 
* **`cp` (세포 분열):** `cp 기존파일명 새파일명` / 원본의 유전자를 남겨둔 채 새 분신을 카피 생성합니다.
* **`mv` (워프/개명):** `mv 이집트 로마` / 파일을 아예 이사시키거나(Move), 이름을 교체(Rename)할 때 짬짜면으로 쓰입니다. 
* **`rm` (살해 명령어):** `rm 악성파일` / 영구적으로 파일을 삭제합니다. 특히 `rm -rf /` (모든 세계수 강제 소각) 명령은 서버를 핵폭발 시키는 절대 금기어입니다.
* **`mkdir` & `cd`:** 새로운 폴더 우주(`Make Directory`)를 구축하고 거기로 워프(`Change Directory`) 해 들어갑니다.
