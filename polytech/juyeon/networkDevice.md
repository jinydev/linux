# 패킷의 이동을 관장하는 인프라 장비 (L2 스위치 vs L3 라우터)

내 리눅스 서버에서 나온 카카오톡 데이터 덩어리(패킷)가, 미국 구글 서버까지 날아가려면 무수한 기계들을 순차적으로 건너뛰며 점프해야 합니다. 이때 트래픽의 모가지를 잡고 길을 제어해 주는 3대 물리 장비의 변천사입니다.

---

## 1. (L1) 구시대의 멍청이: 더미 허브 (Hub)
모든 선을 꽂아 나누는 멀티탭 같은 옛날 장비입니다. 

* **치명적 결함 (브로드캐스트):** 1번 컴퓨터가 3번 컴퓨터에게 비밀 데이터를 보내면, 허브는 누가 3번인지 구분할 지능이 없어서 꽂혀있는 2번, 4번, 5번 컴퓨터에 **무지성으로 다 복사해서 쏴버립니다** (브로드캐스트). 사내 트래픽이 폭주하여 인터넷이 마비되며 보안도 제로라 현재 환경에선 완전히 도태되어 소멸했습니다.

---

## 2. (L2) 사내망의 지배자: 스위치 (Switch)
위의 멍청한 허브에 '맥 어드레스(MAC 주소: 랜카드 고유 기계번호)를 기억하는 장부' 를 탑재한 지능형 L2 장비입니다.

* **동작 원리 (스위칭):** 스위치는 평소에 각 랜선 구멍에 연결된 컴퓨터들의 기계 주소(MAC)를 외우고 있습니다. 1번이 3번에게 패킷을 보내면, 뒷구멍의 3번 선으로만 다이렉트로 던져줍니다. (충돌 0%)
* **한계 (사내 한정):** 사내망(서초동 사무실) 안에서의 배달은 기가 막히게 잘하지만, 외부 세상(강남구 구글 서버)으로 나가는 IP 지리 지식이 전혀 없기 때문에 사무실 밖을 나가는 순간 바보가 됩니다. 

---

## 3. (L3) 인터넷 지도의 네비게이션: 라우터 (Router)
사내망 스위치를 통과한 패킷을 받아들고, 최적의 고속도로를 탐색해 미국 구글 본사 서버까지 점프시켜 주는 강력한 L3 국가 대표 장비입니다. 흔히 여러분 집의 **'인터넷 공유기'** 가 라우터+스위치의 혼합 축소판입니다. 

* **동작 원리 (라우팅 테이블):** 라우터의 두뇌에는 전 세계 IP 주소 대역폭의 고속도로 지도가 수만 개 적혀있습니다. "목적지 IP가 구글이네? 태평양 해저 광케이블로 던져" 라고 판단하여 다음 라우터로 패킷을 강하게 걷어찹니다. 
* **기능 확장:** 외부 해커가 못 들어오도록 IP 방화벽을 세우거나 (ACL 통제), 우리 회사 컴퓨터 100대가 외부로 나갈 땐 전부 회사 대표 IP 1개로 주소를 위조해서 내보내는 마법(NAT 기능) 등을 모두 공유기(라우터)가 감당해 냅니다.
