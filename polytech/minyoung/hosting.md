# 호스팅 서비스

## 호스팅 서비스란?
호스팅 서비스란 인터넷을 통해 웹사이트나 애플리케이션을 24시간 운영할 수 있도록 필요한 서버 공간과 인프라 장비를 임대해 주는 서비스입니다. 고객은 호스팅 업체의 물리적 장비 및 데이터센터 환경을 빌려 자신의 서비스를 배포하고 접속할 수 있게 됩니다.

## 호스팅 서비스의 종류
고객이 운영할 서비스의 규모, 예산, 유연성 요구사항에 따라 세 가지 주요 방식으로 나눌 수 있습니다.

### 1. 서버 호스팅 (Server Hosting)
서버 호스팅은 물리적인 "서버 한 대(또는 그 이상) 전체"를 단독으로 임대하여 사용하는 방식입니다. 관리자(root) 권한까지 온전히 할당받아 시스템 환경을 원하는 대로 커스터마이징할 수 있습니다.

#### 서버 호스팅의 장점 
* **독점적 자원 사용:** CPU, RAM, 네트워크 대역폭 등 서버의 모든 자원을 혼자 독점하여 최고의 퍼포먼스를 낼 수 있습니다.
* **완전한 제어 권한:** 방화벽 구축부터 커널 환경 수정까지 자유롭게 구성이 가능합니다.
* 복잡하고 거대한 자체 시스템이나 높은 보안 수준을 요구하는 대기업, 금융권 서비스에 적합합니다.

#### 서버 호스팅의 단점
* **높은 비용:** 초기 세팅 및 월 임대 비용이 세 가지 호스팅 중 가장 비쌉니다.
* **유지보수 부담:** 하드웨어 장비에 문제가 생기거나 서버 소프트웨어 운영(보안 패치, 업데이트 등) 시 높은 기술적 지식이 요구되며 전문 인력이 필요합니다.

### 2. 웹 호스팅 (Web Hosting)
웹 호스팅은 하나의 거대한 서버 자원을 여러 명의 사용자가 함께 쪼개어 사용하는 "공유 호스팅(Shared Hosting)" 방식입니다. 이미 구축된 웹 환경 공간의 일부만 할당받아 사용합니다.

#### 웹 호스팅의 장점 
* **저렴한 가격:** 여러 사용자와 비용을 분담하는 형태이므로 월 몇천 원대의 매우 저렴한 가격으로 이용할 수 있습니다. 개인 블로그, 소규모 기업의 랜딩 페이지에 최적화되어 있습니다.
* **쉬운 관리:** 서버 OS나 웹 서버 설치, 보안 패치 등 골치 아픈 관리는 호스팅 업체가 전담하며, 사용자는 제공되는 쉬운 관리 패널로 파일만 업로드하면 됩니다.

#### 웹 호스팅의 단점
* **자원 공유로 인한 불안정성:** 같은 서버를 공유하는 다른 이웃 사이트에 트래픽 폭주가 발생하면 내 사이트의 속도도 느려지거나 다운될 수 있습니다. (Noisy Neighbor 문제)
* **관리 권한 제한:** 시스템 파일이나 환경 설정을 마음대로 변경할 수 없어 언어 버전 업데이트 확장에 치명적인 한계가 있습니다.

### 3. 클라우드 호스팅 (Cloud Hosting)
클라우드 호스팅은 여러 대의 물리적 서버 자원을 풀(Pool)로 묶어 가상화 기술을 통해 구축한 뒤, 그 안에서 가상의 서버(인스턴스)를 생성하여 할당해 주는 방식입니다. (예: AWS EC2, Vultr, Naver Cloud)

#### 클라우드 호스팅의 장점 
* **강력한 확장성과 유연성 (Auto-Scaling):** 갑작스럽게 사용자가 급증하더라도, 클릭 몇 번만으로 즉시 CPU나 메모리를 확장하여 대규모 트래픽을 원활하게 처리할 수 있습니다. 제일 강력한 강점입니다.
* **서버 이중화 및 안정성:** 한 대의 물리 기계에 문제가 생기더라도, 클라우드 자원 풀의 다른 서버 장비로 즉시 대체되어 서비스 무중단 환경(High Availability)을 제공합니다.
* **사용한 만큼만 지불 (Pay-As-You-Go):** 초기 투자 비용 없이 매 시간/미닛 단위로 본인이 사용한 리소스만큼만 비용을 효율적으로 지불합니다.

#### 클라우드 호스팅의 단점
* **높은 학습 곡선과 운영 난이도:** 인프라를 프로비저닝하고 로드 밸런서, 방화벽 등을 다루기 위한 전문적인 클라우드 아키텍처 지식이 필요합니다. 관리를 소홀히 하면 요금 폭탄을 맞을 위험도 존재합니다.
* **벤더 종속성 (Vendor Lock-in):** 특정 클라우드 벤더사(예: AWS)가 제공하는 고유 서비스(DB, 람다 등)를 과도하게 사용하면, 향후 다른 클라우드 환경으로 마이그레이션(이전) 할 때 엄청난 기술적 난관에 부딪힙니다.
