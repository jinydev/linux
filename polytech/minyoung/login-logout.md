# 접속 및 로그인, 로그아웃 제어하기

리눅스 시스템은 전통적인 다중 사용자 환경(Multi-User System)으로 설계되어 있으며, 시스템에 접근하고 사용하기 위해서는 필수적인 보안 절차로 로그인(Login) 프로세스를 거쳐야 합니다.

## 1. 로그인이란?

리눅스에서 로그인(login)은 사용자가 시스템의 자원을 사용하기 위해 **'자신의 신분을 증명하고 접근 권한을 획득하는 과정'**을 의미합니다.

* 사용자는 자신의 계정(ID)과 비밀번호(Password)를 입력하여 인증을 수행합니다. 
* 인증이 완료되면, 운영체제(Kernel)는 사용자의 정보(`/etc/passwd` 등)를 확인한 후, 접속한 사용자의 권한 수준에 맞는 작업 환경(Shell)을 띄워 줍니다.
* 리눅스는 다중 사용자 환경이므로 한 시스템에 여러 백그라운드 사용자 및 원격 접속 사용자가 동시에 로그인하여 각자의 작업을 독립적으로 수행할 수 있습니다.

### 핵심 시스템 보안 관문
올바른 인증을 거치지 않으면 철저히 엑세스를 거부하기 때문에, 시스템 보안 측면에서 매우 중요한 일차 방어선 역할을 합니다. 또한 시스템은 누가, 언제, 어디서 로그인했는지 모든 내역을 시스템 로그 파일에 기록하여 사후 감사(Audit) 자력으로 활용합니다.

## 2. 로그인 기록 추적하기

시스템 관리자는 주기적으로 누가 서버에 접속했는지 확인하여 무단 침입을 탐지해야 합니다. 로그인 및 원격 접속과 관련된 정보는 보통 `/var/log/auth.log` (데비안/우분투) 또는 `/var/log/secure` (레드햇/로키)와 `/var/log/wtmp` 등에 꼼꼼히 기록됩니다.

접속 기록을 직관적으로 확인하기 위해 터미널에서 아래 명령어들을 사용합니다:

* **`last`** : 사용자의 전체 로그인/로그아웃 시간, 접속 단말(터미널) 정보, 재부팅 내역을 출력합니다. `/var/log/wtmp` 파일의 내용을 해독해 보여줍니다.
  ```bash
  $ last
  ```

* **`last [사용자계정]`** : 특정 사용자가 서버에 접속했던 기록만 필터링하여 확인합니다.
  ```bash
  $ last john
  ```

* **`last -F`** : 로그인과 로그아웃 발생 연도와 전체 날짜, 시간 정보를 전부 확장해서(Full) 출력합니다.
  ```bash
  $ last -F
  ```

## 3. 로그아웃의 개념 및 차이점 

컴퓨터 사용을 마치면 로그아웃(Logout)을 통해 시스템 세션을 정리합니다. 백그라운드로 명시하지 않은 한 로그아웃과 동시에 현재 쉘 환경과 연결된 포그라운드 프로세스가 종료됩니다.

터미널이나 원격 접속(SSH) 환경에서는 커맨드로 접속 창을 닫게 되는데, 이때 자주 쓰이는 `logout`과 `exit`은 사용 방식이 조금 다릅니다.

### 🛑 `logout` 명령어
`logout` 명령어는 사용자의 **'로그인 셸(Login Shell)'**을 종료할 때만 사용 가능한 명령어입니다. 즉, SSH나 터미널 콘솔을 통해 ID와 비밀번호를 쳐서 최초로 진입한 그 셸에서만 작동하며, 현재 연결된 세션을 완전히 닫고 끊는 역할을 합니다. 중간에 단순히 `bash` 명령어를 쳐서 생성된 서브 셸(Sub-Shell)에서는 `logout` 명령을 수행하면 오류가 발생합니다.

### 🛑 `exit` 명령어
`exit`은 현재 구동 중인 **'모든 종류의 셸(Sub-Shell 포함)'**을 종료하는 명령어입니다. 셸 스크립트를 종료할 때나, `su -` 로 생성한 자식 셸 창을 닫고 원래 셸로 나갈 때에도 유용하게 쓰입니다. 만약 로그인 셸에서 실행했다면 `logout`과 동일하게 접속 창이 종료되고 세션이 끊어집니다. 

*(주의: 이전 학생 작성 리포트 중 "logout이 이전 세션을 저장해준다"라는 설명은 AI의 전형적인 환각(Hallucination)입니다. 리눅스 환경의 로그아웃 커맨드는 단순 엑세스 종료이며 별도의 VM 백업 같은 세션 상태를 저장하지 않습니다.)*

### 🛑 `shutdown` 명령어와의 구분
`logout` 이나 `exit`은 단지 현재 내 접속 창 하나를 닫고 "다른 사용자들은 그대로 서버를 쓸 수 있게" 놔두는 것이지만, `shutdown -h now`나 `systemctl poweroff` 같은 시스템 종료 명령어는 아예 리눅스 서버 기계 전원을 완전히 꺼버리는 최상위 관리자(Root) 명령어입니다. 서버 환경에서 혼동하면 치명적인 장애를 유발할 수 있습니다.
