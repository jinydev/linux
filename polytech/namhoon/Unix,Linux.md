# 뱅킹 서버의 심장 교체: Unix 에서 Linux 로 (다운사이징)

과거 90년대, 수백만 명의 트래픽을 처리하는 정부 기관이나 금융권 메인 서버는 무조건 수억 원을 호가하는 묵직한 하드웨어 대형 냉장고 괴물 머신과 **폐쇄형 운영체제(Unix)** 에 의존했습니다. 그러나 이제는 이 생태계가 가벼운 **x86 리눅스(Linux) 환경** 으로 전복되는 U2L(Unix to Linux) 시대가 도래했습니다.

---

## 1. 태초의 분기점 (과거의 패권)

### [귀족의 전유물: 유닉스 (Unix)]
* 초기 유닉스는 하드웨어 철물과 OS 소프트웨어가 철저하게 한 세트로 결합되어 판매되는 특수 장비에 가까웠습니다. 
* HP사의 HP-UX, IBM사의 AIX, Sun사의 Solaris 등이 시장을 장악했으며, 한 대에 수억 원을 내고 폐쇄적인 하드웨어 장벽 속에서 기업용 보증을 받고 썼습니다.

### [오픈소스 혁명: 리눅스 (Linux)]
* 핀란드의 대학생 리누스 토르발스가 "누구나 공짜로 PC에 깔아 쓸 수 있는 유닉스 모방판을 만들자" 하고 소스코드를 무료로 배포했습니다. 
* 값비싼 거대 특수 하드웨어가 아니라, 용산에서 조립해 온 깡통 PC(x86 아키텍처) 껍데기에도 무설치로 막 굴러가는 미친 이식성을 자랑하며 서버 시장에 폭발적으로 침투했습니다.

---

## 2. 금융권 인프라에 불어닥친 U2L (Unix To Linux)

현재 카카오뱅크, 국민은행, 하나은행 등 굴지의 금융권에서 메인프레임과 유닉스를 도려내고 깡통 서버 뼈대에 리눅스를 올리는 무서운 **다운사이징 전략(U2L)** 이 표준화되었습니다.

1. **압도적인 가성비와 확장성:** 유지보수 비용을 요구하던 수억 원짜리 유닉스 깡통 1대보다, 저가형 PC 서버 100대를 사서 리눅스를 박고 클러스터 병렬 묶기를 해버리는 게 비용은 수십 배 절감되면서 트래픽 과부하 분산 파워는 훨씬 강력합니다.
2. **클라우드와 Docker 의 모태:** 현대 개발 속도의 핵심인 AWS 클라우드, 마이크로서비스 설계, Docker 컨테이너 무중단 배포 시스템 등은 태생적으로 철저하게 리눅스 커널 위에서만 돌아가도록 설계되었습니다. 따라서 은행들이 글로벌 모바일 기술을 선점하려면 유닉스를 버리고 강제로 리눅스 밭으로 이사 갈 수밖에 없었습니다.
