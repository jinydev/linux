# 버추얼박스 외부망 아키텍처: 브릿지 어댑터 (Bridged Adapter)

Host-Only 모드가 외부 인터넷 줄을 잘라버린 폐쇄망이었다면, **브릿지(Bridge) 모드는 가상의 리눅스를 내 윈도우 본체와 완벽하게 동등한 권한으로 공유기 앞에 출현시키는 '외부 물리망'** 세팅입니다.

---

## 1. 아키텍처 사상 (공유기 직결)

* **작동 구조:** 버추얼박스를 거치는 게 아니라, 내 윈도우 PC에 꽂힌 물리적 메인 랜카드의 스펙을 그대로 스틸해서(가로채서) 자기 본인 랜카드처럼 위장 사용하는 모드입니다.
* **네트워크 규칙:** 리눅스를 브릿지로 세팅하면, 집 거실에 있는 '인터넷 공유기(KT/SKT 다이렉트)' 에게서 윈도우 본체와 아예 똑같은 내부망 IP(`192.168.0.x`)를 동등하게 부여받습니다. 
* **장점:** 내 컴퓨터 밖의 옆자리 동료 PC폰이나 거실의 스마트폰에서도, 이 가상머신 리눅스 IP로 직접 `ping`을 때리고 `ssh` 로 뚫고 들어올 수 있습니다. 로컬을 넘어선 실무 테스트 스카우트에 용이합니다. 

---

## 2. 실전 트러블슈팅 (브릿지 프로토콜 연동 실패)

버추얼박스 네트워크 목록에서 브릿지를 고르려는데 랜카드 목록 창이 텅텅 비어 먹통이 되는 경우의 긴급 수술법입니다. 

### [원인: NDIS 드라이버 이식 버그]
버추얼박스가 윈도우 운영체제의 랜카드 지배권을 스틸할 가상 네트워크 드라이버 모듈이 삭제된 현상입니다.

### [해결: .inf 수동 이식]
1. 윈도우 제어판의 `네트워크 연결(ncpa.cpl)` 메뉴를 호출합니다.
2. 현재 인터넷이 돌아가고 있는 윈도우 본체의 이더넷(또는 Wi-Fi) 어댑터를 우클릭 -> `속성` 에 진입합니다.
3. 리스트에 `VirtualBox NDIS6 Bridged Networking Driver` 가 없다면, 아래의 [설치] 버튼을 누릅니다.
4. `서비스` 항목 -> [추가] -> [디스크 있음] 을 선택합니다.
5. 운영체제 C드라이브 심층부 **`C:\Program Files\Oracle\VirtualBox\drivers\network\netlwf\`** 로 침투하여, **`VBoxNetLwf.inf`** 네트워크 뼈대 정보 파일을 강제로 먹여 [열기] 로 설치시킵니다.
6. 성공적으로 드라이버가 인젝션 되면, 버추얼박스 설정 내에서 내 윈도우의 메인 랜카드가 정상 인식되며 기적처럼 외부망 IP 주소를 땡겨오게 됩니다.
