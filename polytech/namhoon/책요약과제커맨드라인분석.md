# 마우스가 죽은 세계의 키보드 조작술: Bash 커맨드라인 단축키

리눅스 CLI 텍스트 바다 환경에서는 키보드만으로 모든 렌더링 워프를 전개해야 합니다. 
마우스를 쓸 수 없는 고통 속에서 텍스트의 끝단을 자르고, 오타를 뒤집으며, 1시간 전 쳤던 수백 줄의 복잡한 명령어를 단 1초 만에 마법처럼 예토전생 시키는 Bash 고급 엔지니어들의 단축키 컨트롤입니다.

> 🚨 **주의:** 맥(Mac OS) 유저 분들은 터미널에서 `ALT` 키의 옵션이 `ESC` 또는 `Option` 키로 매핑되어 동작합니다.

---

## 1. 커서 터미널 워프 조작 (이동)

긴 도커(Docker) 구동 명령어를 치고, 줄 끄트머리에 오타를 발견해 방향키를 수십 번 누르며 가는 것은 초보자의 짓입니다.

* **`Ctrl + A` / `Ctrl + E` (극단적 워프):** 커서를 줄의 맨 앞(A)이나 맨 뒤(E)로 빛의 속도로 워프시킵니다.
* **`Alt + F` / `Alt + B` (단어 스킵 이동):** 한 글자가 아니라 영어 무더기의 띄어쓰기(단어 블록) 기준으로 점프(Forward / Backward)하며 전진/후퇴합니다.
* **`Ctrl + L` (시야 제거):** 화면에 난잡하게 적힌 쓰레기 로그들을 단숨에 지워버리고(Clear 명령어 효과) 내 커서를 청결한 화면 꼭대기로 솟구치게 만듭니다.

---

## 2. 커맨드 증발과 파쇄술 (수정 및 살해)

타자를 지우기 위해 백스페이스를 꾹 누르고 있는 행동은 금물입니다.

* **`Ctrl + W` / `Ctrl + U` (문장 목자르기):** 내 커서가 위치한 지점에서 문장 맨 뒤(K)나 맨 앞(U)까지의 남은 명령어 덩어리를 단숨에 살해하여 지워버립니다. 
* **`Ctrl + Y` (예토전생):** 위에서 `Ctrl + U/K` 로 살해당한 문장들은 영원히 죽은 게 아니라, 시스템 내장 백그라운드 버퍼(Kill-Ring)라는 보이지 않는 창고에 보존됩니다. 이 Y 키를 누르면 방금 살해한 그 문장이 내 커서 위치에 다시 카피/붙여넣기 렌더링 부활합니다.

---

## 3. 영광의 무소불위 만능키: 자동 완성 (Tab)

리눅스와 윈도우 파워쉘을 관통하는 최강의 시스템 유틸리티입니다. 명령어 철자나 깊은 디렉토리 파일명을 다 치지 않고 2~3글자만 친 후 무지성으로 **`Tab`** 키를 치면 시스템이 남은 영단어를 자동으로 타이핑해 줍니다. 
* 겹치는 프로그램 이름이 여럿(예: `sys` 만 치면 sysctl인지 systemd인지 모를 때)일 때는, **`Tab` 기를 두 번 연타 따닥 치면** 하단에 가능한 선택지 리스트들을 검색 팝업처럼 쫘아악 토해내서 보여줍니다.

---

## 4. 백룸 추적과 재투척: 히스토리(History) 장부

어제 밤 쳐놓고 엔터 친 긴 명령어는 `~/.bash_history` 라는 서버의 기억장부(뇌)에 꼼꼼히 기록됩니다.

* **위 방향키(↑) / `Ctrl + P`:** 내가 불과 1초 전, 10분 전 쳤던 예전 명령어들을 하나하나 역순으로 다시 소환해 커맨드라인에 가져옵니다.
* **`Ctrl + R` (역순 증발 키워드 검색기):** 가장 많이 쓰이는 실무 추적 키입니다. 키를 누르고 `dock` 라는 글자를 입력하기 시작하면, 내가 과거 3개월 동안 쳤던 천만 개의 명령어 장부 중 `docker` 가 포함된 가장 최근의 긴 명령어를 찰나의 AI처럼 끄집어내 눈앞 화면에 대령시킵니다.
* **`!!` (강제 이중 투척):** 방금 내가 쳤던 명령어를 똑같이 타이핑하지 않고 **그대로 한 번 더 살포**실행합니다. (예: 아까 권한 부족 에러를 먹었을 때, `sudo !!` 라고만 치면 앞 명령어를 `sudo` 권한 달고 알아서 붙여넣어 주는 극강의 마법입니다.)
* **`!키워드` :** 예를 들어 `!sys` 치고 엔터 치면, 내가 가장 최근에 친 `sys` 문구로 시작한 명령어(예: `systemctl restart nginx`)를 즉시 발동시킵니다.
