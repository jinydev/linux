# 실무 인프라 클로닝: VMware 로컬 랩핑 (Lab)

개발자의 개인 윈도우 PC(Host) 한 대에, 실제 클라우드와 동일한 수십 대의 리눅스 서버(Guest)를 동시에 띄워 클러스터링을 구성할 수 있게 해주는 마법의 **하이퍼바이저(Hypervisor) 가상화 아키텍처** 입니다.

---

## 1. 하드웨어 프로비저닝 (H/W 할당)

가상머신(VM)을 껍데기만 만드는 것이 아니라, 실제 내 컴퓨터의 물리적 부품(자원)을 떼어서 나눠주는 **프로비저닝(Provisioning)** 작업이 필요합니다.

* **CPU 및 RAM 타협:** 가상머신에 RAM을 4GB 할당하면, 내 윈도우 실제 램에서 4GB가 칼같이 뜯겨 나갑니다. 따라서 Host OS가 죽지 않을 정도의 리소스를 계산에 맞게 분배해야 합니다.
* **동적 확장 가상 디스크 (.vmdk):** 디스크를 100GB 할당했다고 해서 당장 내 C드라이브 용량이 100GB 날아가는 것이 아닙니다. 파일이 찰 때마다 리눅스 디스크 용량이 현실에서도 고무줄처럼 늘어나는 동적 가상화 파일 시스템 패러다임입니다.

---

## 2. 형상 관리 치트키: 스냅샷 (Snapshot)

VMware 엔터프라이즈 기능의 꽃인 **스냅샷(Snapshot)** 입니다. 특정 시점의 리눅스 RAM 메모리 상태와 하드디스크의 블록들을 1초 만에 사진 찍듯 얼려버려 백업본을 만듭니다. 서버 세팅을 망치거나 `rm -rf /` 로 리눅스를 통째로 날려 먹더라도, 스냅샷 버튼 하나면 단 3초 만에 과거의 건강했던 서버 시점으로 시간 여행(Time Warp) 렌더링이 가능합니다.

---

## 3. 네트워크 인프라 스위칭 

클라우드 VPC(Virtual Private Cloud)의 축소판인 가상 랜카드 통신망입니다. 단 1대의 PC에서 공유기 세팅을 마음대로 주무를 수 있습니다.

1. **NAT (네트워크 주소 변환):** 가상 리눅스가 내 윈도우 본체의 IP를 등에 업고 숨어서 바깥 인터넷(구글)으로 나가는 기본 모드입니다. (마치 스마트폰 테더링과 같은 구조)
2. **Bridged (브릿지):** 가상 리눅스가 집 공유기로부터 내 윈도우 본체와 완벽하게 동등한 취급(동일 대역 IP)을 받아 작동합니다. 외부(팀원)에서 접속 가능.
3. **Host-Only (호스트 전용):** 인터넷 랜선을 아예 끊어버리고 본체 PC와 내부 가상머신들끼리만 폐쇄망으로 통신하는 보안 로컬망 모드입니다.

---

## 4. ISO 이미지 마운트 조작

호스트 OS에서 게스트 OS로 파일을 통째로 밀어 넣거나 리눅스를 처음 설치할 때, 예전처럼 USB나 CD를 굽지 않습니다. 
다운로드받은 **`.iso` 확장자 파일** 을 VMware 설정의 가상 CD/DVD 롬에 찾아넣기(Mount)만 하면, 리눅스 안에서는 실제 모터가 달린 CD롬에 물리적 CD를 꽂은 것처럼 시스템 하드웨어 단에서 완벽하게 기만 인식됩니다.
