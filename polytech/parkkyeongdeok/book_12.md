# 터미널 생존의 최전선: Vim (모달 텍스트 에디터)

리눅스 데몬 커널 파일을 수정하거나 SSH 원격 서버에 접속했을 때 마우스는 존재하지 않습니다. 이때 시스템 엔지니어들이 모든 텍스트 코딩과 설정 파일 변경을 초 단위의 해킹 속도로 타건하기 위해 쓰는 만국 공통의 전설적인 **모달(Modal)** 텍스트 에디터입니다.

---

## 1. 3대 패러다임: 모달(Modal) 아키텍처

Vim이 초보자에게 악명 높은 이유는 타자를 치면 글씨가 안 써지고 컴퓨터가 꺼지거나 내용이 지워지기 때문입니다. Vim은 평소엔 **'무기(단축키)를 들고 돌아다니는 상태'** 이고, 오직 특수 버튼을 눌러야만 **'펜을 쥐는 상태'** 로 변신하는 모드 전환형 에디터입니다.

1. **명령 모드 (Normal Mode):** 
   Vim을 켜자마자 마주하는 기본 상태. 글씨가 써지지 않으며 모든 키보드 자판이 **"복사, 삭제, 워프"** 기능을 수행하는 마법의 지휘봉 역할을 합니다.
2. **입력 모드 (Insert Mode):** 
   명령 모드에서 대문자 **`i` (Insert)** 나 **`a` (Append)** 를 누르면 화면 밑에 `-- INSERT --` 꼬리표가 붙으며 비로소 텍스트 메모장처럼 타자가 쳐집니다. 다 썼으면 무조건 **`ESC`** 를 눌러 다시 명령 모드로 탈출해야 합니다.
3. **명령어 라인 모드 (Command-line Mode):** 
   명령 모드에서 **`:` (콜론)** 을 치면 화면 맨 밑바닥으로 커서가 떨어지며 저장, 종료 등 시스템 레벨의 제어 명령어를 먹일 수 있습니다.

---

## 2. 숨쉬듯 외워야 할 명령 모드 생존키 (`ESC` 상태)

마우스를 드래그할 필요 없이 키보드만으로 소스코드를 난도질하는 핵심 단축키입니다. 이 키들은 오직 **명령 모드**에서만 작동합니다.

* **삭제와 잘라내기 (d - Delete):**
  * **`x`**: 내 커서가 위치한 글자 1개 삭제 (마치 Delete키)
  * **`dd`**: 내 커서가 있는 가로 한 줄(Row) 전체를 통째로 잘라내어 파쇄
  * **`5dd`**: 내 커서부터 아래로 5줄을 한꺼번에 싹둑 잘라내기
* **복사와 붙여넣기 (y - Yank / p - Paste):**
  * **`yy`**: 내 커서가 있는 가로 한 줄(Row) 복사 스캐닝 (Ctrl+C)
  * **`p`**: 허공에 잘라내거나(dd), 복사한(yy) 데이터를 내 커서 바로 밑줄에 붙여넣기 (Ctrl+V)
* **되돌리기 (u - Undo):** 
  * **`u`**: 방금 친 타자나 삭제 등의 실수를 과거 1단계 전으로 무한 되돌리기 (Ctrl+Z)

---

## 3. 전역 탐색과 폭격 가이드 (콜론 `:` 환경)

서버 설정 파일의 수천 줄에서 특정 단어를 찾거나, 옛날 도메인을 최신 IP로 싹 다 한방에 갈아버릴 때 사용하는 명령어입니다.

* **저장 및 탈출:**
  * **`:q!`** : 파일을 실수로 망쳐서 1도 저장하지 않고 **강제로 비상 탈출**할 때 (Quit 강제)
  * **`:wq`** : 수정한 코드를 완전히 **저장하고 나서 깔끔하게 종료(탈출)** 할 때 (Write & Quit)
* **패턴 스캐닝 (검색):** 
  * 명령 모드에서 **`/검색어`** (예: `/localhost`)를 치고 엔터를 누르면 그 단어로 워프합니다. **`n` (Next)** 을 누르면 다음 일치 단어로 계속 전진 점프합니다.
* **전역 치환 폭격 (Search and Replace):**
  * 특정 단어를 문서 전체에서 모조리 찾아 다른 단어로 한 번에 치환하는 최강의 폭격 명령입니다.
  * **`:%s/원래단어/바꿀단어/g`** (예: `:%s/Windows/Linux/g` -> 문서 전체의 모든 Windows 글자를 Linux로 강제 개조)
