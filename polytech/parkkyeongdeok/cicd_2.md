# DevOps 자동화 공장의 뇌: CI/CD 플랫폼 툴킷 비교

수동 배포를 끊어내고 개발자가 `git push` 한 코드를 트리거해 자동 빌드/테스트/배포 컨베이어 벨트(파이프라인)를 구동시켜 주는 대표적인 아키텍처 엔진 플랫폼들의 실무 생태계 포지션 맵핑입니다.

---

## 1. 설치형 오픈소스의 제왕: Jenkins (젠킨스)

CI/CD 시장을 개척하고 현재까지도 엔터프라이즈 실무 바닥을 장악하고 있는 늙고 거대한 괴물 엔진입니다.

* **동작 환경:** 클라우드에서 빌려 쓰는 게 아니라, 내가 내 서버 컴퓨터(.ec2 등)에다 직접 젠킨스 자바 데몬을 무겁게 깔아서(설치형 On-Premise) 구동시키는 독재자 아키텍처입니다. 
* **특징 (무한한 확장성과 극악의 관리):** 세상에 존재하는 거의 모든 IT 기술과 결합할 수 있는 수만 개의 플러그인 생태계를 자랑합니다. 다만 너무 무겁고 세팅이 기괴해서, "젠킨스 서버 유지 보수를 위한 전담 노예(DevOps 엔지니어)" 가 따로 필요할 정도로 인프라 짐덩이가 되기 쉽습니다. 

---

## 2. 클라우드 SaaS형 태동: Travis CI

내 서버에 젠킨스라는 무거운 툴을 깔기 싫어하는 모던 개발자들을 위해 등장한 '빌려 쓰는 CI/CD 기계(SaaS)' 의 선구자입니다.

* **동작 환경:** 내가 서버를 팔 필요 없이, 내 GitHub 저장소 최상단 루트에 **`.travis.yml`** 이라는 설정 메모장 파일 딱 하나만 던져두면 끝납니다.
* **특징:** 파일 하나만 감지하면 Travis의 클라우드 중앙 컴퓨터가 알아서 내 Git 코드를 훔쳐가서 지네들 클라우드 CPU로 윙윙 빌드 테스트를 돌려주고 결과만 딱 토해냅니다. 설치형 인프라 유지 보수에서 완벽하게 해방되었으나, Private 저장소 빌드 시 치명적인 과금 폭탄이 발생합니다.

---

## 3. Microsoft의 생태계 폭격: GitHub Actions

현존하는 차세대 오픈소스와 모던 기업의 CI/CD 시장을 모조리 흡수하며 젠킨스를 학살하고 있는 게임 체인저(Game Changer)입니다.

* **동작 환경:** 소스코드를 담아두는 본진인 `GitHub` 에 완전히 초밀착 네이티브로 이식된 CI/CD 엔진입니다.
* **특징 (이벤트 기반 파이프라인):** Travis처럼 `.github/workflows/` 디렉토리에 **`.yml`** 파일을 작성하기만 하면 작동합니다. GitHub 플랫폼 자체가 거대한 트리거(Trigger) 무기 공장이기 때문에, "누군가 코드를 Push 했을 때" 뿐만 아니라 "PR에 특정 라벨이 달렸을 때", "이슈에 특정 댓글이 달렸을 때" 등 무한한 이벤트 상황을 포착해 AWS 배포 서버로 코드를 쏴 올릴 수 있는 막강한 자동화 마법을 무료에 가깝게 제공합니다.

## 4. JetBrains의 고품격 결합: TeamCity

Java의 영혼의 파트너, IntelliJ IDE를 만든 JetBrains 사에서 내놓은 상업용 고성능 지속 적합 CI 엔진입니다.
* **특징:** 압도적으로 유려한 UI와 IntelliJ 에디터와의 환상적인 플러그인 결합을 자랑합니다. 젠킨스 시스템의 혼란스러운 플러그인 지옥을 탈피하여, 돈을 주고라도 "알아서 깔끔하게 돌아가고, 문제 추적이 강력한" 파이프라인을 구축하려는 엔터프라이즈 팀에서 은밀하게 채택합니다.
