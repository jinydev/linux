# 깡통 서버 시대의 종말: 클라우드 컴퓨팅 패러다임 전환

서버실에 수천만 원짜리 장비(Server Rack)를 직접 사서 에어컨을 틀어놓고 10년간 감가상각을 맞으며 감시하던 전통적인 인프라 구축(On-Premise) 시대가 저물었습니다. 그 자리를 대체한, **'거대 IT 기업이 전 세계에 짱박아놓은 무한한 슈퍼컴퓨터 자원을, 마우스 클릭 3번 만에 인터넷으로 훔쳐 쓰고 과금(Pay-as-you-go)하는 클라우드 생태계'** 입니다.

---

## 1. Capex(자본)에서 Opex(운영비)로의 압도적 비용 절감

과거 100만 명의 트래픽을 상정해 수억 원어치 장비를 미리 구매(프로비저닝)하여 썩히던 자본 비용(Capex) 모델을 부수고, **쓴 만큼만 비용을 내는 전기세/수도세 같은 렌탈 모델(Opex)** 로 전향했습니다. 

## 2. 유연성의 극의: 스케일링 (Scaling) 

클라우드의 가장 사기적인 파워입니다. 수강 신청이나 블랙 프라이데이 이벤트가 터졌을 때 클라우드가 없다면 트래픽이 멈추거나 직원이 서버실로 뛰어가 RAM 램 카드를 보드에 증설로 꽂아야 합니다. 하지만 클라우드 컴퓨팅은 클릭(혹은 명령어) 한방으로 **내 서버를 10대로 증식시키고(Scale-out)** 이벤트가 끝난 다음 날 아침 **다시 1대로 축소(Scale-in)하여 요금 과금을 방어**할 수 있습니다. 

## 3. 인프라의 소프트웨어화 (IaC - Infrastructure as Code)

클라우드 시대로 넘어오며, 모니터나 선(Cable)과 같은 `Hardware` 가 전부 `Software` 의 개념으로 스며들었습니다. 웹 상에서 옵션을 고르고 텍스트 코드 몇 줄을 던지면 `aws-cli` 를 타고 날아가 단 3분 만에 아시아, 유럽, 아메리카 땅 위에 진짜 물리적인 데이터베이스 서버와 웹 서버들이 마법처럼 튀어나와 부팅을 시작합니다. 

---

## 4. 정보 처리 시스템 아키텍처의 빙하기와 진화

* **1980년대 (메인프레임 중앙집중):** IBM의 집채만 한 거대 냉장고 크기의 컴퓨터 한 대에, 직원들은 바보(Dummy) 터미널 모니터만 연결해 글자만 쳐서 중앙 뇌를 공유했습니다.
* **1990년대 (클라이언트-서버 분산):** PC의 성능 폭발로, 중앙 서버와 각자의 똑똑한 PC(클라이언트)가 연산력을 나눠먹는 혁명이 일어났습니다.
* **2010년 이후 (클라우드 파라다임):** 지구 어딘가에 숨겨진 추상적인 마법의 뭉게구름(Cloud) 속에 무한한 컴퓨터 심장들이 포진해 있고, 전 세계 어디서든 이 구름에서 번개를 내려받아 1초 만에 서버를 빌려 쓰는 초연결망 시대입니다.
