# 단단한 쇳덩어리를 추상화의 마법으로: 가상화와 컨테이너

물리적인 쇳덩어리 기계(HW) 부품의 한계를 깨부수고, 이를 모래알처럼 쪼개어 1대의 기계를 100대로 둔갑시키거나(Virtualization), 100대의 기계를 1대로 융합해 버리는(Clustering) 클라우드 세상의 기반 코어 마법술입니다.

---

## 1. 서버 공간 절단술: 하이퍼바이저형 가상화

과거 전통적인 서버는 쇳덩이 컴퓨터 1대 위에 리눅스 1개만 올려 쓸 수 있어 공간 낭비가 끔찍했습니다.
하지만 쇳덩이(HW) 바로 위에 **VMware(vSphere), KVM, Xen** 이라는 마법의 필터(Hypervisor)를 깐 순간, 그 필터 위에 작은 가상의 가짜 조립 컴퓨터들을 여러 대 올려 각각 독립된 Guest OS(리눅스, 윈도우 등)를 구동시킬 수 있게 되었습니다. (AWS EC2의 기원이 되는 아키텍처입니다.) 

## 2. 혁명의 도래: Docker (컨테이너 가상화)

하이퍼바이저의 무거운 악몽(미니 서버마다 또 OS 뇌를 탑재해야 해서 RAM을 끔찍하게 퍼먹음)을 박살 낸 인류 최고의 아키텍처입니다.

* **동작 원리 (격리 격벽):** 
  무거운 호스트 가짜 OS 패키지를 전부 버립니다. 기존 리눅스 커널 심장 딱 1개만 돌리되, 애플리케이션 주변에 **'투명한 어항(Container) 캡슐 벽'** 을 칩니다. OS 입장에서는 그저 프로세스 1개가 도는 격이지만, 컨테이너 안 공간은 자기가 완전히 격리된 우주인 줄 착각합니다. 
* **승리 이유:** 극강의 깃털 같은 가벼움, OS 부팅이 필요 없는 0.1초의 초광속 시작, 내 로컬 개발 PC의 컨테이너를 복제해 상용 AWS 서버에 던져 넣어도 100% 똑같이 렌더링 돼서 구동하는 미친 호환성 패러다임을 열었습니다. 

---

## 3. 네트워크의 유체이탈: VLAN 과 VPC (Virtual Private Cloud)

* **VLAN (가상 L2 스위치 분할):** 하나의 랜 스위치 장비 라인에, 스위치 칼집 구멍을 쪼개 논리적으로 완전히 부서가 다른 사설망 인터넷 2개로 물리적 단절 효과를 내는 기술입니다.
* **VPC (아마존 속의 내 방):** 클라우드의 핵심 중 핵심입니다. 아마존 남의 집 데이터센터(퍼블릭) 한가운데에 투명한 보안 장막(Private)을 치고 나만의 작은 전세방(VPN 영역)을 구축합니다. 이 공간 안쪽은 나만 접근 명령어를 치고, 구글/네이버 같은 바깥 트래픽 공격은 모두 튕겨내는 가상의 독재 국가가 됩니다.

---

## 4. 클라우드 네이티브를 관통하는 Serverless (서버리스)

클라우드 세상이 만들어 낸 차세대 최종 비경(祕境)입니다. "서버가 없다"는 게 아니라, **"개발자인 내 눈엔 서버 기계가 안 보일 정도로 추상화됐다"** 는 사상입니다. 

* **기존 방식:** 내가 직접 리눅스 AWS 터미널에 로그인해서 접속을 유지하고 항상 에어컨을 켜놓고 24시간 풀가동 비용을 지불해야 했습니다.
* **서버리스 (AWS Lambda):** 아마존 어딘가의 보이지 않는 공간에 내 소스코드 텍스트 쪼가리 함수망만 딱 올려놓습니다 (접속할 OS도, 데몬도 없습니다). 누가 내 사이트에 이미지를 업로드(Event Trigger)하는 찰나의 순간에만, 아마존 서버가 잠깐 1초 잠에서 깨어나 코드를 실행(렌더링)하고 다시 죽어버립니다. 즉 연산이 돌아간 그 '마이크로 밀리초(0.001초)' 만큼만 비용을 과금당하는 충격적인 미니멀리즘 아키텍처입니다.
