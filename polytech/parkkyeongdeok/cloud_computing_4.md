# 구름 위를 지배하는 맹수: AWS 핵심 서비스 대동여지도

클라우드 점유율 절대 1위 인프라의 권력자, 아마존 웹 서비스(AWS)의 광대한 대시보드 속에서 백엔드 엔지니어들이 설계도를 그릴 때 조합해 쓰는 코어 서비스 컴포넌트 5대장 맵핑입니다.

---

## 1. 컴파일 연산 뇌 파워 (Compute)

* **Amazon EC2 (Elastic Compute Cloud):** 
  AWS의 알파이자 오메가입니다. 주문형으로 몇 초 만에 하늘에서 뚝 떨어지는 **빈 깡통 리눅스 가상머신 기계(IaaS)** 입니다. 사용자는 여기에 SSH 원격 접속 터널을 뚫어 맘대로 해킹/개발 환경을 띄웁니다.
* **Auto Scaling (오토 스케일링 복제술):** 
  단순한 EC2 1대를 명품으로 만드는 기적의 컴포넌트. 블랙 프라이데이 트래픽의 과부하(CPU 사용량 상승 등)를 감지하면, 백그라운드 인프라가 스스로 EC2 서버 10대로 자동 증식(Scale-out) 시키고, 밤이 되면 1대로 다시 축소시켜 과금을 예방하는 신의 방패막입니다.
* **Amazon ECS & EKS (컨테이너 오케스트레이터 지휘관):** 
  내가 만든 100개의 Docker 투명 어항 캡슐(컨테이너)을 거대한 선박에 싣고 항해할 때, 도커들이 죽으면 살려내고 로드밸런싱을 배분해 주는 군대 지휘관 패키지 툴(도커 클러스터/쿠버네티스 엔진)입니다.
* **AWS Lambda (서버의 죽음, 서버리스):** 
  OS 깡통 서버를 유지할 노력조차 지워버린 코드 덩어리입니다. 접속자가 특정 행동을 했을 때만 함수 코드 쪼가리가 1초 동안 짜릿하게 동작하고 사망하는 Trigger 파이프라인 엔진입니다.

---

## 2. 저장소의 블랙홀 (Storage)

* **Amazon S3 (Simple Storage Service):** 
  지구상에서 절대 파괴 불가능한 불사신의 객체(Object) 무한 스토리지 바다입니다. 넷플릭스의 동영상, 웹사이트의 이미지(jpg) 파일들이 끝도 없이 거대하게 적재되며, 데이터가 삭제될 확률(내구성)이 99.999999999% 라는 극악의 안전성 보험을 자랑합니다. (HTTP 렌더링 호출 접근 지원)
* **Amazon EBS (Elastic Block Store):** 
  가상 머신 깡통인 EC2에 진짜 '하드디스크(SSD)' 부품을 꽂아 물리적으로 물려주는(Mount) 가상 볼륨 블록입니다.

---

## 3. 영구 저장을 위한 데이터베이스 (Database)

* **Amazon RDS (Relational Database Service):** 
  오라클(Oracle), MySQL, MS-SQL 등 우리가 아는 전통적인 SQL 기반 데이터베이스 서버를 아마존이 대신 다 세팅해서 자동 백업까지 관리해 주는(PaaS 화 된) 매니지드 DB 서비스입니다.
* **Amazon DynamoDB (무한 확장 NoSQL):** 
  SQL의 외래 키(Join 구조) 제약을 박살 내고, 읽기/쓰기가 1초에 천만 번씩 터져도 스케일링으로 무한하게 버텨내는 아마존 흑마법의 1차원 Key-Value 데이터베이스입니다. 게임 로그 저장이나 세션 상태 메모리로 주로 쓰입니다.

---

## 4. 트래픽의 수문장 및 우주 격리 (Networking)

* **Amazon VPC (가상 전세방 격리):** 
  전 세계가 공유하는 아마존 내부에서, 오직 나만의 암호화된 `10.0.0.0/16` C클래스 IP 대역과 외부 구글망 차단 방화벽 라우팅 테이블(Private Subnet)을 완벽 지정해 주는 **독립된 섬(망분리) 인프라** 입니다. 여기 안에 둔 DB는 절대 밖에서 해킹으로 접근할 수 없습니다.
* **Elastic Load Balancer (ELB - 로드 밸런서 교통순경):** 
  `www.kakao.com` 으로 고객 1만 명이 동시 접속을 쏠 때, 내 서버 10대의 앞단 문지기로 서서 1,000명씩 정확하게 트래픽을 나눠 담아 찢어주는(부하 분산) 최전방 트래픽 폭파 지휘관입니다. L4 단(포트 분산)과 L7 단(URL 분산)을 정밀하게 제어합니다.
