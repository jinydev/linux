# CPU 주도권의 강제 박탈 아키텍처: 인터럽트 (Interrupt)

단일 뇌(CPU)가 돌아가는 현대 폰노이만 구조의 컴퓨터 세계에서, CPU가 무한루프(1+1 반복 계산)에 빠져 모든 시스템이 먹통이 되는 재앙을 막고 무작위로 날아오는 마우스/키보드의 입력에 실시간 반응하게 만드는 유일한 해결책, 바로 **"하던 일을 강제로 멈추고 내 말부터 들어!!!" 라고 뇌파를 찌르는 인터럽트(Interrupt) 메커니즘** 입니다. 

모든 현대 운영체제(OS)는 100% 인터럽트의 연속적인 호출로만 구동(Interrupt-Driven)되는 수동적인 껍데기에 불과합니다.

---

## 1. 운영체제 공간 권한의 철벽 격리 (Dual-Mode)

해커나 악성 프로그램 유저가 CPU를 영원히 장악하는 것을 막기 위해 하드웨어 칩셋(Mode Bit) 단계에서부터 세상의 계급을 둘로 찢어놓았습니다.

* **User Mode (사용자 권한 / 평민):** 일반적인 게임, 크롬 브라우저 프로그램들이 도는 껍데기 세상입니다. 여기서 함부로 랜카드를 끄거나 하드디스크의 파일 시스템을 강제할 수 없습니다. 
* **Kernel Mode (운영체제 권한 / 신):** 오직 무소불위의 권한을 가진 '운영체제(Linux 커널)' 만이 상주하는 신의 공간입니다. 일반 평민 프로그램이 파일 저장을 하고 싶으면, 이 커널 공간의 문을 두드리며 System Call(시스템 호출 제물)을 바쳐야만 OS가 대신 파일을 써주고 빠져나옵니다.

---

## 2. 하드웨어 인터럽트 vs 소프트웨어 인터럽트 (Trap)

누가 CPU 연산 뇌파를 찔러서 멈추게 만들었는지에 대한 기원 분류입니다.

* **HW 하드웨어 인터럽트 (전기 충격):** 
  키보드를 치는 순간, 타이머 시계가 울린 순간, 랜카드에 패킷이 들어온 순간. 메인보드의 물리적인 칩셋에서 CPU 핀(회로)으로 전기 신호(신경망)를 강제로 쏴서 현재 하던 코딩 연산을 도끼로 끊어버립니다. 
* **SW 소프트웨어 인터럽트 (Trap / Exception / System Call):** 
  프로그램이 돌다가 0으로 나누기(Divide by zero) 에러 같은 치명적 자폭 에러를 일으키거나, 아까 말한 보안 구역(Kernel)에 일반 프로그램이 "하드디스크에서 파일 좀 빼주세요(I/O)" 라고 OS를 대신 깨울 때 코드로 발동시키는 소프트웨어적인 자해/호출 신호입니다. 

---

## 3. 인터럽트의 피비린내 나는 타임라인 (Context Switching)

키보드의 'A' 키를 누른 찰나의 0.0001초 동안 리눅스 뱃속에서는 숨 막히는 권한 박탈 및 복원 전쟁이 일어납니다.

1. **저격 (인터럽트 발생):** CPU가 사용자 크롬 브라우저 코드를 행복하게 계산하던 도중, 키보드 컨트롤러 칩셋에서 'A 키가 눌렸음' 전기 신호가 CPU에 꽂힙니다.
2. **동작 정지와 냉동 보관 (Context Save):** CPU는 즉각 브라우저 실행을 멈추고, 자신이 방금 전까지 계산하던 모든 메모리 상태(레지스터 값, 스택 포인터)를 프로세스 대피소 패키지(PCB - Process Control Block)에 안전하게 얼려서 박제시킵니다.
3. **주도권 스틸과 인터럽트 벡터 탐색:** 커널 모드(신)로 권한이 강제 변경되며 운영체제(OS)가 깨어납니다. OS는 '인터럽트 벡터(Vector) 메뉴판' 을 뒤져서 '아, 키보드 신호구나. 48번 인터럽트 살해 코드 번호를 실행해!' 라며 주소(ISR - Interrupt Service Routine)를 찾아냅니다. 
4. **대리 처리 (ISR 실행):** 해당 주소로 워프해 'A' 키값을 모니터에 뿌려주는 운영체제 데몬 코드가 미친 듯이 실행 발동됩니다.
5. **제자리로 복원 (Restore):** 키보드 입력 처리가 다 끝났다면, 아까 2번에서 얼려뒀던 크롬 브라우저 메모리 상태를 CPU로 다시 부어 넣고(Restore), 다시 User Mode(평민)로 돌아온 뒤 과거 타임라인에서 크롬을 아무 일 없었다는 듯이 재실행 연산시킵니다.
