# 파일 시스템 전체 스캐닝: find & locate

리눅스 서버에서 수십만 개의 로그 파일이나 소스 코드 속에서 내가 원하는 그 파일을 0.1초 만에 색인해 내는 기술입니다. 마이크로소프트 윈도우의 '돋보기' 아이콘과는 비교도 안 되는 정밀한 쿼리(Query)를 터미널 상에서 던질 수 있습니다.

---

## 1. DB 기반 초고속 색인: `locate`

가장 빠르고 단순한 추적기입니다. 

* **작동 원리:** 내 하드디스크를 무식하게 처음부터 끝까지 다 뒤지는 것이 아니라, 리눅스 백그라운드 데몬이 새벽마다 파일들의 이름과 경로를 장부(DB)에 미리 싹 다 적어놓습니다. `locate` 를 치면 그 장부(DB)만 뒤지기 때문에 검색 속도가 0.001초 만에 빛의 속도로 튀어나옵니다.
* **치명적 한계:** 오늘 방금 새로 만든 파일은 내일 새벽에 장부가 갱신될 때까지 `locate` 로 절대 찾을 수 없습니다. (물론 `updatedb` 명령어를 강제 실행해 장부를 수동 동기화시킬 수 있습니다.)

```bash
# 시스템 내의 'zip' 단어가 들어간 파일의 전체 경로를 초광속으로 색인
$ locate zip

# 검색된 파이프라인 출력을 grep으로 다시 필터링 (bin 폴더 내의 zip만 추출)
$ locate zip | grep bin
```

## 2. 무식하지만 가장 강력한 추적기: `find`

장부(DB)를 보지 않습니다. 무조건 내가 지정한 폴더부터 그 뼛속 하위 폴더 끝까지 내려가면서 하드디스크의 모든 쇳덩어리 블록을 실시간 물리 스캐닝하며 찾아냅니다.

* **최강의 정밀 옵션:** 파일 이름뿐만 아니라 "어제 만들어진 파일", "용량이 1GB가 넘는 파일", "소유자가 root인 파일" 등 메타데이터를 기반으로 한 극한의 필터링이 가능합니다.

```bash
# 기본 사용법: [경로] [옵션] [조건] [액션]

# 내 홈 디렉토리(~) 밑에 있는 모든 항목의 갯수를 카운트 (파이프라인 연계)
$ find ~ | wc -l

# 타입 필터링: 디렉토리(d)만 찾아라
$ find ~ -type d

# 타입 필터링: 파일(f)만 찾아라
$ find ~ -type f
```

### [실무 엔지니어의 find 필터링 조건식]
* **`-name "*.log"`**: 확장자가 `.log`로 끝나는 파일 이름 검색.
* **`-size +10M`**: 파일 크기가 10MB 이상(+)인 엄청 큰 파일만 적발.
* **`-perm 0644`**: 파일 권한이 정확히 644인 것만 색출.
* **논리 연산 조립:** `\( -type f -not -perm 0600 \)` (권한이 600이 아닌 쓰레기 파일 찾기 등 복잡한 AND/OR 쿼리 조립 가능)

## 3. 추적과 동시에 처형: find 액션 (-exec / -delete)

`find` 가 단순히 리스트만 출력하는 데 그친다면 실무에서 쓰지 않습니다. 찾아낸 그 수백 개의 파일을 잡아다가 그 자리에서 압축하거나 잘라내거나 삭제해 버리는 자동화 액션을 먹여야 합니다.

```bash
# 1. 찌꺼기 파일 자동 청소기 (-delete)
# 끝자리가 .BAK 인 백업 쓰레기 파일을 모두 찾아내서 묻지도 따지지도 않고 삭제
$ find / -type f -name '*.BAK' -delete

# 2. 커스텀 명령어 강제 주입 (-exec)
# *.log 파일을 찾은 뒤, 그 파일들을 하나씩 rm -f [파일명] 명령어 안에 집어넣어 강제 삭제
$ find /var/log -type f -name '*.log' -exec rm -f {} \;
```
*(주의: `-exec` 액션은 찾아낸 파일 목록 전체를 대상으로 파괴적인 커맨드를 일괄 수행할 수 있으므로, 실행 전 액션을 빼고 리스트만 먼저 눈으로 확인하는 것이 생존 철칙입니다.)*
