# 리눅스의 신경망 통제실: /etc 디렉터리와 계정 구조

윈도우는 설정값을 `레지스트리(Registry)`라는 숨겨진 복잡한 시스템 DB에 저장해 마우스로 클릭해야만 조작할 수 있습니다. 하지만, 리눅스의 철학은 **"우주의 모든 설정은 모조리 텍스트(Text) 파일일 뿐이다"** 입니다.
리눅스의 생사를 가르는 최고 핵심 환경 설정 파일들은 전부 **`/etc` (Etcetera)** 디렉터리 안에 평문 마크다운처럼 널부러져 있습니다.

---

## 1. 계정 인증의 최전방 뼈대: `/etc/passwd`

서버에 접속하려는 '사람'과 뒷단에서 시스템을 돌리는 '데몬 유령(apache, mysql)'들의 호적 등본 대장입니다. 

* **권한:** 모든 사용자가 읽을 수 있지만(비밀번호가 안 적혀 있으니까), root 신만이 수정할 수 있습니다.
* **텍스트 아키텍처 라인:**
  `userid:x:14:50:FTP This is test User:/var/userid:/sbin/nologin`
  *(콜론 `:` 으로 파이프라인 데이터 구역이 찢어져 있습니다.)*
  1. `userid` : 로그인하는 사람의 문자 아이디
  2. `x` : 예전엔 여기에 비밀번호가 직접 적혀있어 해킹이 빗발쳤으나, 지금은 "x" 로 치환하고 진짜 비밀번호는 뒤의 `shadow` 파일 지하실에 숨겨놨다는 증거입니다.
  3. `14` : UID (시스템이 사람을 구분하는 진짜 주민등록번호)
  4. `50` : GID (소속된 조직 그룹의 등본 번호)
  5. `설명` : 코멘트
  6. `/var/userid` : 로그인 시 뚝 떨어지는 홈 스위트 홈(디렉토리 위치)
  7. `/sbin/nologin` : 지급받는 셸(Shell/무기). `/bin/bash` 면 터미널 명령어를 칠 수 있고, `nologin` 이면 평생 해킹 접속을 튕겨내는 데몬 전용 셸입니다.

## 2. 해시 암호화 지하실: `/etc/shadow`

`passwd` 에서 밀려난, 전 세계 최강의 SHA-512 해시 함수 단방향 암호화 비밀번호들이 갇혀 있는 절대 철통 보안의 금고입니다. 

* **권한:** 일반 평민 계정은 읽기조차 거부(Permission Denied) 당하는, 오직 root 소유의 1급 기밀문서입니다.
* **텍스트 아키텍처 라인:**
  `francis:$6$fislf2R$R45trhertsdfs...:18119:0:99999:7:::`
  1. `francis` : 사용자 아이디
  2. `$6$fislf...` : 솔팅(Salting)이 가미된 흉악한 해시 비밀번호 난수 텍스트. 절대 사람의 눈으로 원래 비밀번호를 역산해 복호화할 수 없습니다. 
  3. `18119` : 비밀번호 최근 변경 날짜 표기 타임스탬프
  4. `최소/최대 사용, 경고, 만료일` : 엔터프라이즈 환경에서 직원이 "비번 90일 지났으니 당장 바꿔라" 고협박하는 트리거 수치값들입니다.

## 3. 부서 권한 통제실: `/etc/group` 과 `/etc/gshadow`

리눅스는 사용자 개개인에게 권한을 주지 않고, 여러 사용자를 묶어 '개발팀', '운영팀' 등 그룹(Group) 단위로 디렉토리 접근 권한을 뿌리는 것이 인프라 관리의 핵심입니다.

* **`/etc/group` :** 
  `mail:x:12:mail,postfix` 처럼 특정 그룹(mail)의 아이디(12)와, 이 그룹 소속으로 묶여있는 멤버 사용자 목록 텍스트를 나열해 둡니다.
* **`/etc/gshadow` :** 
  특정 그룹 공간에 진입하기 위해 알아야 하는 그룹 전용 비밀번호(해시)와 관리자 권한을 매핑한 그룹 권한 보안 지하실 파일입니다.
