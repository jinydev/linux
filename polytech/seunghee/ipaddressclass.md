# 인터넷 바다의 절대 좌표계: IP (Internet Protocol) 아키텍처

내가 브라우저에 카카오톡 메시지를 입력하면 구리 랜선을 타고 미국, 아시아 대륙 해저 케이블을 넘어서 상대방의 컴퓨터로 그 비트 쪼가리들이 정확하게 날아가야 합니다. 거대한 전 지구적 라우터 망(Network)에서 내 데이터 패킷이 길을 잃지 않도록 봉투 겉면에 적어 넣는 32비트짜리 논리적 주소가 바로 **IP(인터넷 프로토콜)** 입니다.

---

## 1. 주소 체계 파탄 위기와 IPv6의 등장

* **IPv4 아키텍처:** `192.168.0.1` 처럼 32개의 0과 1비트로 쪼개어 쓰는 현재 우리가 아는 전통적인 주소. 문제는 만들 수 있는 집 주소의 개수가 약 43억 개가 한계인데, 지구상의 스마트폰과 냉장고, 자동차들까지 전부 인터넷 주소를 요구하기 시작하며 공인 주소가 바닥나버리는 재앙(IP 고갈)이 터졌습니다.
* **IPv6 무한 스케일 아웃:** 아예 주소 길이를 128비트로 극한까지 늘려버린 차세대 주소 체계입니다. 이제 16진수를 써서 `2001:0db8:85a3...` 처럼 끔찍하게 길게 씁니다. 우주의 모든 돌멩이마다 IP 주소를 부여해도 남을 만큼 미친 확장성 스펙을 구축했습니다.

---

## 2. 특수 예약 주소: 네트워크 ID와 브로드캐스트

만약 내가 256개의 IP(`192.168.1.0 ~ 255`)를 할당받는 구역을 샀다고 해서 내 컴퓨터에 256개를 다 쓸 수는 없습니다. 2개는 하늘이 두 쪽 나도 설정 못하게 시스템이 막아버립니다. 

1. **네트워크 주소 (맨 앞 번호 - 192.168.1.0):** 
   이 IP 구역 집합소 덩어리의 '대표 이름 표지판' 입니다. 특정 개인 PC에 줄 수 없습니다.
2. **브로드캐스트 주소 (맨 뒷 번호 - 192.168.1.255):** 
   해당 네트워크 구역에 있는 모든 254대의 PC 컴퓨터들에게 한 방에, 공지사항 방송을 강제 송신(Broadcast)할 때 통으로 찌르는 사이렌 통신 전용 주소입니다. 

---

## 3. 계급사회 공간 분할: IP 클래스 (Class A~E)

군대나 학교의 규모에 따라서 IP 주소 공간을 무식하게 쪼개 배분하던 옛날의 주소(서브네팅) 구획 분할 체계입니다. 총 5개 계급장으로 찢어집니다.

* **A 클래스 (초거대 그룹):** `0.0.0.0 ~ 127.255.255.255`
  앞자리 1칸만 그룹 이름이고 뒤 3칸을 싹 다 PC 번호로 쓸 수 있어서 무려 1,600만 대의 컴퓨터를 입주시킬 수 있는 국가기관/글로벌 대기업용 권역.
* **B 클래스 (대형 그룹):** `128.0.0.0 ~ 191.255.255.255`
  앞 2칸이 그룹, 뒤 2칸이 PC 번호로, 6만 5천 대 컴퓨터를 박아 넣을 수 있는 중견망.
* **C 클래스 (영세 소그룹):** `192.0.0.0 ~ 223.255.255.255`
  우리가 가장 친숙한 대역. 앞 3칸이 그룹 이름이고 맨 뒤 1칸만 PC 번호라 고작 254대의 컴퓨터 IP만 짤짤이로 나눠 쓸 수 있는 동네 PC방 랜망. (D와 E 클래스는 연구, 멀티캐스트용으로 봉인되어 못 씁니다).

---

## 4. IP 고갈의 방어막: 공인(Public) IP와 사설(Private) IP

인터넷 IP 43억 개 고갈 사태를 방어하기 위해 집집마다 깔려 있는 'IP 복제 증식기' 가 바로 와이파이(공유기/NAT)입니다.

* **공인 IP (Public IP - 네이버 IP확인):** 인터넷 세상 밖에서 유일하게 돈 내고 할당받은 단 1개의 진짜 절대 주소입니다 (공유기 바깥 피부). 
* **사설 IP (Private IP - cmd 로컬 IP):** 공유기가 안방에서 자기 마음대로 10.x.x.x 나 192.168.x.x 로 뻥튀기시켜 집안 스마트폰, 노트북 500대에 가짜로 찍어준 무의미한 내부용 주소입니다. 이 사설 IP로는 우리 집안에서 거실 컴퓨터끼리만 통신할 수 있으며, 이 IP 그대로 인터넷 바다로 나갔다가는 즉시 패킷이 증발당합니다.
