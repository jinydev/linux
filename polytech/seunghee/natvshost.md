# 사설 IP 자원 통제와 망 분리: 가상 네트워크 (NAT & Host-Only)

로컬 윈도우 한 대에 여러 대의 리눅스 가상머신(클러스터 서버)을 돌려야 할 때, 부족한 공유기 IP를 아끼거나 해킹을 원천 차단하기 위해 사용하는 가상 네트워크 통신 아키텍처 토폴로지(망 구성도) 기법입니다.

단순 '어댑터 브리지(Bridged)' 방식은 물리적 공유기에서 내 Host PC와 동등한 IP를 따내어 외부 접근이 가장 쉽지만, VM이 20-30대로 늘어나면 공유기의 IP 풀 대역이 고갈되는 치명적인 한계가 발생합니다. 이를 회피하는 기법들입니다.

---

## 1. NAT (Network Address Translation): 기생형 공인 IP 핑퐁 

가장 범용적인 테더링 통신망 구축 방식입니다. IP 주소를 마구잡이로 가상 리눅스들에게 뻥튀기해 뿌리기 위해 사용하는 주소 변환 은폐 기술입니다.

* **동작 맵핑 렌더링:** 가상 리눅스 내부에서는 가짜 사설 IP 주소(`10.0.2.15` 등)를 할당받아 쓰지만, 패킷이 인터넷 밖 세계(구글)로 나갈 때 내 윈도우 본체 Host의 IP 주소로 신분을 위장(Translation)시켜서 튀어 나갑니다.
* **보안적 특성 (인바운드 차단):** 리눅스 VM은 바깥을 향해 카톡, 핑 등 뭐든 자유롭게 나갈 수 있지만, 정작 바깥 인터넷망의 해커가 내 리눅스 서버로 접근하려고 IP를 찌르면(Inbound) NAT 게이트웨이 방어벽(방향 상실)에 막혀 튕겨 나갑니다. (포트포워딩 수술이 필요합니다.)

---

## 2. Host-Only (호스트 전용): 극악 보안의 로컬 폐쇄망

모든 컴퓨터의 외부 랜선(인터넷)을 가위로 싹둑 잘라버리고 고립시키는 오프라인 폐쇄망 구축 방식입니다.

* **동작 맵핑 렌더링:** 외부망(구글 통신)이 완전히 끊어지며, **오직 내 윈도우 본체(Host PC)와 가상 리눅스 군단들끼리만 끼리끼리 통신**하는 진정한 우물 안 개구리 샌드박스로 구축됩니다.
* **실무 활용도 (DB 은폐망):** 실제 해킹 방어가 절대적인 코어망(금융 거래 DB) 서버 렌더링 구축 시, 바깥에서 긁어 들어오는 외부망 IP를 원천 차단하기 위해 이 형태의 폐쇄망 아키텍처를 뒤쪽에 격리 세팅해 보호막제로 응용합니다.
