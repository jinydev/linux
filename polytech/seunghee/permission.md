# 파일 렌더링 통제 철학: 권한(Permission)과 `chmod`

리눅스는 서버를 여러 팀원(해커 포함)이 공유하는 멀티 유저 시스템입니다. 내 소스코드 파일이나, 시스템의 코어 설정이 악의적으로 파괴되는 것을 막기 위한 가장 밑바닥 쇳덩어리 접근 통제 아키텍처가 권한(퍼미션)입니다.

---

## 1. 3계급 3권한의 9자리 폭주 행렬

파일 하나에 접근할 권리가 **'본인 / 속한 부서 / 쌩판 남'** 이라는 3등급으로 나뉘며, 행동 제어도 **'읽고 / 쓰고 / 무기실행'** 이라는 3타입으로 쪼개져 3x3=9 비트 비트로 철저하게 단절 관리됩니다. 이를 `ls -l` 로 조회하면 마주하게 됩니다.

`[rwx] [r-x] [r--]` = 9자리 권한 렌더링

### [계급 분할티어 (Who?)]
1. **u (User/Owner):** 
   이 파일을 생산한 주인장입니다. (`rwx` 자리 배치)
2. **g (Group):** 
   주인장과 같은 회사 부서/팀 그룹에 속해있는 직원들입니다. (`r-x` 자리 배치)
3. **o (Other):** 
   어디서 들어왔는지 모를 익명의 쌩판 타인 해킹 계정입니다. (`r--` 자리 배치)

### [행동 통제권 (What?)]
* **`r (Read, 4)` :** 파일을 읽을 수 있습니다. (디렉토리에선 `ls`로 내부 파일 목록을 까볼 수 있는 권리)
* **`w (Write, 2)` :** 코드를 수정/삭제할 수 있는 위험한 권리입니다. (디렉토리에선 디렉토리 밑에 새 파일을 복사해 넣고 지울 수 있는 권리)
* **`x (Execute, 1)` :** 쉘 스크립트(.sh) 파일을 프로그램화해서 실행시킬 수 있는 코어 권한입니다. (가장 중요: **디렉토리에서 `x` 가 없으면, 겉에서 보이기만 할 뿐 `cd` 명령어를 박고 그 폴더 방으로 걸어 들어갈 진입 자체가 차단당합니다**)

## 2. 8진수 해킹 연산을 통한 `chmod` 권한 부여법

실무 서버의 파일 권한을 갈아치울 때는 위에서 본 글자를 더하거나 빼는 직관적인 명령어 대신, 2진수를 8진수로 압축해 쓰는 폭격 명령어 타건 스킬을 기본 상식으로 강제합니다.
`r=4`, `w=2`, `x=1` 숫자를 더한 결괏값만 계급별로 던져주면 퍼미션을 한방에 갈아 끼웁니다.

```bash
# 777 (4+2+1 / 4+2+1 / 4+2+1)
# 극악의 보안 구멍: 누구나 읽고 쓰고 파괴(실행)할 수 있는 무정부 상태 부과
$ chmod 777 target_file.sh

# 644 (4+2=6 / 4 / 4)
# 웹 서버의 기본 권한 렌더링: 나는 읽고 쓰고 다 하지만, 일반 타겟 유저들은 오직 조회 읽기(4) 무해한 상태로만 열어주는 형태
$ chmod 644 index.html

# 755 (4+2+1=7 / 4+1=5 / 4+1=5)
# 리눅스 스크립트 실행의 표준 교과서: 나는 다하지만, 남들은 텍스트 수정 파괴(w)는 불가능하고 오직 프로그램 모듈 구동 실행(r,x) 버튼만 열어주는 형태 
$ chmod 755 run.sh
```

## 3. 기호 문자(`+, -, =`)를 이용한 섬세한 외과 메스 절개법

특정 상대의 특정 권한만 핀포인트로 빼앗거나 부여할 때 씁니다.

```bash
# 그룹(g) 과 타인(o) 에게서 쓰기(w)와 실행(x) 무기를 모조리 박탈(빼기)
$ chmod go-wx target.txt

# 유저 본인(u) 한테 읽기/쓰기/실행 권한 3신기를 전부(=) 완전 치환 강제로 초기 부여
$ chmod u=rwx root_script.sh

# 디렉토리(-R 자비 없는 재귀 롤백) 포함 하위 모든 파일들의 퍼미션을 755로 갈아엎는 학살 옵션
$ chmod -R 755 /var/www/html/
```
