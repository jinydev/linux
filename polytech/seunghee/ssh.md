# 인프라 암흑 터널링 통신: SSH (Secure Shell) 아키텍처

아마존 밀림 데이터센터에 박혀있는 AWS 리눅스 서버를 제어하기 위해, 한국 내 방에서 키보드를 치면 지구 반대편의 검은 터미널 창(Shell)에 명령어가 입력되는 원격 제어 기술입니다. 구시대 유물인 텔넷(Telnet), FTP가 비밀번호를 날것 평문으로 전송하다 해커들의 와이어샤크 스니핑 패킷 감청에 털려 멸종당한 후 나타난, **"전 우주에서 가장 완벽한 암호화 무결성 네트워크 터널"** 인 SSH(Secure Shell) 통신 표준입니다.

---

## 1. 비밀번호의 파괴: 비대칭 마법의 열쇠 (Key-Pair)

SSH의 가장 강력한 코어 패러다임은, 로그인할 때 키보드로 타이핑하는 **'비밀번호라는 존재 자체를 시스템에서 영구 파기(Password-less)'** 해 버린다는 점입니다. 비밀번호 탈취 브루트포스 해킹 자체를 무효화시키고 한 쌍으로 쪼개진 암호키 인증서 렌더링 파일로만 서버를 통과시킵니다.

* **Public Key (공개키 - 도어락 자물쇠):** 
  남들에게 동네방네 퍼트려도 되는 무해한 키입니다. AWS 리눅스 서버를 세팅할 때 제일 먼저 이 `공개키 자물쇠` 덩어리를 서버(SSH 허가 폴더) 문 앞에 걸어둡니다. 이 자물쇠로 문을 '잠글 수' 만 있고, 여는 것은 불가능합니다.
* **Private Key (개인키 / PEM 키 - 절대 권력 열쇠):** 
  USB나 내 윈도우 본체 하드디스크 깊숙한 곳에 혼자 꽁꽁 숨겨두는 유일무이한 열쇠 조각(`*.pem`, `id_rsa`)입니다. 이 키가 외부에 털리면 인프라 전체가 폭파당합니다. 오직 이 'Private Key' 파일만이 서버에 달린 Public Key 자물쇠를 '열고(복호화)' 터미널로 뚫고 들어갈 영구 권한을 갖습니다.

## 2. SSH 프로토콜 렌더링의 실무 파이프라인

단순 서버 접속뿐만 아니라 GitHub의 코드 푸시나 다른 응용 시스템들도 이 SSH 터널링 포트(기본 22번 TCP 포트)를 기반으로 거대한 보안 데이터 송수신을 구축하고 있습니다.

### [원격 쉘 명령어 지배 (Login & Exec)]
비밀번호 없이 개인키를 흔들어 AWS 서버에 잠입하는 명령어입니다.

```bash
# 기본 접속 룩업 (Private key 명시 안 함 - ssh-agent 동작)
$ ssh ubuntu@192.168.10.50

# 내 PC에 숨겨둔 .pem 개인키 폭탄 조각을 강제로 삽입해 AWS 서버 강제 오픈 
$ ssh -i ./my-secret-key.pem ec2-user@aws-ip-address

# 서버 접속 창으로 완전히 들어가지 않고, 밖에서 'ls' 명령어 결과값 하나만 훔쳐오기 (단발성 원격 쿼리)
$ ssh ubuntu@192.168.10.50 ls -al
```

### [무결점 보안 데이터 전송 컨테이너 복사 (SCP)]
FTP 텔넷 따위 대신, SSH 터널링 안으로 데이터 전송 객체를 넣어서 양자 암호화로 날려 보내는 파일 투척 매커니즘입니다.

```bash
# 내 PC의 index.html(Local) 을 원격 서버의 /var/www 위치에 안전 밀수입 강제 복사 
$ scp ./index.html ubuntu@192.168.10.50:/var/www/html/
```
