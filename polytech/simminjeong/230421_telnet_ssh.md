# 네트워크 렌더링 검열: Telnet의 사망과 SSH (와이어샤크)

모니터와 마우스가 없는 리눅스 서버에 지구 반대편에서 키보드를 연결해 원격 조종하는 기술은 인프라 제어에 필수적입니다. 이 기술의 시작이자 멸종 위기종인 `Telnet` 과 세계를 제패한 암호화 표준 `SSH` 를 네트워크 패킷 탈취(스니핑) 관점으로 해부합니다.

---

## 1. 날것의 공포: Telnet (네트워크의 발가벗은 뼈대)

아무런 포장지 없이 내가 친 키보드의 A, B, C 글자를 랜선 너머 서버로 그대로 날려 보내는 구시대(1980년대) 텍스트 통신 프로토콜입니다. 

* **치명적 위험 (스니핑/Sniffing 노출):** 해커가 길거리 인터넷 공유기에 앉아서 와이어샤크(Wireshark)라는 패킷 도청 해킹 프로그램을 켜놓기만 하면, 당신이 Telnet을 쳐서 서버에 입력한 관리자 아이디(`root`) 와 치명적인 데이터베이스 비밀번호(`password123`) 글자가 암호화 1도 없이 아주 투명하고 정직하게 텍스트 그대로 해커의 모니터에 떠오릅니다. (평문 데이터 전송)
* 현재 인프라 환경에서 Telnet(23번 포트)으로 서버 비밀번호를 친다는 것은, 해커에게 '내 서버 다 뜯어가쇼' 라고 공지하는 행위이므로 완전히 봉인/폐기 되었습니다.

---

## 2. 암흑의 보안 터널: SSH (Secure Shell 의 무결성)

텔넷의 충격적인 도청 위험을 원천 박살 내기 위해 22번 포트를 뚫고 나타난 **전 지구 시스템 제어 표준 터널링 아키텍처** 입니다.

* **양자 보안의 은폐 (암호화 렌더링 패킷):** 당신이 SSH를 통해 키보드를 치면, 당신의 비밀번호 비트 조각들이 RSA/AES 같은 극강의 군사 등급 암호 알고리즘에 의해 이 세상에 존재하지 않는 복호화 불가능 단어들(예: `a3f8z&2^!x..`)로 짓이겨져 전송됩니다.
* **해커의 절망:** 와이어샤크를 켜고 도청하던 해커가 SSH 패킷을 잡아채 분석해 보아도, 100년간 슈퍼컴퓨터를 돌려야 풀리는 절대 암호문 쓰레기값만 보일 뿐입니다. 데이터의 시작부터 끝 종단망(End-to-End)에서 완벽히 터널 실드 기법을 제공합니다. 

---

## 3. Wireshark 스니퍼(해커) 시점 분석 비교

실제 해킹 툴(와이어샤크) 교차 검증을 통해 패킷 렌더링 내부망의 민낯을 까보면 다음과 같은 극단적 대조를 보입니다.

* **[TELNET 패킷 렌더링]:** 해커가 우클릭 'Follow TCP Stream' 을 누르는 순간 -> `login: admin` / `Password: mysecret99` 라는 개발자의 생생한 키보드 타건 이력이 1바이트의 여과도 없이 붉고 선명한 평문(Plaintext)으로 출력되어 모조리 갈취당합니다.
* **[SSH 패킷 렌더링]:** 해커가 동일하게 TCP 패킷 껍데기를 열어 까보면 -> `?|!#9$*a` 같은 의미 없는 외계어 이진수 블록 깨짐 현상만 출력됩니다. 비밀번호는커녕 '접속을 하긴 했는지' 조차 판별할 수 없는 완벽한 보안 방어선이 형성되어 있음을 증명합니다.
