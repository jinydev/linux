# 부팅 스테이지의 권력 통제: 분산 런레벨 (Runlevel)

윈도우는 전원을 켜면 무조건 화려한 바탕화면 GUI(그래픽) 모드로만 부팅이 됩니다. 하지만 서버용으로 쓰이는 리눅스는, 그래픽 카드를 깎아먹는 화려한 바탕화면을 포기하고 시꺼먼 글씨(CLI) 기반의 네트워크 핵심 텍스트 구동 상태로만 선택(Targeting)하여 부팅할 수 있습니다. 

시스템이 켜질 때 '네트워크를 활성화할 거냐', '초보자를 위한 바탕화면을 킬 것이냐', '해킹 복구를 위한 오프라인 모드로 킬 것이냐' 등의 핵심 구동 부품 세팅 조립 번호를 **런레벨(Runlevel)** 이라고 합니다.

---

## 1. 유닉스 init 데몬의 7단계 계급장 (0~6)

리눅스가 켜질 때, 커널이 가장 먼저 숨통을 불어넣는 PID 1번 조상님 `init` 프로세스가 명령하는 부팅 단계 옵션표입니다. 

* **Runlevel 0 (`Halt` - 시스템 강제 타살):** 
  장비 종료. 이 번호로 기본 구동을 세팅해 두면 컴퓨터 전원을 켜자마자 바로 다시 꺼져버리는 무간지옥에 빠집니다.
* **Runlevel 1 (`Single User` - 무적의 응급 복구실):** 
  랜선을 칼로 자른 오프라인 고립 벙커 상태입니다. 네트워크도 안 되고, 데이터베이스 서버도 안 뜹니다. 오직 관리자(`root`)만이 윈도우의 '안전 모드' 처럼 패스워드 없이 다이렉트로 침입하여 날아간 서버 설정이나 해커에게 털린 비밀번호를 롤백 복구할 때 쓰는 최후의 메스(Mes) 단계입니다.
* **Runlevel 3 (`Multi-User CLI` - 인프라 서버의 진정한 본체):** 
  가장 표준적이고 강력한 실무 백엔드 서버 부팅 모드입니다. 그래픽(GUI)을 100% 삭제해 램(RAM) 낭비를 극도로 줄이고, 네트워크 인터페이스와 통신 데몬들만 전부 활성화하여 오로지 검은 화면(텍스트 터미널) 속 명령어만으로 전 세계 트래픽을 처리합니다.
* **Runlevel 5 (`Graphical / X11` - 초보자용 배포판):** 
  Runlevel 3 의 뼈대 위에 화려한 마우스 클릭용 바탕화면 데스크톱 렌더링(GNOME 껍데기)을 강제로 덧씌운 풀옵션 모드입니다 (일반 PC용 데스크톱 리눅스 기본값).
* **Runlevel 6 (`Reboot` - 영원한 예토전생 재부팅):** 
  이 번호를 기본 부팅으로 세팅하면 켜질 때마다 무한히 재부팅(Reboot)을 반복하는 시스템 붕괴를 맛보게 됩니다.

## 2. 시동 스위치 렌더링: `init`에서 `systemd`로의 진화

과거에는 까만 화면 터미널 런레벨 3에서 마우스가 필요해진 순간, 엔지니어가 `init 5` 라는 명령어를 한 방 때리면 곧바로 화려한 그래픽 GUI가 튀어나오며 아키텍처가 전환되었습니다.

하지만 현대의 우분투/Rocky(RHEL 7 이상) 리눅스에서는 이 낡은 번호판 시스템을 파괴하고, 모든 것을 통일하여 지휘하는 새로운 `systemctl (systemd)` 타겟 아키텍처로 환골탈태했습니다.

```bash
# 구시대 방식: 현재 런레벨(부팅 모드) 그래픽 5번으로 즉석 워프 실시
$ init 5

# 현대의 방식 (Systemd Target 전환 렌더링)
$ systemctl isolate graphical.target   # 그래픽 GUI 부팅 (런레벨 5)
$ systemctl isolate multi-user.target  # 검은 화면 서버 부팅 (런레벨 3)

# 영원히(서버 껐다 켜도) 부팅 옵션 고정 강제 박제 (Default 세팅)
$ systemctl set-default multi-user.target
```
