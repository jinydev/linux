# 인프라 OS의 이그니션 렌더링: 리눅스 베어메탈 설치 (CentOS)

개발자 PC 윈도우(Client) 안에서 VirtualBox/VMware 라는 가상 샌드박스를 띄우고, 빈 가상 하드디스크 쇳덩어리에 CentOS 리눅스 인프라 서버 엔진을 이식(Install)하는 메커니즘 렌더링 작업입니다. 

단순히 '다음-다음' 버튼을 클릭하는 윈도우 설치와 달리, 리눅스 서버 설치는 쇳덩어리에 마운트 맵핑과 메모리 스왑 설정을 직접 때려 박아야 시스템이 기동 됩니다.

---

## 1. 하드웨어 스펙 한계선 (AWS EC2 스케일 척도)

가상 서버(VM)에 내 컴퓨터의 물리적 자원 한도를 할당하는 아키텍처 수립입니다.
* **디스크 포맷 파츠 (VDI / 동적 할당):** 당장 내 윈도우 본체 하드디스크에서 허공으로 20GB 용량을 날리지 않고, CentOS가 실제로 파일을 설치하고 불어나는 만큼만 윈도우 용량을 빨아먹으며 연동되는 최신 (동적 사이즈) 프로비저닝 메타 기법입니다.

---

## 2. 수동 디스크 분할 렌더링 (Mounting Point)

OS가 숨 쉬고 폭발하는 폭주 레이어 구역을 논리적 격벽(파티션)으로 도끼질해 분해합니다. (핵심 권장 토폴로지)

1. **`swap` 파티션 (RAM 메모리 둔갑술 쇳덩어리):** 
   RAM이 2GB면 `Swap`은 4GB를 할당합니다. 물리적 RAM이 100% 꽉 차 오버플로우 폭파가 뜨기 직전에, 하드디스크 일부를 램인 것처럼 속여 생명 연장의 급소를 제공하는 블랙홀 구역.
2. **`/` (루트 심장 파티션):**
   나머지 남은 최대 용량(수십 GB)을 모조리 몰빵해 주는 리눅스의 근원 뼈대 폴더. 모든 엔진 프로그램과 설정은 이 루트 안에 영원히 종속됩니다. 
*(원래 실무에서는 웹서버 로그가 폭주하는 `/var` 데이터베이스 폴더 등을 철저히 분리해서 격벽 파티셔닝하지만, 로컬 테스트 환경에서는 통합합니다)*

---

## 3. Server(GUI) vs Server(B / 베어메탈 CLI)

어떤 형태의 통치 시스템을 이 기계에 깔 것인지 커널 포장지를 고르는 작업입니다.
* **DVD (풀패키지 그래픽 GUI):** 마우스 커서와 바탕화면 창이 뜨는 무거운 데스크톱 버전입니다. 초보자는 편하지만 화면을 출력하느라 아까운 서버 RAM 용량을 수 기가바이트씩 갉아먹는 무능한 엔진입니다.
* **Server(B / Minimal 버전):** 그래픽 카드 드라이버와 UI 소스코드를 전면 절단시키고 오직 까만색 CUI(텍스트 터미널 명령어) 창만 딱 하나 띄워주는 완전 백엔드 실무용 코어 렌더링 버전입니다. 램 메모리를 거의 잡아먹지 않고 미친 듯한 속도와 쾌적한 데몬 서비스 서버 구동 환경을 보장합니다.
