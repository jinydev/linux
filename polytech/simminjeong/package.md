# 인프라 종속성 파괴 지휘관: 패키지 매니저 (Package Manager)

윈도우에서는 새로운 프로그램을 깔 때 `setup.exe` 를 다운받아 더블클릭하면 땡입니다. 하지만 리눅스에서는 톰캣 서버를 소스코드로 설치하려다 보면 **"이걸 띄우려면 자바 1.8이 필요해! (설치 시도) → 자바 1.8을 깔려면 C++ 컴파일러가 필요해! → (설치 시도)"** 와 같이 무한히 꼬리를 무는 미친 데카르트의 악마 같은 **의존성 지옥(Dependency Hell)** 사태가 터집니다.

이 끔찍한 의존성 연결고리를 백그라운드 저장소 서버망과 교신하며 단 명령어 1줄로 지가 알아서 싹 다 끌어모아 자동으로 설치해주거나 깔끔하게 제거해 주는 파이프라인 관리 마법이 바로 패키지 매니저 시스템입니다.

## 1. 2대장 시스템 코어 렌더러

마치 안드로이드 스마트폰에 '구글 플레이스토어' 가 있고 애플 아이폰에 '앱스토어' 가 완전히 찢어진 것처럼, 리눅스도 운영체제(OS) 패밀리에 따라 절대 호환되지 않는 각자의 독립 스토어 앱 생태계를 굴립니다.

1. **데비안/우분투 계열 (`.deb` 패키지 아키텍처)**
   * **`dpkg` (저수준 삽질 툴):** 남이 USB로 건네준 오프라인 `.deb` 파일 껍데기를 그냥 우격다짐으로 컴퓨터에 풀어 까는 원시적/수동적 도구. 의존성 꼬이면 나 몰라라 하고 에러 내뿜으며 설치가 터집니다.
   * **`apt / apt-get` (고수준 끝판왕 툴):** `dpkg`의 한계를 파괴한 스마트 도구입니다. "의존성 라이브러리가 없어? 내가 전 세계 우분투 중앙 클라우드 저장소(Repository) 털어서 관련 부품 파일 100개 동시에 다 검색해서 알아서 다운로드 받고 설치해 주고 세팅 맵핑 할게" 를 수행하는 절대 지휘관입니다.
   
2. **레드햇/CentOS 계열 (`.rpm` 패키지 아키텍처)**
   * **`rpm`:** 데비안의 `dpkg`와 똑같이 단순 1차원적인 로컬 설치를 조지는 툴입니다.
   * **`yum / dnf`:** 데비안의 `apt`와 완벽하게 대칭되는, 인터넷 클라우드 서버 저장소 연동 자동 다운로드 및 무지성 의존성 결합 솔루션입니다. (바위처럼 견고한 백엔드 인프라 서버를 구성할 때 쓰는 무기).

## 2. 패키지 조작의 엔지니어 마스터 커맨드

모든 배포판들이 명령어 껍데기만 다를 뿐, 아키텍처 로직은 100% 동일하게 움직입니다. 

### [Apt/Yum 3대 강제 명령 트리거]
```bash
# 1. 1차전: 내 깡통 로컬 PC의 (앱스토어) 목록 장부 목차 책자를 인터넷과 무조건 '최신화(동기화)' 렌더링 조지는 명령어
# (이거 안 치고 프로그램 깔려고 치면 "그런 거 없음" 에러 뜨며 다 터집니다)
$ apt-get update 
$ yum makecache

# 2. 2차전: 톰캣이나 Nginx 따위를 찾아서 의존성 묻지도 따지지도 않고 100% 강제 원 패스 설치 렌더링 (-y 는 [y/n] 묻지 말고 알아서 동의해 버튼)
$ apt-get install nginx -y
$ yum install nginx -y

# 3. 배포 제거: 프로그램만 지우는 게 아니라, 걔 때문에 뒤에 깔렸던 쓰레기 의존성 찌꺼기 파일들까지 모조리 청소 분쇄
$ apt-get remove nginx   (찌꺼기 제거하려면 autoremove)
$ yum remove nginx
```
