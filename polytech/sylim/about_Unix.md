# 운영체제 생태계 비교 (Unix vs Non-Unix)

서버 인프라와 개발 생태계를 이해하기 위해서는 전 세계 OS를 크게 양분하고 있는 '유닉스 계열'과 그 외의 생태계를 이해해야 합니다.

## 1. Unix 계열 운영체제 (Linux, macOS 등)
과거 AT&T 벨 연구소에서 탄생한 Unix 철학을 계승한 운영체제들입니다. 
서버 생태계를 장악한 리눅스(Linux)와, 애플의 macOS가 대표적입니다. (macOS의 내부 커널인 Darwin은 유닉스로부터 파생된 FreeBSD 기반입니다.)

* **개발 친화성:** 수많은 컴파일러와 인프라 관리 도구를 네이티브로 품고 있습니다. 
* **CLI 터미널 중심:** 마우스 없이 키보드와 쉘(Bash, Zsh) 스크립트만으로 전체 데몬과 시스템의 파일 입출력을 완벽히 제어하도록 설계되었습니다.
* **접근성과 생태계:** 리눅스는 완벽한 오픈소스 생태계로 진화하여 전 세계 프로그래머들의 지식 공유(Stack Overflow) 및 발전을 거듭합니다. 반면 macOS는 커널 일부를 제외하면 폐쇄적인(Proprietary) 철학을 유지합니다.

## 2. Non-Unix 계열 운영체제 (Windows)
오직 개인용 컴퓨터 시장을 점령하기 위한 목적으로 독자 개발된 마이크로소프트의 윈도우(Windows) 제품군입니다.

* **GUI 친화성:** 태생부터 수리가 쉽고 직관적인 UI(아이콘, 마우스 클릭)를 위해 개발되었기에 일반 사용자 시장을 독점했습니다.
* **CLI 시스템의 한계:** 과거 제공되던 `cmd`(명령 프롬프트)의 명령어 체계가 유닉스의 그것보다 빈약했으나, 최근 `PowerShell`의 비약적인 발전과 더불어 윈도우 안에 리눅스 터미널을 강제로 내장하는 **WSL(Windows Subsystem for Linux)** 기술을 도입하여 단점을 극복하고 있습니다.

## 3. 모바일 개발 생태계: iOS vs Android

스마트폰 생태계 역시 기반 OS와 개발 시스템이 완전히 구분됩니다.

### iOS 생태계
* **기반 OS:** 유닉스 계열 (Darwin 파생)
* **주력 언어:** Objective-C(사양세) ➡️ **Swift(현재 표준)**
* **개발 환경 (추가 환각 이슈 정정):** 
  *(과거 보고서 내용 중 "C언어 기반의 Objective-C가 개발이 더 섬세하여 여전히 선호된다"는 내용은 완벽한 거짓 정보입니다.)* 현업 iOS 생태계는 2014년 등장한 최신 언어인 Swift로 이미 세대교체가 99% 끝장 선언되었으며, 기존의 막대한 유지보수 레거시 코드 때문에 불가피하게 Objective-C 코드를 읽을 줄 알아야 하는 것일 뿐, 앱스토어의 새로운 신규 프로젝트들은 철저히 Swift로만 디자인됩니다. 

### Android 생태계
* **기반 OS:** Linux 커널 위에서 동작하는 런타임
* **주력 언어:** Java ➡️ **Kotlin(현재 Google 권장 표준)**
* **개발 환경:** 전 세계 프로그래머에게 가장 친숙한 객체지향 언어인 Java 생태계를 포크하여 시작되었으나, 오라클과의 저작권 분쟁 및 자바의 문법적 한계들을 타파하기 위해 현재는 JetBrains 사의 간결한 메타 언어인 **코틀린(Kotlin)** 중심의 개발 구조로 세대 교체가 이루어졌습니다. IDE 도구로는 구글이 공식 배포하는 안드로이드 스튜디오(Android Studio)가 대세입니다.
