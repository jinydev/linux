# 인터넷 상의 주소 체계 : IP와 도메인(Domain)
<hr/>

### 1. 물리적 주소: IP(Internet Protocol)
지구상의 인터넷이라는 그물망에 연결되어 있는 모든 서버 장비와 스마트폰 기기는 기계들이 서로를 통신하고 식별하기 위한 고유한 숫자 형태의 위치 좌표인 **IP 주소**를 가집니다. <br> 
> 예) `115.68.24.88`, `192.168.0.1`

### 2. DNS 도메인(Domain)의 탄생
하지만 기계 친화적인 IP 숫자를 일반 대중들이 수천 개씩 머릿속에 기억하고 네이버나 다음을 찾아가는 것은 불가능합니다. 이를 해결하고자, 복잡한 IP 숫자 좌표계 위쪽에 `opentutorials.org` 처럼 사용자가 1초 만에 식별하고 타이핑할 수 있는 '문자열 이름표'를 씌워주었습니다. 이를 **도메인(Domain)**이라 부릅니다.

브라우저 창에 도메인을 치면, 중간에서 인간과 기계를 중재하는 번역기인 **DNS(Domain Name System) 서버**가 해당 문자 이름표 안에 숨겨진 진짜 IP 숫자를 안내해 주어 트래픽을 토스합니다.

<br/>

### 3. 도메인의 계층(Tree) 구조 체계
도메인은 무작위로 작명되는 것이 아니라 뒤로 갈수록 범위가 커지는 우측 확장형, 역트리(Inverted Tree) 위계 서열 계층을 띱니다. 우측에서 좌측으로 읽을수록 좁아지는 식입니다.

도메인 레벨(단계) 분석 예시: **www.daum.co.kr.** 
(실제 규약상 모든 도메인 맨 끝엔 보이지 않는 루트 마침표(`.`)가 은닉되어 있습니다.)
<br/>

* **1단계 : 최상위 도메인 (TLD, Top-Level Domain)** 
   -> 우측 맨 끝 `kr`, `com`, `net` 영역
   가장 높은 통제 권한을 가진 도메인 구역입니다. 해당 도메인이 국가 공공재인지, 영리 상업 기구인지 큰 테마를 나타냅니다. 
   - 국가 고유 징표(ccTLD) : `.kr(한국)`, `.jp(일본)`, `.uk(영국)`
   - 일반 범용 기관(gTLD) : `.com(상업)`, `.edu(해외 교육망)`, `.gov(정부)`
* **2단계 : 차상위 도메인 (SLD, Second-Level Domain)**
   -> 중간의 `co`, `daum`, `go` 영역
   최상위 도메인의 서브 구역으로서, 해당 도메인이 속한 집단의 정체성을 좀 더 세밀하게 갈라줍니다. 혹은 바로 회사 이름이 등록되는 구역이기도 합니다. `.kr` 안에서의 `.co`(회사), `.ac`(대학 기관), `.go`(관공서) 등이 대표적입니다.
* **3단계 이하 서브 도메인 (Third-Level / Hostname)**
   -> 가장 앞부분의 `www`, `mail`, `blog` 영역
   사용자가 최상위와 차상위 도메인 주소권을 통째로 구매했다면, 그 앞단의 3, 4차 도메인 작명은 서버를 늘릴 때마다 자기 마음대로 수 백개를 찍어 낼 수 있습니다. 가장 앞부분에 붙는 단어는 물리적인 서버(컴퓨터) 장비 인스턴스의 닉네임, **호스트네임(Hostname)**을 의미하는 경우가 잦습니다. (ex. `mail.daum.net`, `blog.naver.com`)
