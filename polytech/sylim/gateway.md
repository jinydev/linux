# 다른 환경으로 나가는 문: 게이트웨이(Gateway)

## 1. 게이트웨이의 정의와 역할
하나의 폐쇄된 내부 네트워크(사설망)에서 외부 세계인 인터넷망이나 혹은 전혀 다른 프로토콜 구조를 가진 이기종 네트워크로 데이터를 내보낼 때, **목적지를 향해 빠져나가는 최종 관문(출구) 역할**을 하는 지점을 게이트웨이라고 부릅니다. 

* 주로 공유기, 방화벽, L3 라우터 등의 네트워크 장비가 네트워크의 최전선에서 이 역할을 수행하게 됩니다. 
* 관습적으로 가정용이나 사내 네트워크에서 게이트웨이의 IP 주소는 뒷자리(4번째 옥텟)를 `.1` 이나 `.254`로 고정하여 사용합니다. (예: `192.168.0.1`)

## 2. "게이트웨이"와 "라우터"의 엄밀한 차이
현대 네트워크에서는 두 단어를 거의 동일한 개념이나 장비로 혼용해서 쓰기도 하지만, 본질적인 기능 차이가 있습니다.

* **라우터(Router):** 같은(동종) 프로토콜 데이터의 길찾기를 해주는 "이정표" 역할을 합니다. 패킷의 목적지 IP를 분석해 어느 쪽 선로로 던져줄지 스위칭하는 배달부입니다.
* **게이트웨이(Gateway):** 전혀 다른(이기종) 두 네트워크 생태계 간의 언어를 통역해 주는 "번역기 및 문지기" 역할을 합니다. 내부의 사설 IP 대역을 외부의 공인 IP로 묶어서 내보내 주거나(NAT 기술), 프로토콜을 변환시킵니다.
> 장비 관점에서 최신 라우터들이 게이트웨이 기능(NAT 등)을 내장하여 제공하기 때문에 두 용어의 경계가 허물어지고 있는 것입니다.

## 3. 네트워크 이동의 척도: 홉(Hop)
데이터 패킷이 내 컴퓨터에서 출발하여 구글 서버에 도달하기까지 수많은 라우터 장비와 게이트웨이들을 점프하듯 거쳐야 합니다. 이때 **다음 장비(Next Gateway)로 이동하는 한 번의 단위 거리를 1 홉(Hop)**이라고 부릅니다. 

네트워크 장애가 발생했을 때 라우팅 경로를 추적하는 `traceroute`(리눅스) 명령어 등을 사용하면 목적지까지 걸리는 총 홉 수를 쉽게 추적할 수 있습니다.

## 4. OSI 7계층과 네트워크 장비
게이트웨이는 일반 물리적 계층에만 속박되지 않고 L4(전송) ~ L7(응용 계층)까지 애플리케이션의 깊은 프로토콜 통역까지 수행하는 고급 시스템입니다.

- **1계층 (물리):** 더미 허브, 리피터, 전기적 랜 케이블
- **2계층 (데이터 링크):** 스위치, 브릿지 (MAC 주소 기반 통신)
- **3계층 (네트워크):** 라우터, L3 스위치 (IP 주소 기반 통신)
- **4~7계층 (전송~응용):** 게이트웨이, L4/L7 로드밸런서 스위치, L7 방화벽 (포트 및 애플리케이션 세밀 통제)
