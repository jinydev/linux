# 리눅스 프로세스(Process) 관리 

## 1. 프로세스와 데몬(Daemon)
리눅스는 다중 사용자 및 멀티태스킹 환경을 지원하기 때문에 메모리에 수백 개의 '프로세스(실행 중인 프로그램)'가 띄워져 동작합니다.

* 시스템 구동 시 최상위 부팅 프로세스(systemd / init)가 실행되며, 이 프로세스가 점차 자식 시스템들을 파생시키면서 모든 네트워크, SSH, 웹 서버 등의 환경을 작동시킵니다.
* 콘솔에 직접 접속하지 않아도, 뒤에서 조용히 자신의 임무를 지속적으로 수행하는 ব্যাক그라운드 프로세스들을 리눅스 명칭으로 **데몬(Daemon)**이라 부릅니다. 

## 2. 작업 관리자 : `ps` (Process Status) 명령어
윈도우에서 `Ctrl+Alt+Del`을 눌러 작업 관리자를 실행해 불필요한 프로그램을 죽이듯, 리눅스에서는 터미널에 `ps` 명령어를 쳐서 프로세스 점유 상태를 파헤칩니다.

### 2-1. `ps` 출력 정보 해석하기
```bash
# ps -al 명령어 예시
F S   UID   PID  PPID  C PRI  NI ADDR SZ  WCHAN  TTY          TIME CMD
0 R  1000  1539  1486  0  80   0 -    1870 -      pts/0    00:00:00 ps
```
* **UID (USER):** 해당 시스템 프로세스를 실행시킨 소유자의 계정
* **PID (Process ID):** 프로세스에게 부여된 고유 식별 번호 (해당 프로세스를 강제 종료할 때 킬(Kill)명령어의 과녁이 됩니다.)
* **PPID:** 내 프로세스를 낳은 부모(Parent) 프로세스의 고유 ID
* **VSZ (Virtual Size):** 해당 프로세스가 확보한 총 **가상 메모리**의 크기
* **RSS (Resident Set Size):** 지금 당장 램에 올려서 사용 중인 **실물 물리 메모리** 크기 
* **STAT (S):** 프로세스의 현재 행동 상태 (R: 러닝, S: 슬립 대기 등)
* **CMD:** 프로세스를 불러일으킨 최초 실행 명령어 (어떤 프로그램인지)

### 2-2. 실무에서 가장 많이 쓰는 콤보 명령어
초기 유닉스의 양대 산맥인 System V 스타일과 BSD 스타일에 따라 `ps` 명령어는 `-` (대시)가 붙는 옵션과 안 붙는 옵션이 혼재되어 있습니다. 현대 리눅스는 둘 다 지원합니다.

1. **`ps aux` (BSD 스타일)**
   시스템 전체에서 실행 중인 **모든 사용자의 프로세스 목록을, CPU 및 RAM 사용률과 함께 자세히(x) 출력**합니다. 가장 대중적으로 사용됩니다.
   ```bash
   # 출력량이 어마어마하므로 보통 grep과 파이프를 조합하여 원하는 단어만 남겨 검색합니다.
   $ ps aux | grep apache    # 시스템에서 실행중인 아파치 웹서버 프로세스만 검색
   ```

2. **`ps -ef` (System V 스타일)**
   전체 프로세스 조회 시, **부모(PPID)와 자식 간의 족보(계층)** 등 포맷 정보를(f) 명확하게 확인하고자 할 때 주로 사용합니다.

```bash
$ ps -ef | grep mysql
```
