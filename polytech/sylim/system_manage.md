# 서버 원격지 관리 시스템 이해

인터넷과 망으로 수백 킬로미터 떨어져 있는 아마존 인프라나 사내 전산실 서버 장비에 진입하여 시스템을 제어하기 위해 사용하는 세 가지 핵심 접속 터널링의 원리를 비교합니다.

## 1. 텔넷 (Telnet) : Legacy
인터넷 초창기인 수십 년 전부터 사용된 최초의 가장 전통적인 평문 통신 원격 접속 프로토콜 방식입니다.
* 사용자가 터미널 창에 키보드로 입력한 계정 비밀번호가 암호화되지 않은 투명한(Clear Text) 텍스트 형태 그대로 인터넷 망 선로를 타고 날아갑니다.
* 이는 고의로 선을 훔쳐보는 해커(Sniffing) 패킷 분석 프로그램에 무조건 아이디와 비밀번호가 그대로 해킹당하기 때문에 **현대 인프라 환경에서는 절대 서버 연결용으로 쓰지 않으며 철저히 퇴출되었습니다.** (다만 장비 포트 오픈 여부를 핑(Ping) 대신 점검할 땐 씁니다.)

## 2. SSH (Secure Shell) : Modern Standard
오픈소스인 `OpenSSH` 서버 프로그램을 주로 띄우는 이 방식은 텔넷과 모든 인터페이스가 똑같으나, **사용자의 키보드 입력과 서버의 데이터 패킷 전 구간을 AES, RSA 기반 등으로 완전히 암호화**하여 복잡하게 변조 전송하는 최신 표준 프로토콜 보안 규격입니다.

* 해커가 중간에서 선로를 감청하더라도 해독이 불가능한 쓰레기값 교란 데이터만 얻게 됩니다.
* (과거 학생 보고서 환각 정정: 윈도우(Windows 10 이후 버전) 클라이언트에서 SSH 접속 시 과거처럼 굳이 `Putty` 등의 프로그램을 구글에서 찾아 다운로드할 필요가 전혀 없습니다. 이제 윈도우 OS의 `표준 명령 프롬프트(cmd)`와 `PowerShell`에 `ssh` 리눅스 네이티브 명령어가 무료 모듈로 기본 내장되어 있어 리눅스와 똑같이 즉시 접속 및 활용이 가능합니다.)
```bash
# 윈도우 CMD/맥 터미널에서 모두 사용 가능한 SSH 접속 규격화 커맨드
ssh root@100.100.1.1 
```

## 3. VNC (Virtual Network Computing)
위 두 가지가 마우스를 쓰지 못하는 검은 텍스트(CLI) 터미널 화면 전송 방식이었다면, VNC는 팀뷰어(TeamViewer)처럼 서버의 화면 좌표 체계와 마우스 커서를 통째로 그래픽 이미지화 시켜 사용자 클라이언트 모니터로 화상 캡쳐마냥 송출해주는(GUI) 프로그램입니다.
* 리눅스의 `X 윈도우` 그래픽 데스크톱 환경 전체를 원격으로 제어할 수 있게 돕습니다.
* 다만 화면 송출 자체만으로 대용량의 픽셀 통신 트래픽을 유발하므로 속도가 몹시 느리고 버벅거리는 심각한 단점이 있습니다.
* 데이터가 암호화되지 않아 취약성이 높기에 실무에서는 VNC 전용 포션을 바로 오픈하지 않고, SSH로 암호화 터널(Tunneling)을 단단히 뚫어 놓은 파이프 속에 VNC 데이터를 흘려보내는 보안 연동 기법이 주로 도입됩니다.
