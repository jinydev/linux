# 리눅스 텍스트 가공 파이프라인 명령어 모음

터미널 기반(CLI) 환경 속에서, 대용량 로그 파일이나 텍스트에서 원하는 데이터 구간만 추출하거나 값을 치환할 때 사용하는 도구들입니다. 보통 `|` (파이프라인)으로 연결하여 서로 연속 사용됩니다.

## 1. 텍스트 확인, 정렬, 필터

### `cat` (연결 및 출력)
문서 내용을 터미널 창에 그대로 출력하거나 서로 병합합니다.
```bash
# 라인 번호(-n)를 붙여서 특정 파일의 내용을 화면에 인쇄함
cat -n error.log
```

### `sort` 와 `uniq` (정렬 및 중복 제거)
알파벳, 숫자 순 등으로 텍스트 행을 엑셀처럼 정렬 한 뒤, `uniq`로 중복을 집계합니다.
```bash
# 중복된 행을 제거하고 오직 하나씩만 출력 (반드시 sort 구문과 파이프로 맞물려 사용해야 위력을 발휘합니다.)
sort user_list.txt | uniq

# -c 옵션을 넣으면 각 항목이 몇 번 중복 발생했는지 개수(count)를 세어줍니다.
sort visitor.log | uniq -c
```

## 2. 텍스트의 열(Column) 자르고 이어 붙이기

### `cut` (특정 열 추출)
쉼표(,)나 콜론(:) 등으로 구분된 텍스트 문서 안에서 특정 필드 번호 영역만 뚝 잘라내어 추출합니다. DB에서 Select 한 효과를 냅니다.
```bash
# 구분자(-d)를 쉼표로 삼고, 두 번째(-f 2) 필드만 가져오기
cut -d ',' -f 2 data.csv
```

### `paste` (열 합치기)
`cut`의 반대입니다. 여러 파일의 내용들을 좌우 병렬로 이어 붙입니다.
```bash
# 이름 파일과 나이 파일 두 문서를 옆으로 나란히 붙여서 출력
paste names.txt ages.txt
```

## 3. 원본 변이 및 치환 편집 

### `diff` (가교 및 차이점 분석)
Git에서 버전 충돌 시 볼 수 있는 가장 원론적인 원천 라인 비교 명령어입니다. 두 문서 간의 추가(+), 삭제(-) 라인 스펙을 찾아줍니다.
```bash
# a코드와 b코드 원본 간의 수정된 코드 라인 차이 비교
diff code_A.c code_B.c
```

### `tr` (Translate: 단일 문자 치환 및 삭제)
*(과거 환각 정정: 정규식 문자열 형태를 치환하는 명령어가 아니며 본래 단일 문자의 1:1 대응 맵핑 명령어입니다.)*
```bash
# 소문자를 입력받으면 일괄 대문자로 변경함 (올바른 POSIX 규격의 문법 수정)
echo "lowercase text" | tr '[:lower:]' '[:upper:]'

# 숫자만 일괄 제거 후 출력
echo "version 1.0.3 string" | tr -d '0-9'
```

### `sed` (Stream Editor : 초강력 정규식 치환 도구)
로그 파일 중 내가 원하는 특정 단어 시퀀스 모양만 골라 다른 단어로 덮어씌웁니다.
*(과거 환각 정정: 역슬래시와 괄호가 난무하던 정체불명 오류 신택스를 걷어내고 업계 현업용 표기법으로 교정했습니다.)*
```bash
# 파일 내부의 모든 'front' 라는 텍스트를 'back'으로 치환하여 대체 출력함 ('g'는 전체 뜻함)
echo "front server, front port" | sed 's/front/back/g'

# 문서의 1번째 라인에서만 치환 조건을 작동시킴
echo "front server" | sed '1s/front/back/'
```
