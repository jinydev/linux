# CLI 명령어의 정체성과 매뉴얼 추적 파이프라인

우리가 리눅스 터미널에서 멍청하게 두드리는 `cd` 나 `ls` 같은 단어들은, 단순히 미리 약속된 마법의 주문이 아니라 철저히 **운영체제가 하드디스크에서 찾아낸 스크립트 쇳덩어리나 내장 함수의 이름** 에 불과합니다. 이 명령어들이 어디서 튀어나왔고 무슨 역할을 하는지 스스로 문서를 까보는 포렌식 기법입니다.

---

## 1. 명령어의 정체를 벗기는 X-Ray: `type` & `which`

터미널 하단에 `type` 이나 `which` 를 박아 넣음으로써, 그 명령어의 물리적 실체 위치를 추적 렌더링합니다.

* **`type` (명령어 DNA 판별기):** 
  "이 명령어가 유닉스 자체 함수냐? 아니면 별명(alias)이냐? 아니면 하드디스크 C++ 프로그램이냐?" 를 감별합니다.
  - `$ type cd` -> *cd is a shell builtin* (쉘 자체 내장 함수)
  - `$ type ls` -> *ls is aliased to `ls --color=auto`* (원래 ls를 조작한 별명 껍데기)
* **`which` (절대 경로 스나이퍼):**
  특정 프로그램이나 명령어가 리눅스 디렉토리망 어느 폴더 구석 방에 실제로 숨어져 있는지 하드디스크 절대 경로를 파싱해 찍어냅니다.
  - `$ which cp` -> `/bin/cp` (루트 밑의 bin 폴더 방에 들어있는 복사 바이너리)

---

## 2. 매뉴얼을 뜯어먹는 엔지니어의 무기: `help` & `man`

구글에 치면 나오지만 오프라인 망 폐쇄망 서버에 갇혔을 때, 명령어의 사용법(옵션)을 자체 하드디스크 내부에서 파싱해 콘솔로 띄워보는 생존 지침서 열람 뷰어입니다.

1. **내장 헬퍼 `$ help [명령어]` / `[명령어] --help`:**
   명령어의 가장 핵심적인 스니펫(사용법과 텍스트 옵션 A/B/C)만 콘솔에 1장으로 요약해서 출력해 주는 치트 시트(Cheat Sheet) 출력기입니다.
2. **풀 스펙 매뉴얼 `$ man [명령어]` (Manual):**
   그 명령어의 탄생 목적, 모든 옵션의 렌더링 결과, 예외 처리 등 수천 줄에 달하는 '공식 기술 문서(지침서 아님)' 전체를 화면에 떡하니 띄워 줍니다 (`q` 로 빠져나옴). 
3. **`$ apropos [키워드]`:**
   명령어 이름이 기억 안 나고 "복사"라는 단어만 기억날 때, 매뉴얼 창고 전체를 뒤져 문자열을 파싱해 관련 명령어 리스트를 쫙 뽑아주는 역추적 엔진입니다.

---

## 3. 내 마음대로 명령어 조작/위조: `alias`

`ls -alF` 처럼 매번 치기 죽도록 귀찮은 거대한 파이프라인 옵션 덩어리를, 내가 원하는 **단 두 글자의 짧은 단어 껍데기로 매핑(별칭 부여) 치환 조작** 해버리는 엔지니어 타건 핫패치 단축키 명령어입니다.

```bash
# 앞으로 ll 이라고 앞글자만 치면, 쉘이 이걸 ls -alF 로 번역해서 실행 조작함
$ alias ll='ls -alF'

# 터미널에 타건
$ ll
(정상적으로 리스트가 출력됨)
```
