# 가상화 (Virtualization) 와 하이퍼바이저

현대 클라우드 컴퓨팅(AWS, Azure 등)은 거대한 물리적 서버를 쪼개어 수만 명의 고객에게 임대해 주는 비즈니스입니다. 이 모든 비즈니스의 밑바탕에는 하드웨어의 한계를 부수는 **가상화(Virtualization)** 기술이 숨어 있습니다.

## 1. 가상화 (Virtualization) 란?
운영 체제(OS)가 하드웨어(CPU, RAM, 디스크)에 직접 종속되어 돌아가지 않고, 그 사이에 '하이퍼바이저'라는 논리적인 소프트웨어 계층을 두어 물리적 하드웨어 1대를 "마치 여러 대의 독립된 가상 컴퓨터(Virtual Machine)가 있는 것처럼" 쪼개어 쓰는 기술입니다.

### 왜 가상화를 해야만 하나요?
과거에는 윈도우 서버 1대, 리눅스 웹 서버 1대, 오라클 DB 서버 1대를 구축하려면 각기 다른 물리적 하드웨어 서버 3대를 사야 했습니다. 하지만 최신 서버 장비들은 CPU 성능이 너무나 압도적이어서, 겨우 OS 1개를 돌리기엔 컴퓨터 자원의 80%가 계속 놀고 있게 됩니다. **하나의 괴물 서버 위에 여러 개의 독립적인 창문(가상 OS)을 띄움으로써, 하드웨어 낭비를 제로에 가깝게 줄이는 것이 가상화의 핵심 목적입니다.**

## 2. 하이퍼바이저 (Hypervisor) 분할 방식

물리적 컴퓨터를 쪼개는 소프트웨어인 하이퍼바이저는 2가지로 나뉩니다.

* **Type 1 (Native / Bare-Metal 하이퍼바이저):** 컴퓨터 깡통 하드웨어 위에 윈도우 대신 하이퍼바이저 OS 자체를 바로 깔아버립니다. 그 위에서 여러 가상머신을 돌립니다. 속도가 압도적으로 빨라 AWS 등 실제 기업용 서버 인프라(VMware ESXi, Xen 등)의 표준입니다.
* **Type 2 (Hosted 하이퍼바이저):** 내 컴퓨터의 윈도우(OS) 위에 일반 애플리케이션처럼 VMware Workstation이나 VirtualBox 프로그램을 설치해 가상 리눅스를 돌립니다. OS를 두 겹이나 거쳐야 하므로 속도가 많이 느립니다.

## 3. 서버 가상화의 4대 장점
1. **유연성 및 이식성:** 특정 하드웨어 부품이 고장 나도 가상 머신(VM 파일) 덩어리만 복사해서 다른 건강한 물리 서버로 이동시키면 단 3분 만에 시스템이 복구됩니다.
2. **비용 한계 돌파:** 전기세, IDC 공간 임대료, 하드웨어 구매 비용이 1/10 수준으로 절감됩니다.
3. **완벽한 격리성:** VM 1번이 바이러스에 걸려 포맷되더라도, 바로 옆의 VM 2번 서버에는 1%의 타격도 주지 않는 완벽한 독립 철창 구역이 만들어집니다.
4. **민첩성 다중화:** 새로운 서버 컴퓨터가 필요할 때 주문하고 배송받을 필요 없이, 클릭 몇 번이면 5분 만에 새 리눅스 서버 한 대가 메모리상에서 뚝딱 만들어집니다.

> 💡 **최신 트렌드: 가상화(OS) vs 컨테이너(Docker)**
> 무거운 OS를 통째로 여러 개 복제하는 기존 가상 머신(VM) 방식조차도 버겁다고 판단한 현대 개발자들은, 리눅스 커널 하나를 공유하면서 프로그램만 가상으로 격리해 돌리는 **'도커(Docker 컨테이너)' 기술**로 클라우드의 트렌드를 완전히 이동시켰습니다.
