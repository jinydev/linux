# 친절한 텍스트 편집기: nano

리눅스 서버 환경(CLI)에서는 마우스 기반의 화려한 편집기를 켤 수 없습니다. 
대부분 전문가들은 강력한 조작성을 지닌 `vi` (`vim`) 에디터를 사용하지만, 모드를 변경해가며 단축키를 외워야 하는 `vi`는 처음 흑백 콘솔을 접하는 초보자에게 극심한 공포감을 안깁니다.

초보자 친화적이고, 화면 하단에 모든 단축키가 친절하게 표시되는 가장 직관적인 텍스트 편집기가 바로 **`nano` 에디터**입니다.

---

## 1. nano 설치 및 실행

대부분의 최신 리눅스 배포판(Ubuntu 등)에는 nano가 기본 탑재되어 있습니다. 

```bash
# 데비안/우분투 계열 설치 확인 
sudo apt-get install nano

# 레드햇/Rocky 계열 설치
sudo yum install nano

# 파일 열기 또는 새 파일 생성
nano polytech.txt
```

## 2. nano 인터페이스와 모덜리스(Modeless) 통제
`vi`는 a나 i를 눌러 입력 모드로 들어가야 글씨가 써지는 방식이지만, **`nano`는 모덜리스(Modeless) 방식**입니다. 즉, 메모장처럼 열자마자 바로 키보드를 치면 글씨가 입력됩니다.

명령을 내릴 때는 `Ctrl` 키(화면 하단에 `^` 기호로 표시됨) 또는 `Alt` 키(`M` 기호로 표시됨)를 눌러 제어합니다.

---

## 3. 핵심 단축키 (치트시트)

nano에서 다음의 단축키 4개만 알면 리눅스에서 어떤 환경 설정 파일이든 쉽게 고칠 수 있습니다.

| 단축키 | 화면 표기 | 설명 |
| :-: | :-: | :-- |
| **`Ctrl + O`** | `^O` (Write Out) | **저장하기**입니다. 변경된 내용을 현재 파일 이름으로 실제 디스크에 덮어씁니다. 엔터를 한 번 더 쳐야 저장 이름이 확정됩니다. |
| **`Ctrl + X`** | `^X` (Exit) | **종료하기**입니다. 수정 사항이 있는데 저장하지 않았다면 "저장할래?"(Y/N) 하고 물어보는 매우 친절한 창이 뜹니다. |
| **`Ctrl + W`** | `^W` (Where Is) | **검색하기**입니다. 수백 줄이 넘는 아파치/DB 설정 파일에서 특정 단어를 찾을 때 필수적입니다. |
| **`Ctrl + K`** | `^K` (Cut Text) | 현재 커서가 있는 줄(Line)을 통째로 **잘라내기(삭제)** 합니다. 연속해서 지울 때 유용합니다. |
| **`Ctrl + U`** | `^U` (Uncut Text) | 방금 잘라낸 줄을 새 위치에 **붙여넣기** 합니다. |
| **`Ctrl + G`** | `^G` (Get Help) | 나노 에디터 도움말 및 전체 단축키 매뉴얼을 띄웁니다. |

> 💡 **실무 팁:** `nano`는 분명 직관적이고 편하지만, 1000줄 이상의 방대한 코드에서 일괄적으로 문자를 치환하거나(Replace), 창을 반으로 쪼개서 볼 때 등 고급 기능이 부족합니다. 따라서 리눅스 환경에 적응한 뒤에는 반드시 `vim` 편집기를 학습하는 권장 코스로 이어집니다.
