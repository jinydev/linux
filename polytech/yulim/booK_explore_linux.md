# 우분투 리눅스 데스크톱 마스터하기

*(과거 2010년 초반 우분투 10.04/12.04 유니티(Unity) 데스크톱 시절의 낡은 컴피즈(Compiz)나 피진 메신저 등 완전히 소멸한 구형 기술 가이드를 최신 2024년 우분투의 GNOME 40 이상의 셸 환경과 보안 트렌드에 맞게 전면 리뉴얼한 가이드입니다.)*

## 1. 우분투 GNOME 데스크톱 환경 내 입맛에 맞추기

현대 우분투는 가장 깔끔하고 무거운 3D 그래픽 엔진을 사용하는 **GNOME(그놈)** 데스크톱을 얹어 배포됩니다.
* **액티비티(현재 활동) 대시보드:** 맥OS의 런치패드나 윈도우 키와 동일합니다. 키보드의 `Super (Windows)` 키를 누르면, 현재 떠 있는 모든 창이 축소되고 상단에 소프트웨어 검색 창이 나타납니다. 여기서 "터미널"을 쳐 즉각 진입합니다.
* **노틸러스 파일 관리자 (내 폴더):** 윈도우의 탐색기와 같으며, 우분투의 GUI 환경에서 수많은 폴더 트리를 직관적으로 클릭 수술할 수 있습니다. 
* **우분투 소프트웨어 센터 (App Center):** 앱스토어입니다. 구글링해서 `apt` 커맨드를 복잡하게 입력하지 않아도 디스코드, 슬랙, 카카오톡 대체재를 버튼 터치 하나로 마법사처럼 편히 내려받을 수 있습니다.

## 2. Root 최고 관리자 계정의 잠금 철학

초보자는 "도대체 어떻게 관리자로 로그인해? 암호가 뭐야?"하고 묻습니다. 
**우분투는 보안 최적화를 위해 설치 직후 Root 계정의 로그인 비밀번호를 일부러 설정하지 않고 '아예 봉인' 시켜버립니다!** 즉 절대 로그인 화면에서 아이디 `root`로 들어오지 못하게 막아둔 것입니다.

### 권한 대행으로 우회하기 (최신 트렌드)
자신이 로그인한 일반 유저 계정에서, 임시로 슈퍼 파워를 빌려 쓰는 법을 써야 합니다.
```bash
# 1. 일회용 권한 대행 (비밀번호는 일반 유저 암호를 칩니다)
sudo apt update

# 2. 콘솔 자체를 영구적으로 root 신분으로 바꾸기 (안료 후 exit로 탈출)
sudo su - 
```

### 굳이 꼭 Root 비밀번호를 강제로 풀고 싶다면?
서버 전용 세팅을 위해 반드시 Root 아이디 활성화가 필요하다면, 아래 명령어로 강제 패스워드를 주입하여 환생시킬 수 있습니다.
```bash
sudo passwd root
# (비밀번호 2번 입력) 이제부터 su 명령으로 즉각 root로 빙의 가능합니다.
```

## 3. 리눅스의 부팅 관리자, GRUB (그럽) 설정 변경

컴퓨터에 윈도우와 우분투 리눅스 2개를 함께 깔았다면(멀티 부팅), 전원을 켰을 때 **"1번 우분투, 2번 고급 설정... 5번 윈도우 부트 매니저"** 처럼 남색이나 검은색 화면이 뜨며 10초를 세는 메뉴가 나타납니다. 이 부팅 지휘관 프로그램이 바로 **GRUB**입니다.

기본 커서를 윈도우가 되게 하거나, 10초 대기 시간을 3초로 줄이고 싶을 땐 터미널로 들어갑니다.
```bash
# GUI 편집기 띄우기 (최고 관리자 권한 필요)
sudo gedit /etc/default/grub

# 위 파일을 열면 아래의 핵심 소스 두 줄이 보입니다.
GRUB_DEFAULT=0     # (위에서부터 첫 번째 메뉴가 기본 자동 선택이라는 뜻, 0번 시작)
GRUB_TIMEOUT=10    # (메뉴 고를 대기 시간을 10초로 준다는 뜻, 3으로 변경)

# !! 중요 !! 편집 후 저장을 완료했다면 반드시 터미널에 업데이트 컴파일 명령을 때려야 실제 부팅 시 인식합니다.
sudo update-grub 
```

## 4. 확장 프로그램 (GNOME Extensions)
*과거 해킨토시 흉내를 내던 OpenGL Dock이나 무거운 젤리 창 효과(컴피즈)는 데스크톱이 최신화되며 모두 사장되었습니다.*
현대 우분투 데스크톱 해킹의 꽃은 웹 브라우저에서 버튼만 누르면 시스템의 모든 작업표시줄과 디자인을 뜯어고칠 수 있는 **GNOME Extensions** 시스템입니다. 크롬 웹 스토어에 방문해 통합 확장인스톨러를 깔면, 맥OS 특유의 화려한 하단 통통 튀는 아이콘 배열(Dash to Dock)이나, 시계 디자인 등을 1초 만에 테마화 할 수 있습니다.
