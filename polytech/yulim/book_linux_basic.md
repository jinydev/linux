# 리눅스 네트워크와 원격 접속 마스터하기 (SSH의 부상)

IDC(인터넷 데이터 센터)에 입주해 있는 고성능 랙 서버 머신에는 직접 모니터와 키보드를 꽂을 수 있는 구비 환경이 없거나, 설령 있더라도 엔지니어가 시끄러운 에어컨 바람을 맞아가며 1시간 동안 서서 개발을 할 수는 없습니다.
따라서 오피스 개발자의 따뜻한 윈도우/맥 노트북에서 저 멀리 있는 리눅스 서버로 가상의 검은색 콘솔 터미널에 원격 접속해 시스템을 부려먹어야 하는데, 이때 사용되는 양대 통신 규약 프로토콜이 존재합니다.

## 1. 텔넷 (Telnet)과 멸망
클래식 유닉스 서버 시절 가장 대표적으로 사용되었던 원격지 터미널 프로토콜입니다.
> ⚠️ **주의 (과거 교재 오류 수정):** *이전 교육 문서에는 Telnet 서버 패키지를 `xinetd`를 이용해 설치하라는 가이드가 있었습니다. 하지만 현대 실무 클라우드 인프라에서는 **Telnet의 사용을 악성코드 감염 수준으로 엄격하게 금지**합니다.*

* **왜 폐기되었는가? (해킹 리스크):** Telnet은 암호화라는 개념이 세상에 없던 시절에 만들어졌습니다. 내가 원격으로 `root` 비밀번호 `1234`를 치고 로그인하면, 그 키보드 타이핑 정보 텍스트가 와이파이 네트워크를 타고 날아갈 때 평문(Plaintext)으로 100% 날 것 그대로 전송됩니다. 카페에서 같은 공유기를 쓰는 해커가 툴을 켜면 내 비밀번호와 타이핑하는 서버 핵폭파 명령 코드가 숨김없이 다 보입니다. 

## 2. 유일무이한 표준 접속 체계, SSH (Secure Shell)
Telnet이 가진 재앙 수준의 보안 붕괴를 막기 위해 나타난 대체재로, **현재 전 세계 서버 관리 원격 접속의 99.9%를 담당하는 독점 절대 규약**입니다.

* **특징:** 클라이언트와 서버 간의 터미널 타이핑 텍스트 라인을 전부 양방향으로 '강력한 RSA, ECDSA 암호키'로 버무려 우주인 언어로 변경하여 보냅니다. 중간에 패킷을 훔쳐보아도 `f$k9z#~` 같은 쓰레기 값만 잡혀 비밀번호가 절대 해독되지 않습니다. 
* 심지어 `sftp` 등 안전한 포트 파일 전송이나 이중 터널링 VPN 포워딩까지 이 SSH 뼈대를 응용해 다 이루어집니다.

### 🔥 우분투 서버에 SSH 설치 및 포트 오픈 (현업 권장 방식)
```bash
# 1. 패키지 다운로드 및 강력한 보안 원격 데몬 설치
sudo apt update
sudo apt install openssh-server

# 2. 서비스 실행 및 부팅시 자동화
sudo systemctl enable ssh
sudo systemctl start ssh
```
이제 개발자의 개인 PC(윈도우)에서 대표적인 접속 클라이언트인 `PuTTY`, XShell 혹은 최신 윈도우의 '명령 프롬프트(CMD)'에 내장된 ssh 명령어를 이용해 클라우드 서버에 침투할 수 있습니다.
```bash
# [내 PC 터미널에서 실행] 아이디@서버IP주소
ssh yulim@192.168.229.2
```

## 3. (심화) 가상 환경 (VirtualBox) 네트워크 통신 이해하기

버추얼박스(VirtualBox)를 이용해 내 노트북 안에 작은 리눅스 샌드박스 망을 만들었다면, 내 진짜 노트북 운영체제와 가짜 가상머신 간에 어떻게 IP 네트워크 케이블을 꽂아 통신할까요? 두 가지 핵심 어댑터를 이해해야 합니다.

* **NAT (기본 제공 모드):** 내 컴퓨터가 일반 공유기 역할을 하여, 가상머신 리눅스에게 임의의 IP를 몰래 할당하고 자신이 인터넷만 대리 수행해 뿌려줍니다. 이 경우 가상머신은 유튜브도 들어가고 바깥세상(인터넷)과 풀 통신이 되지만, **반대로 내 윈도우 PC(Host)에서는 핑을 쳐도 가상머신의 존재 자체를 투명 망토 처리하여 찾거나 접속할 방법이 없습니다.**
* **호스트 전용 어댑터 (Host-Only Network):** 내 진짜 컴퓨터 윈도우와, 버추얼박스 리눅스를 직접 1대1 다이렉트 랜선으로 꽂아버리는 전용망입니다. 외부 인터넷은 일절 안되지만, 이 다리 덕분에 `192.168.229.1 (윈도우)` ↔ `192.168.229.2 (리눅스)` 간의 완벽한 SSH 원격 접속 콘솔 해킹 실습이 가능해집니다.
