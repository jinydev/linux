# 라이선스 선택 가이드

## 라이선스 선택 가이드

### 1. 라이선스 선택 시 고려사항

**프로젝트 성격:**
- **상업적 목적**: MIT, Apache 2.0 권장
- **교육 목적**: MIT, GPL 권장
- **커뮤니티 프로젝트**: GPL, Apache 2.0 권장

**개발 환경:**
- **기업 환경**: Apache 2.0, MIT 권장
- **학술 환경**: MIT, GPL 권장
- **개인 프로젝트**: MIT 권장

### 2. 라이선스 적용 방법

**라이선스 파일 생성:**
1. **LICENSE 파일**: 프로젝트 루트에 LICENSE 파일 생성
2. **저작권 표시**: 소스 코드 파일에 저작권 표시 추가
3. **README 업데이트**: README 파일에 라이선스 정보 포함
