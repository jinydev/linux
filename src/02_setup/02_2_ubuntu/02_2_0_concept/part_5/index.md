# 5 설치 확인 및 트러블슈팅

## 5. 설치 확인 및 트러블슈팅

시스템이 정상 설치되었는지 버전 정보를 출력하여 검증합니다.
```bash
# Ubuntu 배포판 버전 확인
lsb_release -a
# 커널 버전 확인
uname -r
```

> **부팅 문제 발생 시**: 가상머신에서 AMD-V 또는 VT-x 가상화 기능이 BIOS에서 켜져 있는지 확인하고 리소스(RAM)를 넉넉하게 재할당해 보세요.
