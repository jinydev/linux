# 호스팅 서비스의 기초

## 1. 호스팅이란
호스팅 서비스란 인터넷 상에서 웹사이트나 애플리케이션을 운영할 수 있는 `공간`과 기술적인 지원을 제공하는 서비스를 말합니다. 일반적으로 `웹 호스팅`, `클라우드 호스팅`, `서버 호스팅` 등 다양한 형태의 호스팅 서비스가 제공됩니다.

## 2. 공유 기반 호스팅 (웹 호스팅)
웹 호스팅은 보통 `공유 호스팅`이라고도 하며, 하나의 거대한 리눅스 서버 리소스를 여러 명의 고객이 일정 할당량만큼 쪼개어 공유해서 사용하는 형태입니다. 비교적 저렴한 가격에 웹사이트를 운영할 수 있어 많은 개인 블로그나 중소기업들이 이용하고 있습니다.

## 3. 원격 단독 서버 임대 (서버 호스팅)
서버 호스팅은 고객이 원하는 사양의 서버 하드웨어 기계를 원격 데이터센터에 직접 구축하거나 통째로 임대하여 단독으로 100% 자원을 사용하는 형태입니다. 완전한 루트(Root) 제어 권한을 가지고 자유도가 매우 높지만 비용도 높은 편입니다.

이러한 호스팅 서비스를 제공하는 업체들은 고객에게 기초적인 리눅스 통제권과 함께 서버 관리, 백업, 보안 등 부가적인 인프라 기술을 지원합니다.
