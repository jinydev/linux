# 7.2 데비안 계열 (Ubuntu) APT 패키지 기초 관리

Ubuntu 등 데비안 계열 리눅스 배포판에서 가장 보편적으로 사용하는 **APT (Advanced Package Tool)** 의 개념과 실무 활용 방법을 학습합니다.

---

## 1. APT 개요 및 특징

과거에는 프로그램 껍데기 파일인 `*.deb` 파일(dpkg 기반)을 어딘가 인터넷에서 수동으로 구해다 넣어야만 하는 불편함이 있었습니다. 이 번거로움을 해결하여 '앱스토어'처럼 자동으로 받아주는 툴이 바로 APT 매니저입니다.

- **의존성(Dependency) 자동 해결**: 카카오톡을 깔려면 관련된 수많은 그래픽 엔진 파일들이 부수적으로 더 필요한 경우가 많습니다. APT는 이런 서브 파일(의존성)들을 봇(Bot)처럼 알아서 백그라운드로 다 긁어와 한 번에 설치해 줍니다.
- **저장소(Repository) 관리**: 인터넷 상에 검증된 리눅스 소프트웨어 저장소 주소들을 통합적으로 관리하여, 바이러스나 해킹 버전이 아닌 공식 프로그램들을 내려받을 수 있게 해줍니다.

---

## 2. 필수 시스템 패키지 명령어 (APT)

주로 Ubuntu 환경에서 새로운 서버 환경을 세팅할 때 밥 먹듯이 사용하게 될 4가지 핵심 명령어입니다. 관리자 권한으로 시스템 영역에 어플리케이션을 까는 것이므로 반드시 **`sudo` 권한**이 동반되어야 합니다.

### 2.1 저장소 목록 업데이트 (`update`)
```bash
sudo apt update
```
* **의미**: "현재 전 세계 리눅스 앱스토어의 카탈로그 새 버전이 나왔는지 주소록을 갱신하라!"라는 명령입니다. **어떤 프로그램을 에러 없이 다운받으려면, 이 명령을 가장 최우선적으로 1번 실행하여 항상 최신 주소록을 유지시켜 둬야만 합니다.**

### 2.2 설치된 패키지 싹 다 업그레이드 (`upgrade`)
```bash
sudo apt upgrade
```
* **의미**: 주소록이 최신으로 갱신되었다면, "현재 내 서버에 깔려있는 모든 구형 버전 프로그램들을 최강의 보안 패치 버전으로 일괄 업그레이드하라"는 뜻입니다.

### 2.3 새 패키지 설치 (`install`)
```bash
# 기본 사용법
sudo apt install 패키지이름

# 중간에 (Y/n) 물어보는 것을 무시하고 무조건 전부다 yes 처리해서 다운받기
sudo apt install -y 패키지이름
```
* **의미**: 내가 원하는 프로그램(ex: `nginx`, `git` 등)을 리눅스 환경에 영구적으로 깔아버립니다.

### 2.4 불필요한 패키지 삭제 (`remove`)
```bash
# 프로그램만 삭제 (설정 파일은 남음)
sudo apt remove 패키지이름

# 패키지의 흔적(설정 파일)까지 서버에서 완전히 날려버리기
sudo apt purge 패키지이름
```

## 3. [실습] APT를 통한 우분투 소프트웨어 설치

가상머신 및 우분투 서버를 처음 건져 올렸을 때 진행하는 최우선 필수 패키지 관리 실습입니다.

### 실습 1. 서버 앱스토어 갱신 후 wget 파일다운로더 설치
```bash
# 1단계. 수천 개의 패키지 주소록을 최신화합니다.
sudo apt update

# 2단계. 인터넷에서 파일을 당겨오는 유명한 기초 툴인 wget(더블유겟)을 강제(-y) 설치합니다.
sudo apt install -y wget

# 3단계. 설치가 제대로 됐는지 버전을 확인해 봅니다.
wget --version
```

### 실습 2. 우분투 환경 전체 업그레이드하기
수많은 해킹 위협에서 서버를 지키기 위해 우분투를 완전히 최신판으로 밀어올립니다.
```bash
# (실행 시 시간이 다소 오래 걸릴 수 있습니다)
sudo apt upgrade -y
```
