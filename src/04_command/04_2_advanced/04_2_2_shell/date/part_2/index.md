# 날짜 형식 지정

## 날짜 형식 지정

`date` 명령어는 다양한 형식으로 날짜와 시간을 출력할 수 있습니다.

### 기본 형식 옵션

```console
# 년-월-일 형식
hojin@DESKTOP-11LMH3B:~$ date +%Y-%m-%d
2020-05-21

# 년/월/일 형식
hojin@DESKTOP-11LMH3B:~$ date +%Y/%m/%d
2020/05/21

# 요일, 월, 일, 년도
hojin@DESKTOP-11LMH3B:~$ date +%A, %B %d, %Y
Thursday, May 21, 2020

# 24시간 형식
hojin@DESKTOP-11LMH3B:~$ date +%Y-%m-%d %H:%M:%S
2020-05-21 15:41:31

# 12시간 형식
hojin@DESKTOP-11LMH3B:~$ date +%Y-%m-%d %I:%M:%S %p
2020-05-21 03:41:31 PM
```

### 자주 사용되는 형식 지정자

| 지정자 | 설명 | 예시 |
|--------|------|------|
| `%Y` | 4자리 년도 | 2020 |
| `%y` | 2자리 년도 | 20 |
| `%m` | 월 (01-12) | 05 |
| `%d` | 일 (01-31) | 21 |
| `%H` | 시간 (00-23) | 15 |
| `%I` | 시간 (01-12) | 03 |
| `%M` | 분 (00-59) | 41 |
| `%S` | 초 (00-59) | 31 |
| `%A` | 요일 (전체) | Thursday |
| `%a` | 요일 (축약) | Thu |
| `%B` | 월 (전체) | May |
| `%b` | 월 (축약) | May |
| `%p` | AM/PM | PM |
| `%Z` | 시간대 | KST |
| `%z` | 시간대 오프셋 | +0900 |
| `%s` | Unix 타임스탬프 | 1590049291 |
