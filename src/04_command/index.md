# 4장. 리눅스 명령어 (Command)

그래픽 환경(GUI) 없이 터미널 인터페이스(CLI)에서 리눅스 시스템을 제어하는데 필수적인 명령어들을 학습합니다. 서버 엔지니어가 마우스 없이 키보드만으로 시스템을 빠르고 안전하게 다루기 위한 명령어 파이프라인과 텍스트 스트림 조작 기법을 살펴봅니다.

## 세부 학습 목차

* **[4.1 리눅스 기본 명령어 (Basic)](04_1_basic/)**
  현재 작업 경로를 확인하고(`pwd`), 디렉토리를 이동하며(`cd`), 파일을 목록화 및 열람, 나아가 복사 및 삭제(`cp`, `mv`, `rm`, `cat`)하는 가장 기초적이면서도 필수적인 리눅스 터미널 활용 방법들을 학습합니다.
* **[4.2 리눅스 고급 명령어 구축 (Advanced)](04_2_advanced/)**
  단순 파일 조작을 넘어, 다수의 파일을 아카이브(tar) 및 압축하거나, 정규식을 포함해 심층적으로 텍스트를 검색(`grep`, `find`)하고 서버의 동작(시작/종료)을 시스템 수준에서 처리하는 깊이 있는 명령어 환경을 배웁니다.
* **[4.3 텍스트 편집기 및 입출력 제어 (Editor & Stream)](04_3_editor/)**
  서버 환경에서 가장 강력하고 표준적인 터미널 텍스트 편집기인 Vim(vi)의 조작 모드들을 마스터하고, 파이프(`|`)와 리다이렉션(`>`, `<`) 기호를 이용해 여러 명령어 간의 입출력 데이터 스트림(Stream) 흐름을 조립하는 파이프라이닝 스킬을 획득합니다.

> **💡 이관 안내:**
> 과거 버전에 수록되어 있던 네트워크(Network) 설정 메뉴얼, 웹 개발 도구 환경(VSCode, Git 등), 사용자 계정 및 권한 제어 문서는 강의 커리큘럼 정책에 따라 전용 챕터인 **6장(네트워크), 11장(개발 시스템), 3장(기본 사용법)** 으로 각각 이관 통합되었습니다. 본 장에서는 시스템 명령어 활용 구문에만 집중합니다.
