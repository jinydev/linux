# 장점

## 장점
---

### IP 주소 절약
하나의 공인 IP를 사용하여 여러대의 호스트가 인터넷에 접속할 수 있다.

* 예) 집에 외부 IP 하나만 있고, 내부의 많은 기기들이 내부 IP를 사용하여 인터넷 통신할 수 있다.

### 보안
NAT 동작 특성상 내부의 IP를 숨길 수 있다.

* 예) 라우터를 통해서 나가는 내부 ip는 외부에 노출이 되지 않기 때문에, 안쪽의 ip로 직접 공격할 수 없다.
