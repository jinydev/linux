# IP 주소 체계

## IP 주소 체계
각 8 bit 씩 4개의 번호로 이루어짐
> 8 bit = 2^8 =  256

### ip의 주요 역할
네트워크를 나타내는 네트워크 id와 호스트를 나타내는 호스트 id로 구분된다. 

* Ex) Server의 IP 주소는 192.168.111.141, 모든 컴퓨터에서 자기 자신을 의미하는 IP 주소는 127.0.0.1
