# 9.2 우분투 네트워크 고정 IP 설정 (netplan)

서버(Server)는 식당의 간판과도 같습니다. 손님이 언제 접속하든 항상 같은 주소 체계를 유지해야 서비스를 안정적으로 영위할 수 있으므로, 리눅스 서버 환경에서는 랜덤으로 주소가 바뀌는 것을 막기 위해 **수동 고정 IP(Static IP)** 할당 작업이 강력하게 요구됩니다.

![리눅스 IP 할당 2가지 방식 비교도](./img/ip_config.svg)
> **동작 원리**: 처음 가정용 공유기나 VMware에 우분투 리눅스를 설치하면 DHCP 방식으로 자동 할당을 받아 인터넷이 잘 됩니다. 하지만 재부팅을 하거나 며칠이 지나면 이 주소가 변해버려 원격 접속이 끊어지는 대참사가 발생합니다. 그래서 `/etc/netplan/` 내부의 환경 설정 파일을 조작해 영구 못을 박습니다.

---

## 1. 현재 네트워크 IP 주소 확인하기

과거의 모든 유닉스 및 구형 리눅스 시스템에서는 컴퓨터의 네트워크 카드를 조회할 때 `ifconfig` 라는 단일 명령어를 써왔습니다.

### 1.1 `net-tools` 패키지를 통한 조회
하지만 최근의 데비안/Ubuntu 20.04 이상 버전부터는 `ifconfig` 명령어가 아예 삭제되어 작동하지 않는 당황스러운 일을 마주하게 됩니다. 이를 쓰기 위해서는 수동으로 구형 네트워크 툴킷을 먼저 깔아야 합니다.
```bash
# apt 패키지를 최신화하고 네트워크 조회 툴 박스를 강제 설치합니다.
sudo apt update
sudo apt install -y net-tools

# 이제 예전처럼 명백하게 본인의 IP를 조회할 수 있습니다.
ifconfig
```
> *(조회 결과 나오는 `wlo1` 이나 `ens18` 같은 단어가 내 서버의 진짜 안테나(인터페이스) 이름입니다.)*

### 1.2 `ip` 명령어를 통한 신규 조회
툴 설치하기가 번거롭다면 요즘 리눅스들에 탑재된 신형 표준 명령어를 쓰면 한 줄로 뜹니다.
```bash
ip addr show
```

## 2. [실습] 고정 IP(Static)로 영구 변경하기

> 외부 레퍼런스 참고: [우분투 22.04 LTS 고정 IP 설정 가이드](https://it-svr.com/ubuntu-22-04-lts-static-ip/)

최신 우분투는 네트워크 관리를 모두 `yaml(야믈)`이라는 띄어쓰기 엄격 포맷을 사용하는 **Netplan 매니저** 로 컨트롤합니다. 아래와 같이 root 관리자 모드로 야믈 파일을 열고 세팅합니다.

### 실습 1. Netplan 설정 파일 열고 편집
```bash
# 반드시 관리자 (sudo) 권한으로 /etc/netplan 폴더 깊은 곳의 파일을 에디터로 엽니다.
# (파일명 01-network... 등은 컴퓨터마다 앞 숫자가 다를 수 있습니다)
sudo vi /etc/netplan/01-network-manager-all.yaml
```

### 실습 2. YAML 편집 (수동 IP 입력)
에디터 화면에서 다음과 같이 공백(Space) 간격을 철저히 맞추어 IP 세트를 강제 입력합니다.
```yaml
# This is the network config written by 'subiquity'
network:
  version: 2
  ethernets:
    ens18:     # (본인 컴퓨터의 ifconfig 통신 인터페이스 이름으로 맞춰야 함)
      addresses:
        - 192.168.1.12/24    # (강제로 고정할 서버 주소와 /24 대역 마스크)
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]   # (구글의 글로벌 접속 DNS 세우기)
      routes:
        - to: default
          via: 192.168.1.1   # (인터넷으로 나가는 내 집/회사 공유기의 게이트웨이 주소)
```

### 실습 3. 변경 사항 시스템 강제 적용 (Apply)
위처럼 파일을 저장하고 빠져나온 후, Netplan 백그라운드 엔진을 재부팅시켜 바뀐 고정IP를 즉시 입혀줍니다.
```bash
sudo netplan apply
```
