# 9.3 텔넷(Telnet)과 보안 쉘(SSH) 원격 접속 관리

실제 데이터센터나 클라우드 인터넷망(AWS 등) 공간에 놔둔 수백 대의 리눅스 장비들은 모니터와 키보드가 달려 있지 않습니다. 내 노트북(Client)에서 지구 반대편의 장비(Server)로 네트워크 선을 타고 들어가 타건하는 **'원격 접속(Remote Connection)'** 작업이 서버 다루기의 모든 것입니다.

![원격 접속 프로토콜 안전성 비교](./img/remote_ssh.svg)
> **동작 원리**: 네트워크 IP를 알아냈다면, 이제 그 IP 위로 통신 터널을 뚫어야 합니다. 통신 터널을 뚫는 규약인 프로토콜(Protocol)을 어떤 것을 쓰냐에 따라 해커에게 털릴 수도 있고, 안전하게 보호받을 수도 있습니다.

방대한 주제를 분할하여 제공합니다.
