# 패키지 설치

## 패키지 설치
명령을 실행하여 BIND를 설치합니다.

```bash
sudo apt-get update 
sudo apt-get install bind9 
```

BIND가 설치되면 구성해야 할 수 있습니다. 
명령을 실행하여 BIND 서비스를 다시 시작합니다.  
```
sudo service bind9 restart 
```
