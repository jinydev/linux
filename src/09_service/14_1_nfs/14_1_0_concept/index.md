# 14.1 NFS (Network File System)

NFS는 원격지에 있는 서버의 하드디스크 공간을 마치 내 컴퓨터의 폴더처럼 편하게 `mount` 시켜 사용하는 파일 공유 기술입니다.

## 패키지 설치
```bash
sudo dnf install nfs-utils
```
