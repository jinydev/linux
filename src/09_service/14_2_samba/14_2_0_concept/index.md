# 14.2 Samba (삼바 파일서버)

Samba는 리눅스 저장공간을 윈도우 OS 시스템에서 '네트워크 드라이브' 형태로 접근할 수 있게 해주는 호환성 오픈소스입니다.
SMB/CIFS 프로토콜을 사용합니다.
