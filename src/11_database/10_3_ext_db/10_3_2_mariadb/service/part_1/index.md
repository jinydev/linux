# systemctl

## systemctl
---
Apt 명령어로 설치를 할 경우 `/etc/system/system`에 `서비스이름.service` 또는 `서비스이름.socket`으로 등록된다.

```
$ sudo systemctl start 서비스 이름
```

* start : 시작
* stop : 종료
* restart : 재시작
* status : 상태
* enable
* disable
