# 설치

## 설치

페키지 목록을 최신 상태로 유지합니다.

```
$ sudo apt update
```

설치하기

```
$ sudo apt-get install postgresql postgresql-contrib
```

postgresql 설치시 기본적으로 postgres 계정이 생성됩니다.

postgres 계정은 PostgreSql을 관리하기 위한 계정 입니다.

postgres 계정으로 변경합니다.

```
sudo -i -u postgres
```
