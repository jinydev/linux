# 13장. 애플리케이션 및 오픈소스 실습 (App)

리눅스와 오픈소스 문화는 떼려야 뗄 수 없는 관계입니다. 앞선 중급 과정에서 습득한 파일 권한 논리, 웹 서버(Apache/Nginx) 및 데이터베이스(DB) 연결 지식을 응용하여 복합적인 생태계의 오픈소스 시스템을 처음부터 끝까지 혼자 구축해 봅니다.

아래의 세부 학습 주제를 챕터별로 클릭하여 상세 레퍼런스를 확인하세요.

  * 여러 대의 서버 부하와 상태를 중앙에서 수집하고 대시보드로 관제하는 Zabbix 시스템 인스톨
