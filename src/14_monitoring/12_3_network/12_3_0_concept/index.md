# 12.3 네트워크 모니터링 (netstat, ping)

네트워크 포트 점유 상태 및 외부 통신 레이턴시를 측정하여 네트워크 병목과 단절 원인을 파악합니다.

* **`netstat -ntlp`**: 현재 Listen 중인 데몬 포트를 확인합니다.
* **`ping`**: 네트워크 왕복 지연율 및 손실률을 측정합니다.
