# 15.2 시스템 로그 관제 (/var/log)

서버의 모든 발자취는 흔적을 남깁니다. `/var/log` 내의 주요 파일을 항상 주시해야 합니다.

- `auth.log` / `secure`: 누가 언제 어떤 계정에 로그인 성공/실패했는지 기록합니다.
- `syslog` / `messages`: 소프트웨어 및 하드웨어 오류 커널 메시지가 쌓입니다.
- `dmesg`: 시스템 부팅 과정의 I/O 연결 기록입니다.
- `logrotate`: 끝도 없이 커지는 로그 파일을 매일/매주 단위로 자르고 압축해주는 데몬입니다.
